# 仓库与日常入口第二轮整理

本轮按当前功能补充管理与日常入口，不改源脚本、不删除用户数据，不包含投屏。最低平台目标继续为 iOS 18。

## 功能与入口

- GitHub 仓库管理增加 PY／JS、已安装／未安装筛选，并区分本机安装与公共仓库发布。上传确认前刷新仓库检查路径和 ID：新源显示新增预览；已存在时明确拒绝重复新增，不会覆盖旧文件。候选分支发布和双线路核对仍走现有流程，本次没有向公共源仓库发布任何内容。
- 点击全局网络等待提示可查看请求来源、HTTP 方法、主机和等待秒数，取消单个请求。只取消该请求的本地生命周期，不取消共享的父任务或其他请求；取消异常按 NetworkCancelled 处理，防止队列再次重试已取消请求。完成、超时和迟到状态仍按请求 ID 清理。详情不显示 URL 路径、查询参数、请求体或凭据。
- 源体检增加搜索试查，保存加载、搜索、详情、地址解析的分项结果、时间和源版本。管理列表展示记录，源版本不同标为旧版本检测。正文支持文字。地址解析通过不会被标为可播放；只有播放器确实进入非缓冲播放且时间已前进时，才记录实际起播时间。无痕播放不写此记录。所有状态均为历史验证，不保证站点当前始终可用。
- 源管理的“站点维护 → 重复源检查”比较本机脚本 SHA256 与站点域名。完全相同脚本与疑似同站不同版本分开展示；不联网、不自动合并、不自动删除。读取失败会说明，用户返回源管理决定停用或删除。
- 设置“阅读与播放 → 继续看／读／听”按最近进度汇总各板块记录及媒体库音频进度。视频进入续播详情，漫画/小说按原章节 ID 续读；章节消失则转详情供选择。原源不可用保留进度并提供搜索其他来源，换源时以原作品名和集名复核，不套用旧源的内部章节 ID。原板块身份与数据不迁移。历史锁定板块隐藏条目，后台切换清除解锁状态；锁密码变更也要求重新解锁。媒体资源同时遵守目标及原板块的历史锁。
- 收藏抽屉增加更新频率菜单：仅手动、每小时、每 6 小时、每天，默认 6 小时。只在打开收藏时按间隔检查已收藏作品，不注册系统后台定时任务或推送通知。检测有总预算和逐项等待限制，可停止，退出抽屉取消。空目录不会清除有效章节基线；更新标识补充新增条目数，避免把多线路条目误作唯一集数。
- 预载与清理、缓存管理统一到“存储与缓存”；流畅度、日志、报告和诊断包统一到“问题排查”。旧功能保留，旧名称仍可搜索直达。
- 原生导航提供标准玻璃、紧凑玻璃、清晰实色预设；细调参数收进“高级外观”，保存值与原有高级能力保留。

## 验证与边界

新增回归覆盖单请求取消隔离、等待详情、仓库筛选、源验证记录、重复提示不修改源、统一记录的历史锁、原来源失效后进度保留、收藏频率及导航预设。相关测试分组运行，另跑播放器、阅读书架、源管理、公开仓库候选发布及导航兼容性回归。静态检查覆盖 lib 和 test。

没有生成新 IPA，也没有在 iPhone 上逐站播放或真实提交公共源仓库。这轮不会让旧安装包自动拥有新入口，需要安装包含对应提交的 App 构建。真实 iOS 网络等待回调、媒体内核和玻璃材质效果仍需真机体验核对。
