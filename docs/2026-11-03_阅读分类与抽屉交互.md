# 阅读分类与抽屉交互

## 漫画、视频入口

漫画板块统一容纳漫画、美图、文字小说、有声与 Kazumi。书架和源菜单提供分类选择；源菜单使用统一纵向列表，不再将漫画、美图固定分占左右两列。视频保留 JS、猫源、PY、模块、网页，并新增 TVBOX 格式入口。

漫画与视频均通过“调整分类顺序”拖动排序，保存在各自阅读设置中，“全部”固定在前面。新分类追加时不丢失旧顺序。全局“内容分类显示”按两个板块列出漫画、美图、小说、有声、Kazumi、视频、影视、TVBOX；关闭只影响抽屉显示，不删除数据或停用源。

## 旧数据迁移

应用启动、页面及订阅任务创建之前，将视频库里明确的文字小说、有声源和 Kazumi 移至漫画库。TVBox 条目保留在视频库。源 ID、脚本、站点配置、启停状态、网络覆盖、回滚记录均保留；收藏、文件夹及逐集进度按原 source/item 身份复制。独立订阅随源移动，混合订阅保留原板块，迁移成员保留单独更新地址。

目标数据和订阅先持久化，再清理原源。中断后可重试；同 ID 不同脚本时保留原数据并记录冲突，不覆盖目标源。普通综合站不整站迁移，仍按单个作品的真实载荷选择详情与阅读器。缓存及既有下载文件不删除。

## 首页手势

源首页屏内左滑进入下一个一级分类，右滑进入上一个；切换复用既有分类请求，从第一页加载。边界不循环，短滑不切换，源切换/首屏加载/搜索输入期间不触发。屏幕两侧保留抽屉手势，子级横向内容优先处理自己的滑动。

## 播放器

弹幕保持原来的右侧抽屉和“来源与匹配 / 显示样式”标签，只放大字号、按钮和间距。剧集线路标题、说明和选项统一内边距，避免文字贴边；切线与进度保留语义不变。

## TVBox 与导入诊断

视频源菜单新增 TVBOX 标签及添加入口。TVBox 的 CMS、直播和 Python 均在此分组，底层运行时不变。导入页注明显示位置，成功后可直接进入查看，并通知视频源列表刷新。

订阅导入按脚本隔离声明错误，错误指向具体文件；失败清单仍保护旧源，不再中断之后的有效条目。火力视频的源设置声明由不支持的 password 类型修正为 text，版本 2.0.1；App 对密码、令牌、Cookie 等敏感文本字段使用遮挡输入。

GitHub 授权仍只由设备 Keychain 保存，未将用户令牌加入源码、安装包、文档或订阅。

## 验证

使用真实 SQLite 覆盖迁移、重复运行、同 ID 冲突、收藏/逐集进度、文件夹、订阅归属与排序持久化；Widget 测试覆盖两板块拖动、TVBOX 分类、导入取消、单列表、可见性、分类滑动与抽屉边界、弹幕抽屉及线路留白。预览入口为 `tool/source_picker_unified_preview.dart`，示例数据与正式配置独立。iOS 最低版本保持 18.0。
