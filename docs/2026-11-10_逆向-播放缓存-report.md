# 播放磁盘缓存与续播兼容

范围：[本次授权与边界](2026-11-10_播放缓存-scope.md)。

用户诊断中存在本地红果源分段长度不一致及 HTTP 502。修复采用一套共享 HTTP 缓存层，接在初次预启动、正常加载、重试及下一集预载路径；四个原生内核共用，第三方包保持原样。实际 iPhone 网络播放与原生编译仍需设备或 macOS CI 验证，模拟测试不代表所有 CDN 故障已经消失。

## 实现

- 磁盘缓存默认 1 GiB，可选 500 MiB / 1 / 2 / 5 GiB；异步串行写入、LRU 回收、独立清理。会话缓存重启后清除，不作为离线下载使用。
- 按 HTTP Range 分块读取，合并被本地代理截短的响应，校正下游长度；临时 502/503/504 最多重试一次。远端起点错误或媒体变化时拒绝拼接，不伪造缺失数据，也不切换画质。
- HLS 清单不缓存，改写变体、分片、密钥和初始化段地址；处理跳转后的相对路径和 gzip/deflate 清单。跨域不携带原域 Cookie/Authorization。非可缓存响应保持内核流式播放。
- 磁盘空间至少预留 256 MiB；空间不足或写入失败回退内核缓冲。播放稳定且缓冲有余量时才串行补充磁盘预读，切集、后台或退出停止额外预读。
- 设置沿用「预载与清理」，播放器网络设置和缓存管理均可进入；播放信息显示磁盘占用、命中、读取量和下一集实际缓冲，诊断包增加相关设置文件。

| 默认参数 | 原值 | 新值 |
|---|---:|---:|
| 当前集目标前向预读 | 120 秒 | 300 秒 |
| 内核前向内存预算 | 150 MiB | 256 MiB |
| MPV 回退预算 | 16 MiB | 32 MiB |
| 下一集目标预缓冲 | 5 秒 | 15 秒 |
| 图片、音视频预载总预算 | 64 MiB | 128 MiB |
| 其中视频预算 | 16 MiB | 32 MiB |

已有用户设置保持原值。AVPlayer 的内存字节预算仍由系统决定；磁盘上限由共享缓存层执行。起播不等待目标缓冲填满。下一集在播放到 85% 或剩余设定秒数时准备，前提是当前集有 15 秒余量或剩余内容已全部缓冲。
