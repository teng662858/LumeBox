# 媒体徽章

设置 → 阅读与播放 → 媒体徽章：总开关、资源卡片、详情、播放器、随控件隐藏及纯文字/紧凑徽章/图文徽章样式，偏好保存到 AppPreferences。

卡片最多两个、详情最多八个，设置页提供明确标注的演示规格。图文样式按分辨率、动态范围、编码、位深、音频、声道、帧率和语言使用不同图形；动态范围采用柔和强调色，不使用第三方品牌徽章包。

源列表条目的可选 mediaInfo 字段支持 resolution、dynamicRange、videoCodec、bitDepth、audioCodec、channels、fps、language。只接受显式参数，不扫描标题。尚未提供参数的源不显示徽章，无需请求详情补全每个海报。真实播放使用现有 PlayerStats 分辨率、编码、帧率；HDR、杜比、位深、声道暂不能从现有内核接口确认，不编造。

验证：徽章解析/开关/样式预览 3 项及横竖屏布局 3 项通过；改动文件静态分析通过。Android 预览入口增加“媒体徽章”，仅预览入口保留在本地。

## 场景与分类定制

- 默认紧凑徽章，提供纯文字与图文徽章；兼容第一版图形偏好。
- 八类规格独立开关，同类去重，海报最多两个、详情最多八个，播放器默认仅分辨率/动态范围/音频格式。
- 预览改为海报角标、详情规格行、播放器叠层，演示参数明确标注；各位置开关和分类选择直接影响预览。
- 新增分类隐藏、同类去重、播放器密度与文字样式测试，徽章 4 项测试及静态分析通过。
