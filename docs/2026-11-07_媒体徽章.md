# 媒体徽章

设置 → 阅读与播放 → 媒体徽章：总开关、资源卡片、详情、播放器、随控件隐藏及文字/图形样式，偏好保存到 AppPreferences。

卡片最多两个、详情最多八个，设置页提供明确标注的演示规格。图形样式为内置媒体图标配文字，不使用第三方品牌徽章包。

源列表条目的可选 mediaInfo 字段支持 resolution、dynamicRange、videoCodec、bitDepth、audioCodec、channels、fps、language。只接受显式参数，不扫描标题。尚未提供参数的源不显示徽章，无需请求详情补全每个海报。真实播放使用现有 PlayerStats 分辨率、编码、帧率；HDR、杜比、位深、声道暂不能从现有内核接口确认，不编造。

验证：徽章解析/开关/样式预览 3 项及横竖屏布局 3 项通过；改动文件静态分析通过。Android 预览入口增加“媒体徽章”，仅预览入口保留在本地。
