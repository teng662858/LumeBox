# 275听书（i275.com）评估：能做的部分做完了，播放被站方锁给官方 App

- 日期：2026-11-05
- 目标：https://www.i275.com/（同内容镜像 `m.i275.com`，都实测 200）
- 板块：有声（`category: audiobook`，App 归漫画板块的「有声」分类）
- 交付物：`sources/comic/i275.js`（v1.0.0，浏览/详情/目录全真实；播放按站方现状如实报错）
- **没有进订阅、没有推到 LumeBox-Sources**：播放链路无法验证（原因见第三节），
  按约定不放「能导入、点开就报错」的源。要不要上架等站方放开再说。

## 一、站点结构（全部实测）

PHP + Tailwind 服务端渲染，**没有分类页、没有排序、没有筛选、没有会员体系**。可用结构只有四块：

| 路由 | 说明 |
|---|---|
| `GET /` | 首页只有「最近上架」12 部 + 「热门搜索」5 部（`剑来 / 凡人修仙传 / 神秘复苏 / 仙逆 / 大奉打更人`） |
| `GET /search.php?q=<词>` | 站内搜索，命中书名/作者/演播/简介；**服务端 `LIMIT 50`，`page=` 被忽略** |
| `GET /book/{书号}.html` | 详情 + **完整目录**（`<a id="chapter-pos-N" href="/play/{书号}/{章节号}.html">`） |
| `GET /api_chapter.php?book_id=&chapter_id=` | `{url,title,book_title,cover}` —— 取音频地址的唯一接口 |

页面里的坑（都已处理）：

1. **书本页顶部带着和首页一模一样的搜索大标题**（`<h1>275听书-海量免费有声小说</h1>`），
   直接取第一个 `<h1>` 会把书名解析成站名；真正的书名在 `<h1 class="text-2xl …">`，
   简介要认 `class="text-gray-600 … line-clamp-3"`（页面 `<style>` 里也有 `line-clamp-3` 这个类名）。
2. 目录条目跨两行（`<a id="…"` 换行 `href="…"`），正则要 `[\s\S]`。
3. 书的编号不连续：`/book/1.html`、`/book/20000.html`、`/book/39400.html` 是空的（正文仅 10~200 字节），
   `18000~29500` 一大段基本是空书。
4. `www.ting275.com`、`ting275.com` 只剩 nginx 404（老域名），`www.tingshijie.com` 是公司主页，都不是镜像。
5. `/play/…` 播放页**无 Cookie 时 302 回首页**；带 `PHPSESSID` 才给页面（页面里 `fetch('/api_chapter.php…')`）。

## 二、接口要会话：`api_chapter.php` 的门票

- 直接请求（无 Cookie）→ `{"error":"非法访问"}`；
- 先 `GET /` 拿 `Set-Cookie: PHPSESSID=…; notice_seen_…=1`，再带 `Cookie` 请求 → 正常返回 JSON；
- `Referer` 带不带都一样，关键是那个会话。

源里的做法：会话存 `LumeSource.fs`（6 小时），命中「非法访问」自动重领一次；
宿主若替我们维持了 Cookie 罐（`headers` 里看不到 `Set-Cookie`），就自己生成一个 `PHPSESSID` 兜底。

## 三、音频三种状态，以及为什么现在放不出来

`api_chapter.php` 的 `url` 字段只有三种形态（抽样 57 本，跨 100~39300 号段）：

| 形态 | 样本数 | 含义 |
|---|---|---|
| `http(s)://2025.tingshijie.com/…`、`audio.tingshijie.com/…` | 8 | 自建音频（`/jl/0003.mp3`、`/63/63_56186.m4a` 这类） |
| `lrts$<专辑号>#<音轨号>#…#<手机号>.txt` | 24 | **只存了懒人畅听的编号**，本站没有音频文件 |
| `null` | 5 | 新书还没上传（`39453`、`39454` 这类最新书全是 null） |
| 没有章节（空书/已下架） | 20 | `/book/{id}.html` 正文只有几行 |

**形态 1 的地址是对的，但取不到字节**：`*.tingshijie.com` 对一切非官方 App 的请求回
`403 Access Denied: Please use the official App.`（43 字节，`Content-Type` 还写着音频类型）。实测矩阵：

- `http` / `https` 都是 403（https 证书还是过期的）；
- 带 `Range`、带 `PHPSESSID`、带 `Referer`（站点首页 / 播放页 / `app.tingshijie.com`）、
  带 `Origin`、`X-Requested-With`、`X-From: app` 全部 403；
- 换 UA：Safari / Chrome / Dalvik / 微信 / Apache-HttpClient / 各种 App 猜名（tingchina、
  tingzhongguo、com.tsj.babala、TSJ…）全 403；只有 `okhttp/*`、`ExoPlayer` 会走成普通 nginx 404
  （说明 App 用的不是这几个裸 UA，而是另一套带凭据的 URL）；
- 加 `?sign=` / `?token=` / `?e=&st=` / `?wsSecret=&wsTime=` 等签名参数不改变结果（连不存在的路径都 403）；
- 换路径前缀（`/audio/` `/media/` `/app/` `/v1/` …）用 `okhttp` UA 探测全 404；
- **境外多节点复测**（check-host.net 的 at/de/ir/rs/ru 节点）同样 403，源站 IP `61.160.236.95`，
  所以不是本机出口 IP 的问题。

站点自己的态度也写在首页弹窗里：「**本站无法正常收听**，请微信搜索小程序『拾音盘』」——
`<audio>` 直连同一批文件，站方自己也知道播不响。结论：**播放是站方刻意关掉的，不是解析问题。**

## 四、源实现（`sources/comic/i275.js`）

- **home**：`热门收听`（首页热门搜索 5 部，实测都还有音频）+ `最近上架`（12 部）。
- **categories / list**：`hot`、`new`，再加 19 个「题材」分类 —— 站点没有分类页，
  所以用站内搜索词做浏览轴（`kw:玄幻` / `kw:悬疑` / `kw:都市` / `kw:评书` / `kw:儿童` …），
  每个词实测都有 10~50 条真实结果，首条互不相同；站方搜索上限 50 条且不分页，所以一页到底（`hasMore:false`）。
- **detail / chapters**：一次请求书本页，解析书名/封面/作者/演播/状态/热度/简介 + 完整目录
  （`剑来` 5231 章、`灵境行者` 840 章），解析结果缓存 30 分钟，详情与目录共用同一份。
- **content**：领会话 → `api_chapter.php` → 三种形态分别处理
  （`lrts$…` 抛「本站没有音频文件」、`null` 抛「新书还没上传」、正常 URL 先探一次字节）；
  探测拿到 403 就抛「站方只给官方 App」，**不伪造可播地址**，也不静默返回空。
- 不声明排序/筛选/分页/`commonSettings`——站点没有对应能力。

验证（`node tools/lume-source-check.mjs sources/comic/i275.js`）：

```
- ok home       (902ms) 2 板块 / 17 条
- ok categories (1ms)   21 个（hot / new / 19 题材）
- ok list       (386ms) 5 条（hot），new 12 条，kw:* 各 50 条，首条互不相同
- ok detail     (1674ms) 剑来（上下部）/ 封面 imagev2.xmcdn.com / 简介完整
- ok chapters   (2ms)   5231 章，标题「0001 剑来-笼中雀」…
- FAIL content  → http://2025.tingshijie.com/jl/0001.mp3 403「Please use the official App.」
```

## 五、解锁播放需要什么（按性价比排序）

1. **官方 App 的音频凭据**：包名 `com.tsj.babala`（「听中国听书」1.8.9），站点首页右下角
   指向蓝奏云目录 `wwbww.lanzouq.com/s/tingchina`（里面现在是 `拾音盘1.41.apk`）。
   拿到 APK 后看它请求 `*.tingshijie.com` 时带了什么 UA/签名头（`okhttp` 会走成 404，
   说明 App 用的不是裸 UA，而是另一套带凭据的地址），把那一层复刻进 `content()`。
   本机目前下载不到：直链主机 `dq9.692657.com` 掐连接、蓝奏云文件页有 JS 挑战。
2. **在手机上验一次**：把 `sources/comic/i275.js` 手动导进 App，点「热门收听 → 剑来」的任意一集。
   如果 App 里能出声，说明 403 其实是**出口 IP 白名单**（我们这边是境外 IP），源立刻可用；
   如果报源里那条 403 文案，就是客户端凭据门禁，等第 1 条。
3. 拾音盘/懒人畅听方向（`lrts$` 那 24 本）：那是另一套站点的内容，另做源，不属于 i275。
