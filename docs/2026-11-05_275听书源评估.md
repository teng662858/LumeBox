## 一、站点结构（实测）

PHP + Tailwind 服务端渲染，**没有分类页、没有排序、没有筛选、没有分页、没有会员体系**：

| 路由 | 说明 |
|---|---|
| `GET /` | 首页只有「最近上架」12 部 + 「热门搜索」5 部；`?page=` 被忽略 |
| `GET /search.php?q=<词>` | 命中书名/作者/演播/简介，**服务端 `LIMIT 50`，`page=` 被忽略** |
| `GET /book/{书号}.html` | 详情 + **完整目录**（`<a id="chapter-pos-N" href="/play/{书号}/{章节号}.html">`） |
| `GET /api_chapter.php?book_id=&chapter_id=` | `{url,title,book_title,cover}`，取音频地址的唯一接口 |

解析坑（都处理了）：

1. **书本页顶部带着和首页一样的搜索大标题**（`<h1>275听书-海量免费有声小说</h1>`），直接取第一个 `<h1>` 会把书名解析成站名；书名在 `<h1 class="text-2xl …">`，简介要认 `class="text-gray-600 … line-clamp-3"`（页面 `<style>` 里也有这个类名）。
2. 目录条目跨两行（`<a id="…"` 换行 `href="…"`），正则要 `[\s\S]`。
3. 书号不连续：`/book/1.html`、`/book/20000.html`、`/book/39400.html` 是空书（正文 10~200 字节）。
4. `www.ting275.com` / `ting275.com` 只剩 nginx 404（老域名），`www.tingshijie.com` 是公司主页，都不是镜像。
5. `/play/…` 无 Cookie 时 302 回首页 —— 源里不走播放页，只用 `api_chapter.php`。

## 二、`api_chapter.php` 要会话

- 裸请求 → `{"error":"非法访问"}`；
- 先 `GET /`（站点会 `Set-Cookie: PHPSESSID=…`）再带会话请求 → 正常 JSON；
- 宿主（App 的 SiteSessionPool / 检查器）本来就按 origin 存 Cookie，所以源里**先裸打**，被判非法访问时才自己 `GET /` 拿 Cookie 重试一次；**不要自己造 PHPSESSID**（实测造假 id 反而被判非法访问）。

## 三、音频四种来路，两种能播

抽样 70 本（书号 200~39300 均匀取），`api_chapter.php` 的 `url` 分布：

| 形态 | 数量 | 播放 |
|---|---|---|
| `lrts$<专辑号>#<音轨号>#<分段>#<手机号>.txt`（懒人畅听） | 31 | **免费章可播**，收费章明确报错 |
| `http(s)://2025.tingshijie.com/…`、`audio.tingshijie.com/…`（站方自建） | 11 | **全部 403**，播不了 |
| `null`（新书还没上传） | 3 | 播不了 |
| 空书（没有目录） | 25 | — |

（另有极少数 `xm$<声音ID>`＝喜马拉雅，抽样里没抽到，但实测存在：书 1314。）

**① 懒人畅听（lrts）→ 能播（免费章）**
`GET https://m.lrts.me/ajax/getPlayPath?entityId=<专辑>&entityType=3&opType=1&sections=[<分段>]&type=0&id=<音轨>&section=<分段>`
→ `list[0].path` 是腾讯音乐 CDN 的签名 m4a，实测 `206 + audio/mp4`（`vb.stream.tencentmusic.com/long/…m4a`）。
限界：站方只免费放出**靠前的章**（实测 3012 第 1 章 ok，第 50/300/890 章回「收费章节未购买」；4268 全本免费用到第 66 章仍 ok）。源里把这条 msg 翻成人话再抛。

**② 喜马拉雅（xm）→ 能播（整本）**
`https://mobile.ximalaya.com/mobile/redirect/free/play/<声音ID>/0` 会 302 到 audiopay CDN 的 m4a，实测 `206 + audio/x-m4a`（http/https 都行），书 1314 第 1/20/168/335 集全部 206。
源里**故意不预取**（宿主会跟 302，预取一次就把整集几 MB～几十 MB 拉进沙箱），直接把跳转地址交给播放器。

**③ 站方自建音频 → 403，播不了（这是站方现状）**
`*.tingshijie.com` 对所有非官方 App 的请求一律回 `403 Access Denied: Please use the official App.`：

- http/https、带不带 `Range` / `PHPSESSID` / `Referer`（首页、播放页、`app.tingshijie.com`）/ `Origin` / `X-Requested-With` 全 403；
- 换 UA：Safari / Chrome / Dalvik / 微信 / Apache-HttpClient / tingchina、tingzhongguo、com.tsj.babala… 全 403；只有 `okhttp/*`、`ExoPlayer` 走成普通 nginx 404；
- 加 `?sign=` `?token=` `?e=&st=` `?wsSecret=&wsTime=` 不改变结果（连不存在的路径都 403）；
- 换路径前缀（`/audio/` `/media/` `/app/` `/v1/` …，用 okhttp UA）全 404；
- 换主机：`audio.tingshijie.com` 同样 403，`www/m/app.tingshijie.com` 上没有这批文件（404）；
- **境外多节点复测**（check-host.net 的 at/de/ir/rs/ru 节点）同样 403（源站 `61.160.236.95`），不是本机出口 IP 的问题；
- 站点首页自己也弹窗写着「**本站无法正常收听**，请微信搜索小程序『拾音盘』」。

所以 `content()` 对自建音频先探一次字节：403 就抛「站方自建音频主机拒绝非官方 App」的可读错误，不伪造可播地址。

## 四、发布与两条线路（**当前被仓库可见性卡住**）

- `LumeBox-Sources` 提交：`3b6d1a1`（`audiobook/275听书.js` + catalog + 订阅清单 + 源目录）
- `python tools/build_catalog.py --check` → `changed 0`
- 两条线路实测（2026-11-05）：
  - `raw.githubusercontent.com/teng662858/LumeBox-Sources/main/audiobook/275听书.js` → **404 Not Found**
  - `cdn.jsdelivr.net/gh/teng662858/LumeBox-Sources@main/…` → **Failed to fetch … from GitHub.**
  - `api.github.com/repos/teng662858/LumeBox-Sources` → **404**（对照 `nodejs/node` → 200）
  - 结论：**仓库现在是私有的**，raw / jsDelivr 都取不到，App 里所有订阅（不只是本源）都会失败。
    改回 public：`gh repo edit teng662858/LumeBox-Sources --visibility public --accept-visibility-change-consequences`
    之后刷新 CDN（`python tools/purge_cdn_cache.py --repository … --after <sha>`）再复核两条线路。
- 自建 Cloudflare Pages 线路（`https://lume-sources.pages.dev/subscriptions/audiobook.txt`）**本机测不了**
  （TLS 握手被本地网络断掉），手机上是否可用要以真机为准；它需要重新部署（`bash tools/deploy_pages.sh`）
  才会带上这份新源。

## 五、源的实现要点

- **home**：`热门收听`（首页热门搜索 5 部）+ `最近上架`（12 部）。
- **categories / list**：19 个「题材」分类（站内搜索词）+ `热门收听（站内）` + `最近上架（站内）`；
  站方搜索上限 50 条且不分页，一页到底（`hasMore:false`）。题材顺序把「首条实测能播」的
  （悬疑/灵异/仙侠/相声/儿童）排在前面，免得第一下就踩到被锁的自建音频。
- **detail / chapters**：一次请求书本页解析书名/封面/作者/演播/状态/热度/简介 + 完整目录
  （剑来 5231 章、灵境行者 840 章），缓存 30 分钟，详情与目录共用。
- **content**：领会话 → `api_chapter.php` → 按 `lrts$` / `xm$` / http 三路分派；
  各自带对的 `Referer`（`m.lrts.me`、`www.ximalaya.com`、站点）。

## 七、已知限制

1. **自建音频那批（站内热门 + 新书，约占样本 16%）播不了** —— 站方把 CDN 锁给官方 App。
2. **懒人畅听那批只有免费章**（约样本 44%），后面章要在懒人畅听购买；源里抛可读文案。
3. 空书 + `null`（约样本 40%）没有内容；「最近上架」几乎全是这类新书。
4. 站点没有排序/筛选/分页，源里也不声明；搜索最多 50 条。
5. 完整解锁播放需要官方 App（`com.tsj.babala`）请求音频时的凭据；本机拿不到 APK
   （直链主机掐连接、蓝奏云文件页有 JS 挑战），留给以后。
