# 2026-11-04 八叉书库源（`comic/8csk.js`）

用户给的入口 `https://8csk.org/` + 发布页 `https://8csk.xyz/`。站点是「八叉书库」（8xsk 字站），
WordPress + `truyen` 小说主题的**成人小说站**，按**文字小说**交付（`mediaType: novel`、`content` 返回
`kind: text`），归漫画板块的「小说」分类。

| 项 | 值 |
| --- | --- |
| ID / 名字 | `8csk_comic` / 八叉书库 |
| 版本 | 1.0.0 |
| 板块 | comic（文字小说） |
| 分级 | 18+（`adultIds` + `content-ratings.json`） |
| 网络 | direct（19 个域名全实测直连 200） |

## 一、结构（逐页实测）

- **分类 9 个** `/booklist1…9`：长篇/综合/武侠/历史/都市/玄幻/女生/其他/现代。
  分页是「页号 − 1」：`/booklist1/1.html` = 第 2 页，末页 322（共 323 页）。
- **榜单 4 个**：`/latest` 最新更新、`/release` 最新入库、`/popular` 热门排行、`/completed` 完本，
  分页 `/latest/index_2.html`、`/popular/index_3.html`。
- **题材 30 个**：`/genre/{slug}/`、`/genre/{slug}/index_2.html`。站点**没有题材索引页**，
  这 30 个 slug 是从书页 `<a href="/genre/xx/" title="中文">` 反查出来的（人妻/熟女/教师/校园/巨乳/黑丝/母子…），
  抽测 `renqi`、`heisi`、`xiaoyuan`、`koujiao` 四个首条互不相同（`heisi` 只有 4 条、`koujiao` 16 条）。
  站点没有「分类 × 题材」的组合参数，**选了题材就按题材栏目浏览**（分类被覆盖），文件头与设置说明都写了。
- **搜索** `/e/search/index.php?keyboard={词}&show=title,writer,byr&searchget=1`，
  结果页带 `searchid`，翻页 `/e/search/result/index.php?page={页-1}&searchid={id}`。
  源里把 `searchid` 按关键词缓存 30 分钟；缓存冷时先搜一次拿 id 再翻页，不会把第 1 页当第 2 页返回。
- **详情** `/novel{id}/`：h1 + `.single_title`、封面 `img[itemprop=image]`（`img.8xsk.top`，webp 实测 200）、
  作者、分类 + `#题材`、观看数、更新时间、简介 `.desc-text`。
- **目录** `/novel{id}/?p=N`，每页 51 章。两个坑：
  1. 书页顶部还有一块「最新章节」（2 条、顺序相反），只认 `#list-chapter` 里的完整目录；
  2. 目录里掺了 `position:absolute;left:-99999px` 的**隐藏诱饵章节**（假章节号），必须跳过。
  目录本身从第 1 章往后排，源里保持原序（不做翻转）。
  抓取用 6 路并发：38 章的书 0.8 秒；1001 章的书（21 页）5.3 秒。
- **正文不在 HTML 里**：章节页内嵌一次性令牌，前端 `POST /conapi.php`：

  ```
  url(密文串) mobile=1 isk=1 novel={id} chapter={N} t={时间戳} n={随机串} sign={sha256}
  → {"success":"1","content":"……纯文本……"}
  ```

  本源从章节页抓这 7 个参数、立刻回放同一个请求（令牌按页生成、带 `t`，没法跨章复用），
  拿到纯文本正文。实测 book 50252 `chapter0` / `chapter500` 各 2295 / 2027 字，
  书 70933 第 1 章 4617 字；没有图片字、没有付费墙、没有登录要求。

## 二、域名与发布页

发布页 `https://8csk.xyz/` 列了 18 个域名，全部实测 200 且同内容（标题、首页字节数一致）：
`8csk.net/org/cc`、`bxsk.net/org/cc`、`bcshuku.com/cc/net`、`bcsk8.com/net/cc/xyz`、`bacsk.com`、
`baxsk.com`、`8xsk.net/info/xyz`。源里 `mirrors` 放前 10 个（`8csk.org` 是用户给的入口，排第一），
发布页做成设置里的「打开发布页（8csk.xyz）」按钮，不当镜像自动解析。

封面域名 `img.8xsk.top` 与站点分离；没有封面的书记录会 404，源里不做探活（App 有占位图兜底）。

## 五、限制

- 题材筛选会覆盖分类（站点没有组合参数）；题材只有 30 个（站内 slug 实际上有 86 个，其余没放）。
- 目录最多读 40 页（≈2000 章）；1000 章以上的书 `chapters()` 约 5 秒，属于目录量本身的开销。
- 正文令牌一次性，`content()` 必须是「先 GET 章节页、再 POST conapi」；站点改哈希/参数名会让
  正文接口失效（源里会报「没找到正文令牌」）。
- 隐藏诱饵章节只在目录里出现，源里按 `left:-99999px` 过滤，不会混进章节目录。
