# 2026-11-01 LXXLXX 换域名 + 海角源升级（1.1.0）

## 一、LXXLXX：截图里的「请求超时」不是源的锅

`LumeSource.home` 超时的根因是**站点改名换域 + 源站宕机**：

- `lxxlxx.com` 的 `zhx.` / `zhy.` 现在 **301 → `https://zhs.lxxxxlxxx.com`**（字母加倍的
  新域）；`www.` / `m.` / `zhs.` / `hk.` 这些子域的源站已经挂了，直接回
  **Cloudflare 522**（香港出口 20s 才回 522，本机 + 两个第三方代理都复现 → 全球源站不可达，
  不是本机网络问题）。
- 522 要等 20 秒，而 App 单次脚本调用预算只有 10 秒（`SandboxPolicy.defaultTimeout`），
  于是用户看到的是「请求超时：调用超时：LumeSource.home」，而不是站点错误。

1.0.1 的改动：

- `mirrors` / `defaultBase` 换成 `https://zhs.lxxxxlxxx.com`，旧 `zhs.` / `www.` 留作备用
  （源站恢复后旧域会 301 过去，等于自带跳板）。
- 每个请求套 **4.5 秒软超时**（`Promise.race` + `setTimeout`）：源站不回就立刻抛可读错误
  「站点 4500ms 内没响应…稍后重试，或到源设置换镜像」；
- 5xx（520/521/522/523/524/525/527）单独报「源站不可达」，并把失败记 60 秒，期间点重试
  立即返回，不再每次都等一轮；
- `contentCategory: adult` 补上（成人短片段子站）。

## 二、海角社区（haijiao.com）：源早就有，这次把它修成能看

`https://www.haijiao.com/home` 是 **Vue2 SPA**，数据全在 `/api`，响应是**三重 Base64**
（`JSON.parse(b64(b64(b64(data))))`）。仓库里已有 `sources/video/haijiao.js`（1.0.0），
匿名浏览完全可用，1.1.0 补的是三件事：

1. **播放不再直接报错**：站点对匿名请求 `/api/topic/att/<attachmentId>` 只回线路名
   （普通1 / 普通2 / VIP线路），`url` 全是空串，连标称免费的片 `can_play=false`。
   现在 `content()` 拿不到地址时返回 `{kind:'webplayer', pageUrl: base()+'/watch?id=<id>'}`，
   在 App 的网页视图里登录/用券后即可播放；配了账号或 Cookie 仍优先取原生地址。
   路由依据：`c3` 里 `$router.push({name:'videoWatch', query:{id}})`，`watch` → `videoWatch`。
2. **镜像/网络**：`www.haijiao.com` 实测直连 200（1.7s），`mirrors` 加 www，`network: direct`，
   去掉过时的「必须配代理」。
3. **首页不再两块一样**：1.0.0 的「推荐」其实是把第 1 页又拉了一遍；现在第二块取第 2 页
   并按 id 去重，标题「更多」。详情页在 `can_play=false` 时补一段「为什么拿不到地址」。

## 验证

- `node tools/lume-source-check.mjs sources/video/haijiao.js`：home / filters / categories /
  list / detail / chapters / content 全 ok（content = webplayer），
  真站点请求：`/api/video-center/video/list?page=1|2`、`/api/video-center/category/list`、
  `/api/video-center/video/detail?id=`、`/api/topic/att/` 全部 200。
- `node tools/lume-source-check.mjs sources/video/lxxlxx.js`：4.5s 内返回
  「站点 4500ms 内没响应」；紧接着的下一次调用瞬间失败（down 缓存 60s）。
  站点侧当前仍是 522，源站恢复后无需再改源。
- 双线路：`raw.githubusercontent.com` 与 `cdn.jsdelivr.net` 实下载与本地 sha256 完全一致
  （海角.js `E3181890…` / 27486 B / 1.1.0；LXXLXX.js `C4DF4AFB…` / 15149 B / 1.0.1）。

## 已知限制

- 海角：原生播放地址需要「登录 + 解锁（观影券/VIP）」，匿名只做浏览；解锁后的 HLS
  `EXT-X-KEY` 在站点播放器里还要过一层 wasm，本源没拿到过真实地址，未验证。
- LXXLXX：站点源站当前全球 522，只有源站恢复才能真正播放；本源只能保证「域名指对 + 失败快 + 说人话」。
