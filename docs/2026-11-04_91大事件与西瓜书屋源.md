## 一、91大事件（campus.ravwriau.cc / 91dasj.com）

- Typecho + Mirages 主题 + `tbxw`/DPlayer 插件，与 91吃瓜（`91cg1`）同族：
  - 列表：`/`、`/page/{N}/`、`/category/{slug}/{N}/`、`/tag/{词}/{N}/`、`/search/{词}/{N}/`
  - 卡片：`<a href="/archives/{pid}/">` + `.post-card-title` + `loadBannerDirect('封面')` + `.post-card-category`
  - 分页：页面里写「第 2 / 共 296 页」，直接拿来算 `hasMore`
- 用户给的 `campus.ravwriau.cc` 与页面 canonical 指的 `91dasj.com` 同内容、都直连 200 → 一个源 +
  `mirrors`（下标 0 = 用户给的入口）。
- 分类 12 个（今日吃瓜 / 热门吃瓜 / AI短剧 / 每日大赛 / 伦理猎奇 / 学生校园 / 网红吃瓜 /
  网黄吃瓜 / 反差女神 / 探花大神 / AV动漫 / 体育直播）+「往期内容」，**12 个逐个实测出内容、首条互不相同**。
- 筛选：站上 300 个标签里取 24 个常用词做成「标签」组（实测每个都换内容）；Typecho 标签页只吃单个词，
  多选取第一个。
- 排序：站点没有排序参数（`?sort=`/`?order=` 实测被忽略，只有发布时间倒序），**不声明排序组**。
- 播放：详情页每个帖子 1–3 个 `<div class="dplayer" data-config="{&quot;video&quot;:{&quot;url&quot;:…}}">`，
  `data-config` 解实体后就是原生 m3u8（`op.udhhzr.cn/videos5/{hash}/{hash}.m3u8?auth_key=…`）。
  实测清单 206 + `#EXTM3U`，不需要 Referer。多段视频全部展开成章节；没有原生视频的帖子转 `webplayer`。
- 封面：`pic.hdhwqx.cn` 的图是 **AES-128-CBC(PKCS7) 密文**（响应头写 `binary/octet-stream`，文件头
  `09 3d e3 b1`），key/iv 与 91吃瓜同源：`key=f5d965df75336270`、`iv=97b60394abc2fbe1`；
  源里用 `coverHeaders` 标 `aes-cbc-pkcs7` 交 App 原生解密。本机用 node crypto 解出真 JPEG（`ffd8ffe0`）。

## 二、西瓜书屋（www.xiguashuwu2.com）

- 老牌「simishuwu」系模板站，全静态 HTML：
  - 分类 `/category/{0-15}/{页}.html`（20 条/页）、筛选 `/category/{finish|vip}/{分类}/{页}.html`、
    榜单 `/rank/{all|week|month}/{分类}/{页}.html`、详情 `/book/{id}/`、
    目录 `/book/{id}/catalog/{页}.html`（100 章/页）、正文 `/book/{id}/{章节}.html`。
  - **分类 / 筛选 / 排序都实测生效且互不相同**：`category/7` 首条《青冥淫梦录》、
    `state=vip` 首条跳到 VIP 专列（`212108 小公主nph`）、`state=finish` 是完本列表、
    `sort=total/week/month` 走榜单页（首条 `56572 清纯婊被肏日常`，与分类默认不同）。
- **VIP 的处理（本站“有 VIP”）**：
  - 站方给 `isvip=1` 的书打 vipok 角标（书 1/2/3/212108…），页脚还挂了一句
    「想看 vip 章节请把书名发到 simishuwu@gmail.com」；
  - 实测正文**不做服务端拦截**：book 1（长日光阴）第 1/51/100 章、book 212108（小公主nph）
    第 1/51/100 章正文都在 HTML 里（每页 1.2–1.8 千字），没有购买/登录占位；
  - 所以本源把 VIP 书按普通书读，`detail` 里标注「VIP 书（本站 VIP 标记不影响阅读）」。
- 长章节会被拆成 `{章节}_2.html`（`_3.html`…）：`content()` 顺着「下一页」把分页正文接起来，
  实测 book 1 第 1 章 = 1209 + 889 字。
- **质量限制（如实记录）**：第二分页把敏感词渲染成 `<img class='hz' src="/wzbodyimg/{hash}.png">`
  （30×30 位图字，一页 189 处 / 61 个不同字）。文件名与字没有可推导关系（crc32 / md5 / sha1 / base62
  各版本都不符），站上也没有字典（`/wzbodyimg/` 无目录、无 json）。本源的处理是**跳过图片字**：
  第一分页与短章节完全正常，第二分页保留全部非图片字，读起来通顺，只缺那批露骨词。不伪造、不猜字。
- 搜索：`/search/{词}` 挂在 **Cloudflare managed challenge** 后面（列表/详情/正文都不受影响）。
  源里先试远端搜索，挡到就抛 `NEED_WEBVIEW_VERIFY`（App 会给网页视图过校验）；
  同时会把浏览过程中看过的条目写进本地索引（`index.json`，上限 600），过校验之前用本地索引顶着，
  真搜不到才抛错，不静默返回空。
- 交付形态：`mediaType: 'novel'`、`content` 返回 `kind: 'text'`，归漫画板块的「小说」分类。
