# 播放缓存改造范围

- auth：用户在本会话授权「全部修复和接入」，随后要求精简代码并增大现有参数。
- in_scope：LumeBox 播放链路、磁盘缓冲、下一集预载、设置和诊断；用户提供的四组猫源包只读分析；本机 HTTP 模拟验证。
- out_of_scope：修改第三方远端仓库、账号或服务器配置；提交下载的第三方源包及本机临时数据。
- network_profile：下载用户给出的公开订阅及对应脚本、配置、校验文件；回环测试服务器；GitHub 项目提交和推送。
- 后续授权：用户提供五个原始 PY 文件，要求修改 App 宿主适配，禁止修改源来迁就 App。纳入 Python 运行时及代理/弹幕/播放字段兼容和原样文件验证。
