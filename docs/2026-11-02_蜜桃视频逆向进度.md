日期：2026-11-02

## 一、真实站点与规模

`1mt8w.sbs` 会跳到 `1mth5.sbs` 系域名（实测渲染页地址为 `mtal8d.1mth5.sbs`）。
前端是自研 SPA（`oss.niuxiaodong.com/static/pb/*.js`，字符串数组混淆），数据**服务端注入 HTML**，
不在 XHR 里 —— 所以 curl 直取只有 8.6 KB 壳，浏览器却渲染出 321 KB DOM。

壳页里就是全部数据：

```html
<script>window.APP_DATA = [ {module:'text_link', data:[标签…]}, {module:'video_list', currentPage:1, totalPages:1089, data:[…20 条…]} ]</script>
```

实测各频道规模（20 条/页）：

| 频道 | 路径 | 页数 | 约条数 |
|---|---|---|---|
| 国产 | `/type/2` | 1089 | ≈ 21,780 |
| 日韩 | `/type/1` | 3339 | ≈ 66,780 |
| 网黄 | `/type/6` | 355 | ≈ 7,100 |
| 欧美 | `/type/3` | 443 | ≈ 8,860 |
| AI剧 | `/type/9` | 107 | ≈ 2,140 |
| 动漫 | `/type/5` | 79 | ≈ 1,580 |

合计约 **10 万条**，是这批国产站里体量最大的一个。

## 三、当前唯一的卡点：`sign`

格式：`<unix秒>-<5位随机>-<uid=0>-<32位md5>`

四组实测样本：

```
eab2eac3b26466a3  1793551333  bl6jh  0  f2ba767895ef460da8fa9382505b805a
6748c8d1a3c9973c  1793551339  4cfsw  0  fb9833df87a5404baa99a121aaf98edf
00c89251d200fac6  1793551344  xkbe4  0  2ce9fc28b85de6f6c3341c344ff9bda4
f53d15f64c715654  1793551350  g0gvt  0  f0b9a5f0e749f3cf8fb5f2124fda59ad
```

已排除 20 种"无密钥"模板（`md5(path)`、`md5(path+ts)`、`md5(ts-rand-uid-path)` 等全部不中），
说明 md5 里掺了**固定密钥**。密钥在混淆包里（`common.js` / `icons.js` 都是字符串数组 + 解码器，
静态搜 `sign` 只搜到无关噪声）。

## 四、下一步（可执行）

1. **动态拿栈**：在 Tabbit 里对 `HTMLMediaElement.prototype.src` 装 setter，或 hook `URLSearchParams`，
   播放时打印 `new Error().stack`，拿到生成 URL 的函数所在文件与行列。
2. **定位密钥**：按行列回读混淆包，找到 `md5(...)` 的入参拼装，取出字符串数组里的常量（可在页面里直接调用解码函数验证）。
3. **落地**：把 md5 + 拼接在源里用纯 JS 复刻（源沙箱无 crypto），`sign` 用 `Date.now()/1000` + 5 位随机 + `0` 现场生成。
4. 若密钥是**按会话/域名下发**，则改为"详情页 HTML 里已带 sign"再确认一次字段位置。
