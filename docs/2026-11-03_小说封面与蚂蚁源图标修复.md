# 爱丽丝书屋封面与蚂蚁搬运图标修复

2026-11-03。用户反馈爱丽丝书屋列表缺图、小说详情不显示封面，以及蚂蚁搬运源选择卡片没有图标。

## 原因与修改

- App：`NovelDetailPage` 原来只画标题、作者、简介和目录，没有封面控件，尽管 `detail.cover` 已存在。现接入按源绑定的图片管线和 SectionImage，透传 coverHeaders；详情图为空时回退列表封面，历史和收藏同步采用实际选用的封面。关闭页面释放自建管线。
- 爱丽丝书屋 1.1.1：列表页本身不提供图，需要补抓详情。原 1.5 秒超时对慢线路偏紧，批量等待也容易被慢项拖住。改为 6 个连续工作者、单请求等待 4.5 秒和总补图 6 秒预算；详情读取也写回封面缓存；图片解析兼容附加 class、包裹链接及懒加载字段。列表、详情、缓存命中均返回图片 Referer/UA。超过预算仍可能有条目没有封面，不伪造图片。
- 蚂蚁搬运 1.0.1：元信息未声明 icon，自动解析失败时退回“蚂”字。声明站点自己的 `https://www.antbyw.com/favicon.ico`，实测 HTTP 200、image/x-icon；不替换用户自定义图标。

## 验证

- 真实 QuickJS：详情响应延迟 1.8 秒、imgbox 附加 class、链接包裹和 data-src 的封面被正确回填；再次列表请求命中缓存并保留请求头。
- 小说详情控件：真实 PNG 经图片管线解码并显示；详情图优先和空详情回退列表图均通过；图片头未丢失。
- 封面和综合小说相关 Flutter 测试共 11 项通过，改动 Dart 静态分析无问题。
- 两源 lume-source-check 完整入口均通过。爱丽丝 latest/rank_month 首条分别 32013/53968；蚂蚁 all/少女首条分别 200719/200711，分类不是同一列表。
- 爱丽丝封面 HTTP 200、image/webp；蚂蚁 favicon HTTP 200、image/x-icon。
