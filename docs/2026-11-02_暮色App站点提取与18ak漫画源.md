# 2026-11-02 「暮色」App 站点提取与 18ak 漫画视频源

日期：2026-11-02 · 样本：`app-暮色-1.0.1(开发模式安装).ipa` / `app_暮色_1_0_1…安装.apk`
（`com.look.mbox`，versionName 1.0.1，Flutter + `package:avbox/*` 模块化打包，43 个站点图标）

## 一、怎么拿到站点清单（结论：不用抓包）

1. IPA / APK 都是 zip，直接展开：
   - APK：`assets/flutter_assets/assets/images/ic_app_<站点>.png`（43 张图标 = 43 个内置站）
   - Dart AOT 在 `lib/arm64-v8a/libapp.so`（10.75 MB）/ IPA 的 `App.framework/App`（11.63 MB）
   - `libapp.so` 里只有符号名是明文（`package:avbox/module/rryy/...`），
     **中文与域名都被编译进字符串池、且很多域名不落地**，静态 `strings` 只捞到 86 个 URL（多为广告/CDN）。
2. 真正的清单在**运行时**：App 首次启动会拉一份加密配置（`https://i.baf8.store/web1.txt` 等，
   2048 B 的 AES 密文），解密后写进
   `/data/data/com.look.mbox/shared_prefs/FlutterSharedPreferences.xml`，**明文**。
3. 做法：模拟器（x86_64，可 `adb root`）装 APK → 启动 → `adb shell cat` 那个 xml。

```bash
adb install -r app_暮色_1_0_1….apk
adb shell am start -n com.look.mbox/com.look.avbox.MainActivity
adb shell cat /data/data/com.look.mbox/shared_prefs/FlutterSharedPreferences.xml
```

> 附：frida 在这台模拟器上 attach 会 `agent connection closed`（Flutter spawn gating），
> 走 prefs 这条路反而更快；`BoxImageCache.json` 还能看到当时加载的图片域名。

## 三、已做成的源：18ak漫画·视频（`sources/video/akmh.js` v1.0.0）

协议（从前端 `assets/index-*.js` 的 axios 拦截器还原，再用真实响应验证）：

```
baseURL = /api
headers.timestamp = parseInt(Date.now()/1000)
headers.sign      = md5(timestamp + "api" + path + METHOD + "6F7A4DF7000C045C636B9123B11E4EC7").toLowerCase()
响应 {"code":200,"data":{"suffix":"<6hex>","data":"<base64>"}}
  key = "9a2d65b4a693ad0e40e5b156df25e406"（AES-256）
  iv  = "9a62e6977b" + suffix
  AES-CBC / PKCS7，base64 输入，明文是 JSON
```

接口：

| 接口 | 说明 |
|---|---|
| `GET /api/videoLists?page=&size=15&type=` | type 0=漫画改编(695) / 1=真人(836) / 2+=全部(1531)；size 服务端写死 15 |
| `GET /api/videoDetails?id=` | 上面字段 + `price` / `is_free` / `sales_num` |
| `GET /api/stacksCategories`、`/api/notices`、`/api/hotSearchBooks`、`/api/searchBooks?keyword=` | 漫画侧（本源未用） |

付费实测：`price=2、is_free=0` 的片，`videoDetails` 仍下发 `pay_url`（相对路径），
`base + pay_url` **200 + #EXTM3U**（分片 `010.ts`…），不需要登录/购买；
`preview_url` 只是 10 秒试看，做兜底。

沙箱没有 `crypto`/`atob`，所以 MD5 与 AES-256 都是源内纯 JS：
复用橙涩源的 AES 内核，把 `expandKey128` 改成按 key 长度取 `nk=4/6/8`，
并补 AES-256 特有的 `j % nk === 4` SubWord 分支；`aesCbcDecryptUtf8` 增加独立 iv 参数。

验证：

```
node tools/lume-source-check.mjs sources/video/akmh.js
  → PASS；home 3 块 / categories 3 / list 15 条 hasMore / detail / content
  → playable 200 + #EXTM3U（https://www.18akmanhua.com/comic-video/video/own/737/01.m3u8，624 B）
flutter test test/source_content_rating_test.dart → 3 用例全过（akmh_video 已登记 18+）
```

## 五、限制

- 各站加密协议**互不相同**（akmh 一套；mdtv/insav/aijav 各一套），没有「一个模板通吃」，
  只能一站一站逆；每站约 20–40 分钟（扒 JS → 还原签名/解密 → 写源 → 验证）。
- 域名会换：本源 `mirrors[0]` 是 `www.18akmanhua.com`（站点自称永久海外域名）。
- 视频没有站内搜索（`/searchVideos` 404），只有漫画有 `/searchBooks`。
