# 播放器与页面缓存

入口：设置 → 预载与清理；播放页 → 内核与网络 → 视频磁盘缓冲与下一集预载。

## 手动参数

| 参数 | 默认 | 设置页范围 |
| --- | --- | --- |
| 视频磁盘缓冲 | 1024 MB | 100～20480 MB |
| 当前视频预读 | 300 秒 | 5～3600 秒；播放页仍兼容原有秒数输入 |
| 播放缓冲内存预算 | 256 MiB | 32～1024 MiB |
| 下一集／音频目标预缓冲 | 15 秒 | 3～300 秒 |
| 片尾前触发预载 | 30 秒 | 5～1800 秒 |
| 进度触发预载 | 85% | 50～99% |
| 预载总预算 | 128 MiB | 16～2048 MiB |
| 首页与列表缓存 | 120 秒 | 15～900 秒 |
| 快进、快退步长 | 各 10 秒 | 分别设定 1～300 秒 |

预载总预算中，图片占一半，音视频各占四分之一。时长是目标上限，不会等待填满才起播。磁盘缓存统一作用于 AVPlayer、MPV、MDK、Aether 的网络媒体；空间不足保留回退机制。MPV/Aether 接收字节预算，AVPlayer/MDK 的预读主要按时长控制，预算不包含解码器、纹理等全部进程内存。

从播放页进入设置并返回后，当前集重新应用预读时长与内存设置；磁盘模式切换在重新加载资源时生效。下一集准备实例在策略变化后释放，按新值重新准备。

## 播放交互

- 进度条拖动期间只更新预览，松手后提交最终位置；本地画面横滑保留原有串行快定位策略。
- 预览优先使用源返回的 `thumbnails: [{time: 秒数, url: 图片地址, headers: 可选请求头}]`。源预览沿用图片管线、队列与缓存，停留 400ms 后才切换请求。
- MPV/MDK 可低频保存已解码画面：正常前台播放、无拖动、无缓冲、无 PiP、已知分辨率不超过 1080 高时，每 30 秒采样一次，最多保留 60 张、最长边 192 像素。切集清空。不为未知位置额外下载视频抽帧；无预览时如实提示。
- 长按全屏“下集”可查看解析、实际缓冲、实际分辨率与画质保持状态，也可正常重新解析下一集。播放信息里同样显示状态。
- 卡顿提示依据实际缓冲和输入速率区分可能原因；播放信息增加“保留进度恢复”。诊断是依据可用指标的判断，不把推测当作确定故障。
- 自动／硬解优先均允许内核兼容回退，软件兼容关闭硬解偏好。AVPlayer 不提供强制软解接口；实际解码器未由接口提供时明确显示未知。MPV 读取 `hwdec-current`。
- 默认仅 Wi-Fi 允许额外视频磁盘预读与下一集预载，蜂窝正常播放继续。网络定期检查，允许一个已发出的请求完成；内核正常播放所需缓冲不受此开关阻断。

## 整站复用

新增源响应短时缓存复用现有分板块内存缓存，覆盖 JS/PY 宿主及 Cat 的首页、分类、搜索、资料、目录和筛选结果，按源、参数、设置隔离。播放解析、章节正文和动作接口不进入响应缓存。页面响应缓存限于本次运行，不宣称离线首页或跨启动恢复。

相同所有者的相同读取合并；不同页面的取消所有权隔离。下拉刷新、搜索刷新和直播封面刷新绕过旧值；脚本释放、清理之后，晚到结果不会重新写回。较早已有的详情／目录缓存和筛选缓存仍遵循各自策略。

附近图片、下一页、阅读页和音频预载沿用原有实现。播放期间额外图片预载降为每管线一路，共享队列为可见图片保留名额。磁盘块的进度通知限频、LRU 淘汰和票据查找避免大缓存下反复全表扫描；预载设置异步串行落盘。
