# 2026-11-03 「4K影视」失效处理：源站已停站，改用 4k影视（4kvms 系）

真机现象：视频板块里叫「4K影视」的源打开只有一张空卡片——
「暂无首页推荐内容 · 这个源没有给出首页模块」。分类栏是
`全部 / 首页推荐 / 电视剧 / 电影 / 动漫 / 短剧`。

## 一、定位：这是 4kyingshi 那一条，站已经没了

按「分类名 + 站名」对号入座，仓库里唯一匹配的是
`sources/archive/python/4K影视-HTTP错误修复.py`（`fourkyingshi_python_video`，
站点 `https://www.4kyingshi.net`，CATES 就是 `首页推荐/电视剧/电影/动漫/短剧/综艺`）。

2026-11-03 复测：

| 探测 | 结果 |
|---|---|
| `https://www.4kyingshi.net/` | **403**（nginx/1.18.0，162 B；换 Baiduspider / Chrome / iOS Safari UA、换 UA 全量浏览器头、用 DoH 真实 IP 直连，全部 403） |
| `https://www.4kyingshi.com/`（`4kyingshi.net` 301 到这里） | **200 但只有 5.6 KB 的 `Redirecting…`**，脚本把 `{domainApex:"4kyingshi.com",tenant:"olive"}` 发去 `router.parklogic.com` —— 域名已到期、进入停放出售流程 |
| `https://www.4kyingshi.cc/` | 200 462 KB，但站内导航是 `欧美P站 / 原创AV / 网黄 / 猛料-SM / 成人综艺…`，是同名的**另一家成人站**，模板与 `/video/<id>/`、`/category/cateNNN/` 结构都不同 |
| 4kyingshi.org / .top / .vip / .la / .biz / .pro / .xyz / 4kys.* | 全不通（部分 302 到赌博域名） |

结论：**这条源没有可修的地方**——域名到期被停放，同后缀站点不是同一个站，结构也不兼容。
（原始 Python 源在 archive 里，已把状态说明改成「站点已停站」并标明替代源。）

## 二、处理：把可用的 4k影视（4kvms 系）升级到 1.1.0

仓库里另有一条同名但不同站的 `4k影视`（`fourk_video`，`www.4kvms.org` 等 9 个域名）。
2026-11-03 复测 9 个域名全部 200，首页约 700 KB、336 个 `/play` 链接 —— 这条是活的。
顺手把它升级，让它能顶替原来那条的内容面：

1. **分类改走真分页**：旧版把 `/movie /tv /anime` 当分类，那三页服务端只有固定一页
   （`?page=` 不生效）。现在统一走 `/filter?classify=N`：
   `1 电影 / 2 电视剧 / 3 动漫`，不带 `classify` 就是全量片库，**每页 30 条真翻页**
   （实测第 184 页仍有内容）。
2. **补筛选**：`/filter` 同一套查询串支持 `types=`（30 个类型）/ `areas=`（44 个地区）/
   `years=`（79 个年份），实测可组合。源里按站点原标签抓了常用子集（类型 21 项、
   地区 14 项、年份 10 项），组内单选，多选时取第一个（注释已写）。
3. **搜索**保留 `/search?q=`（实测「斗罗」2 条），仍带「先摸一次首页拿会话再重搜」的兜底。
4. **播放**不动：站点的播放地址由 `/static/wasm/nbmovie_wasm.js` 现算签名
   （`/video/play?p=&v=&q=&s=&t=&k=`），源里不复制签名逻辑，交给 App 的网页播放器。
5. 分类里**没有放「综艺」**：`/filter?classify=4` 目前返回 0 张卡（空表），
   按「空分类不拿别的顶替」的规矩不列。

## 四、用户要做的一步

失效的「4K影视」是手动导入的 4kyingshi 源，**删掉它**；订阅同步后
用 `4k影视`（1.1.0）。两者名字相近但不相关：前者站点已停，后者是 4kvms 系。

## 五、限制

- `4k影视` 的播放仍走网页播放器（分集在播放器里点）：站点签名在 wasm 里，
  没有可靠的免浏览器算法，源里不猜、不伪造地址。
- 综艺分类当前是空表，站方上内容后把 `CATS` 里补一项 `classify: 4` 即可。
