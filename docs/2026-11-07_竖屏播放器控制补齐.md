# 竖屏播放器控制补齐

- 窄屏全屏控制分成两排，保留播放、下一集、快捷记片头尾，并增加片头片尾设置和上滑切集开关；宽屏沿用单排布局。
- 非全屏控制栏增加下一集和片头片尾图标，窄屏允许换行。
- 将上滑切集设置从方向设置移至“手势与外观”，沿用原有设置存储和手势判定。
- 播放提示改成裁剪范围内的磨砂背景，减弱底色和描边，增加内边距；沿用提示替换与自动关闭逻辑。
- 修复字幕轨和外挂字幕入口在窄设置面板中的溢出。

验证：137 项播放器、横屏布局、设置分类和手势回归通过；补充 320/375 宽竖屏入口及开关切换断言。最终窄屏布局 3 项复测通过。`flutter analyze --no-pub lib test/player_full_feature_test.dart` 通过。全仓分析仍受未跟踪的 `work/` 临时预览文件报错影响。
