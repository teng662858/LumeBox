# 写源规则速查（新任务先读这一页）

> 目的：换新会话时不必翻聊天记录。详细版在 `sources/README.md` 的「源约定」、
> `docs/lumesource-guide.md`（契约）、`docs/源线路与专用设置.md`（设置/线路）；
> 本页是执行清单，冲突时以那三份为准。

## 0. 先确认的三件事

1. 站点属于哪个板块：`video`（视频/有声）还是 `photo`（图集）——`photo` 在 App 里导入漫画板块。
2. 有没有**发布页/地址发布页**（例如 `02.uno` 这种）：有就按第 4 节写进源设置。
3. 站点是否需要代理、是否需要登录、有没有 Cloudflare 人机校验。

## 1. 身份头（必写）

```js
// LumeSource: {"id":"<站名>_video","name":"站名","version":"1.0.0","category":"video",
//   "contentCategory":"adult","settingsApiVersion":2,"requiresSettings":["settingsActions"],
//   "mirrors":["https://主站","https://镜像1","https://镜像2"],"network":"direct",
//   "icon":"https://主站/favicon.ico"}
```

- `id`：字母数字短横下划线，≤64；`contentCategory`：`adult` / `movie`（18+ 必写 adult）。
- `network`：`direct`（实测直连可开）/ `proxy`（实测直连超时、RST、403 挑战）。
- `settingsApiVersion:2` + `requiresSettings` 只在真的用了 `settings` / `commonSettings` 时写。

## 2. 五个入口 + 两个可选

| 入口 | 要求 |
|---|---|
| `categories()` | 每个 id 都要在 `list({categoryId})` 里换成不同内容 |
| `list({page, categoryId, keyword, filters})` | 分页/关键词/筛选都要真的传给站点 |
| `detail({id})` | 找不到返回 `null`；标题/封面尽量真实 |
| `chapters({id})` | 视频=选集/线路；图集=一组 |
| `content({id, chapterId})` | `images` / `video`（可带 `qualities`）/ `audio` / `webplayer` |
| `home()`（可选） | 板块数组或平铺列表；`moreUrl` 会回传成 `categoryId` |
| `filters()`（可选） | 组内多选以逗号回传；站点不支持组合时取第一个并写注释 |

## 3. 镜像规则

- `mirrors[0]` = 主站（官方/首发域名），后面放**实测同内容**的镜像；每组最多 20 个，
  设置页首屏只列前 3 个、其余收在「更多镜像」。
- 官方公布但本机打不开的（DNS 污染/被墙）**可以进 `mirrors` 供手选，但不要进脚本自动解析路径**。
- 脚本里从 `LumeSource.config.domain` 拼 URL，用户换镜像/自定义域名不用改脚本。
- 换域名的站点：宿主会把 302 跟完，`reply.url` 是**最终地址**，所以可以让脚本「自发现」当前域名
  （典型做法：请求站方跳转/发布服务，取 `reply.url` 的 origin，再探活首页，成功就缓存 12 小时）。
  样板见 `sources/video/d9y1w.js` 的 〇·二 与 `discoverHost()`。
- 已知坑：`reply.url` 是 1.0.x 之后才有的字段，脚本仍要写兜底（读不到就退回种子域/已知镜像）；
  另外 http 跳转服务常见**证书过期**，能用 http 就别硬上 https。

## 4. 发布页 / 地址发布页

站点有发布页（换域名、备用地址、找回邮箱）时，写进源扩展功能，**不要当镜像**：

```js
settings: [
  { key:'publishPage', type:'action', action:'openWebsite',
    title:'打开发布页', url:'https://发布页/',
    description:'站点换域名时先看这里' },
  { key:'note', type:'info', title:'站点说明', description:'站点特性 / 限制 / 是否需登录或代理' },
]
```

App 会用一个按钮在内嵌浏览器打开它；旧版 App 忽略 `url`，退回打开当前站点，不会崩。

## 5. 设置声明：只在站点真有对应结构时写

- `commonSettings`：`pageSize` / `quality` / `imageQuality` / `playbackMode` / `searchMode` / `autoNext`。
  **写了就要在脚本里读 `LumeSource.config.commonSettings` 并落实**（`playbackMode` 由 App 裁决）。
- `settings`：≤32 项，`toggle/select/text/number/info/action`；`action` 走 `settingsAction`
  （≤8 个 `inputs`）或内置 `login/openWebsite/testConnection/clearCache`。
- `endpoints.images` / `endpoints.video`：确实有多个**可互换**的图床/CDN 才声明，App 按前缀替换。
- **不要假声明**：App 只校验格式/范围/能力，不验证脚本是否真的用了；假声明只会误导用户。

## 6. 沙箱与真机坑

- video/photo 沙箱**没有 `atob` / `Buffer` / `crypto` / 端口 / 进程**；加密自己写纯 JS
  （AES-CBC/GCM 都能跑），单次调用 3–5 秒 + 指令上限。
- 封面/图片：支持 `lume-enc://aes-ecb|aes-cbc/<key>[/<iv>]/<url>`（App 原生解密，明文可为
  `data:image/...`）；**站点返回 `data:` 文本 body 的地址不能直接当封面**，要换真图 URL。
- 只混淆了**开头若干字节**的图（Butterfly 系 App 把前 100 字节和 imgKey 循环 XOR）：在列表项上带
  `coverHeaders: {'x-lume-image-encoding':'xor-prefix','x-lume-image-key':'<key>'}`
  （长度不是 100 时再加 `'x-lume-image-length':'<字节数>'`）。同类还有 `reverse`、
  `strip-prefix-16`、`aes-ecb-base64`、`aes-cbc-pkcs7|nopadding|pkcs7-ivprefix`。
- 人机校验：抛 `NEED_WEBVIEW_VERIFY：...`（CF）或 `WAF_RECAPTCHA_V3：...`，App 会给网页视图过校验。
- 失败要抛可读错误，别静默返回空；空分类也不要拿别的分类顶替。

## 7. 18+ 要登记两处

1. App：`lib/core/source/source_content_rating.dart` 的 `adultIds` + `test/source_content_rating_test.dart`；
2. 源仓库：`metadata/content-ratings.json`（`sources` 里 `"rating":"18+"`，`evidence` 写站点性质）。

## 8. 验证（缺一不可）

```bash
node tools/lume-source-check.mjs sources/video/xxx.js                    # 五入口 + 播放探活
node tools/lume-source-check.mjs sources/video/xxx.js --call list \
  --category <A> --json   # 与下面一次对比：首条 id 必须不同
node tools/lume-source-check.mjs sources/video/xxx.js --call list --category <B> --json
flutter test test/xxx_source_test.dart        # 有快照时：真 QuickJS 跑五入口
dart analyze <改动文件>
```

- 复杂解析/加密的源建议配站点快照 + 原生用例（`snapshots/` 注册、`.sources-cache/` 本地缓存）。
- 封面要单独探活（200 + image/*），播放要探活（200 + `#EXTM3U` / mp4 206）。

## 9. 发布（App 仓库 + 源仓库都要提）

1. `cp sources/<板块>/xxx.js` → `D:\Zcode\LumeBox-Sources\<comic|photo|video|...>/<中文名>.js`
2. 源仓库：`python tools/build_catalog.py`（会更新 catalog / 订阅清单 / 源目录），
   `python tools/build_catalog.py --check` 必须 0 变化。
3. 源仓库 commit + push → GitHub Actions 会 purge CDN。
4. **实际下载两条线路核对**：raw 与 `cdn.jsdelivr.net` 的版本号 + sha256 必须与本地一致；
   jsDelivr 若仍返回旧版，手动 `https://purge.jsdelivr.net/gh/<repo>@main/<path>` 再等 1 分钟重试。
5. App 仓库 commit + push（源码、测试、README/文档）；交付时写提交号、验证结果、限制。

## 10. 交付时说什么

- 改了什么（站点结构 / 域名 / 解析点）；
- 验证结果（lume-source-check、原生用例、analyze、两线路 sha）；
- 提交号（两个仓库）；
- 限制（需要登录/代理、只能网页播放、分类白名单等）。
