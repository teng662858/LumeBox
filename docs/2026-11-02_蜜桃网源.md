## 一、这个站是怎么找到的

`mitaow50.com` 抓下来只有 27 KB、没有 JS、没有数据 —— 它不是内容站，而是**地址发布页**。
用 Tabbit 打开后页面文字直接摊开：

```
蜜桃网-线路一 admire.mdskbdjb.cc
蜜桃网-线路二 base.mdskbdjb.cc
蜜桃网-线路三 access.mdskbdjb.cc
蜜桃网-线路四 d2l6fc4s7txsb.cloudfront.net
找回邮箱 mitaow2026@gmail.com
```

真站 `admire.mdskbdjb.cc` 是**服务端渲染**的爆料站（title：蜜桃网-热点吃瓜、网红爆料与黑料视频合集），
数据不需要逆接口，页面里就带着播放器配置。

## 三、解析要点

1. **卡片**：`<a href="/archives/<id>/" title="标题">`，图片是 `z-image-loader-url="`https://…`"`（**值被反引号包着**，要剥掉）。
   一页里 `/archives/<id>/` 出现多次（同一张卡片的标题链接、评论数链接），必须按 id 去重。
2. **播放地址**：详情页
   ```
   <div class="videoplayer dplayer" data-config='{"video":{"url":"https://hls.ohjzmm.cn/videos5/<hash>/<hash>.m3u8?auth_key=…&v=3&time=0","type":"hls"}}'>
   ```
   取出 `data-config` → `JSON.parse` → `video.url`；解析失败还有一条正则兜底。
3. 签名 m3u8 带 `auth_key`，**带 `Referer: https://admire.mdskbdjb.cc/` 才能播**（实测无 Referer 会被 CDN 拒）。源里已带。

## 五、发布

- 源仓库：`video/蜜桃网.js` + `metadata/content-ratings.json`（`mitaow_video: 18+`），`build_catalog.py --check` 0 变化。

## 六、限制

- 9 个分类只有首屏 40 条（站点没有分类分页），要翻只能走「今日更新 / 热门」列表。
- 三个主域 + 一个 CloudFront 镜像同一套站；换域名时改 `DEFAULT_DOMAIN` 或走源设置里的自定义域名。
- 封面与播放都在 `pic.gyezbp.cn` / `hls.ohjzmm.cn` 上，若 CDN 换域需要重新抓详情页确认。
