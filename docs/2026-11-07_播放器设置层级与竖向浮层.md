# 播放器设置层级与竖向浮层

播放设置采用“分类首页 → 分类详情”：打开时只列播放与画质、片头片尾、画面与显示、声音与字幕、弹幕、手势与外观、内核与网络。详情顶部提供返回分类和关闭入口；系统返回优先回到分类，分类首页保留滚动位置。移除横向分类标签、重复快捷栏和详情中重复的分类标题。

播放弹窗的标题 15、正文 14、分组标题 13、说明 12，保留系统字体缩放。分类行最小 48，左右留白 16，统一分隔线、数值与开关对齐；详情使用完整列宽。移除播放器临时控制区和主要设置区的嵌套卡片，说明使用较轻字重。全局设置继续由外层唯一滚动视图承载。

倍速与内核共用 144 宽的竖向矩形浮层，圆角 12、内边距 6，选项等宽垂直排列，当前项高亮，选择后关闭。倍速保留 0.25–4 倍完整档位，浮层最多高 280，超出可滚动；不可用内核禁用并保留原因提示。菜单滚动不占用宿主的主滚动控制器。

验证：130 项播放器、设置导航、全局设置、内核、面板和倍速相关测试通过；横竖屏及 1.3 倍字体覆盖分类进入、返回和设置保留，相关静态分析通过。Android x64 隔离预览构建成功；iOS 18 原生显示效果仍需真机核对。本次未修改源或订阅。

后续按用户要求进一步收紧倍速及内核浮层：内容宽度 144 → 128，外边距 6 → 4，选项上下留白 2 → 1，并使用紧凑选项密度。补充四个内核总内容高度不超过 160 的断言；99 项内核及播放器回归、相关静态分析和 Android 预览构建通过。
