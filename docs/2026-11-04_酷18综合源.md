## 一、站点结构（实测）

老式论坛，**进门先过年龄门**：`/index.php` 只返回 1.3 KB 的「成人内容验证警示」，
`/index.php?isok=true`（或带 `Cookie: isok=true`）才进站。源里所有请求都带这个 Cookie。

**列表数据是页面内联 JSON**：

```js
const _PageData = [{"tid":"14639551","rootid":"0","uptid":"0","uid":"...","username":"不冷心",
  "subject":"【穿越了我就是神】（38-40）龙椅旖旎[原创]","dateline":"11\/04\/26","size":"72046",
  "country":"原创","type":"original"}, …];
```

一页 150~261 帖，直接 `JSON.parse` 就行，比解析 HTML 稳。

**排序（三档，都实测换内容）**
- 最新：`/{板块}/index.php`（`_PageData`）→ 201 条
- 热门：`/{板块}/index.php?app=forum&act=hot` → 100 条榜单表（`<td class="title-col">` 里
  `标题 - 作者 (12345 bytes) <i>日期</i> (70377 reads)`）
- 精华：`/{板块}/index.php?app=forum&act=gold` → 200 条

**筛选 / 搜索**
- 全成人区搜索：`/search.php?keyword=xx&sa=全成人区搜索` → 跨板块 200 条，
  结果结构 `<li><a href="…/{板块}/index.php?…tid=NNN"><p>【板块】</p><p>【标题】…</p></a></li>`
- 板块内：`/{板块}/index.php?action=search&bbsdr={板块}&act=threadsearch&app=forum&keywords=xx&submit=查询`（兜底）

**正文**
```
<div class="post-content">
  <div class="content-section" id="content-section">
    <pre> …文字用 <p></p>/<br> 分段，图片是 <center><img src="https://img.xwbo.com/…"></center> … </pre>
    <div class="view_ad_incontent">广告</div>
```
- 文字帖：`<p></p>`、`<br>` 折行，去标签（实测一篇 **21694 字**）
- 图片帖：收集 `<img src>`，跳过站内资源/图标/广告域名，给 `imageHeaders` 带 Referer（实测 **54 张**，
  playable 探测 `https://23img.com/i/2026/11/03/xuu1uu.jpeg` 200）
- 成人影视：正文是 `.login-container` 登录框 + 一个广告 iframe → 源里直接抛
  「成人影视板块的播放页要求登录」，不假装能播
