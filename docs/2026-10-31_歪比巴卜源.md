2026-10-31 · 源文件 `sources/video/wbbb.js`（id `wbbb_video`，v1.0.0）

## 一、站点与入口

地址发布页 `https://www.xn--clr79vmzkema.com/`（歪比巴卜.com）给出 3 个节点：
`wbbb1.com`（主线路）、`v.wbbb1.com`、`www.wbbb1.com`，三者同内容（首页 93.6–93.7 KB）。
站点是**苹果CMS v10 + 自定义主题**，服务端渲染，`dart run tools/site_reachability.dart`
实测 Dart 直连 200 → `"network":"direct"`。

| 用途 | 路径 | 实测 |
|---|---|---|
| 栏目 | `/show/1-----------.html` … `/show/4-----------.html` | 电影/剧集/动漫/综艺，各页 72 张卡 |
| 翻页 | `/show/{类型}--------{页}---.html` | 第 2 页首条 116170 ≠ 第 1 页 116031（真分页） |
| 详情 | `/detail/{id}.html` | 标题、封面、简介、9 条线路 × 最多 41 集 |
| 播放 | `/vplay/{id}-{线路}-{集}.html` | 每集一页 |

## 二、三道槛

**1）首访 403（Cookie 门）**
任何页面第一次请求返回 `403` + `Set-Cookie`，页内 JS 再跳回同一地址才 200。
源里 `fetchHtml()` 遇到 403 自动重发一次（宿主会带上 Cookie），与浏览器一致。

**2）播放地址由站点前端现算，本源不复制**
`/vplay` 页只给 `player_aaaa.url` 的密文，真地址要由页面 JS 生成
`api.php?url=<密文>&key=&vkey=&ckey=` 再请求，签名逻辑在混淆后的
`/player/artplayer/js/setting.js`（jsjiami v7，338 KB）里，解析服务是第三方域名
`哈喽.850088.xyz`。

本机实测（headless Chrome + CDP 逐条探）：
- 抓到的请求形如 `POST https://xn--qvr2v.850088.xyz/player/api.php`，
  body = `url=<密文>&key=…&vkey=…&ckey=…`；
- **推荐（abc）/ 蓝光4K（wbbf）/ 蓝光I（wbbI）/ BF有广（bfzym3u8）四条线路，api.php 全部返回
  `{"code":404,"msg":"解析失败"}`** —— 本机出口被该解析服务限制（站点播放器在用户自己的网络里正常）；
- 顺带确认：`s` 类签名参数不可复用（改一位即失败），所以本源**不去猜播放地址**。

→ 交付形态：`content()` 返回 `webplayer`，打开源站的**详情页** `/detail/{id}.html`。
该页就是站点自己的选择界面：上面一排线路（蓝光A / 高清C / 蓝光I / 蓝光4K…，带集数），
下面一整格分集——用户在 App 里点开就能像浏览器一样换线路、选集；
某条线路「解析失败」时换一条即可（这正是站点自己的提示）。

`chapters()` 只给一项，标题里写明「N 条线路，最多 M 集」：因为线路/集数都不在 URL 里，
给假的深链反而会点错集。

**3）站内搜索被 WAF 拦**
`/search/<词>-------------.html` 返回「系统安全验证」页；`/index.php/ajax/suggest` 直接 403。
本源改用**本地索引**（`index.json`）：浏览过的条目会被记住，搜索时在索引里过滤；
索引为空时先抓一页灌进去。不伪造搜索结果。

另外站点对高频访问会短时 **429**（本机连续测 10+ 次时出现，冷却 60 s 后恢复），
源里把 429 变成可读错误，不静默返回空。

## 四、限制

- **播放走网页播放器**：不产出直连 m3u8；线路/集数在站点页面里选。
- **搜索是本地索引**：只能搜到浏览过的条目（站点搜索被 WAF 拦）。
- **站点限流**：连续请求会 429，冷却是分钟级；本源每次调用只发 1–2 个请求。
- **首访 403 门**：首次请求失败属正常，源里会自动重试一次。
- 站点有成人分区（独立入口），本源只做公开影视栏目，`contentCategory` = `movie`。
