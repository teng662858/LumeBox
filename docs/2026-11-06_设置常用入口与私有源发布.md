# 设置常用入口与私有源发布

- 常用入口允许 1–4 项，选择顺序由用户控制；既有选择和顺序不自动重排。
- 偏好文件恢复最多保留四项，修复只改界面后第四项在重启时被截断的风险。
- 四个常用按钮使用现有 FrostedGlassWidget 原生材质底座。iOS 26 用 UIGlassEffect，iOS 18–25 回退系统磨砂；Android 回退 Flutter 半透明材质。未改动最低 iOS 18 目标。
- 复用现有原生组件；文字、图标及点击仍由 Flutter 绘制，不将 Android 截图表述为 iOS 原生材质验收。
- 设置专项 40 项测试通过，覆盖四项显示、取消不保存、四项偏好恢复及窄屏/大字号；完整 lib/test 静态检查通过。
- 已构建、安装并打开 Android 虚拟机的隔离预览。预览使用正式设置组件，演示四项布局，不写入手机或正常运行目录中的用户偏好；预览文件、截图和 APK 不提交。
- 用户确认源仓库保持私有，后续使用 App 私有 GitHub 订阅。9 个源脚本及目录/订阅清单共 13 个文件已通过授权 Contents API 下载，与提交中的 Git blob 字节及 SHA-256 一致。公开 CDN 工作流被跳过，不声称双线路发布完成。
