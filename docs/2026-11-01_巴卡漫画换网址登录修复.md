# 2026-11-01 巴卡漫画 2.2.1：换网址后阅读仍提示登录

## 原因与修改

2.2.0 的正文、搜索和登录请求读取 `__host` 或硬编码主站。`config.domain` 只有 404/502 后的探测会读取，因此源设置换到新域名并登录后，重新进入阅读仍可能请求旧域名。

2.2.1 所有请求入口先同步用户选择的域名；配置未变化时保留已成功的备用线路，切换配置后立即切换请求地址。登录重试标记包含域名，旧域失败不阻止新域登录。旧收藏或章节中的绝对地址也转换到当前域，正文图片 Referer 随之更新。Cookie 仍按域隔离，不跨域复制；自定义未知站点仍不自动提交账号密码。

## 验证

- Node 16 项回归通过：首次直接阅读、旧绝对章节地址、列表/搜索/详情/章节/正文、换域登录、失败重试、Cloudflare、购买权限和自定义域名限制。
- App 真实 QuickJS + 宿主 HTTP 桥回归通过：主站切换至镜像后直接阅读、登录、搜索及图片 Referer 均使用新域。
- `dart analyze test/bakamh_domain_test.dart` 通过。
- 源仓库 `python tools/build_catalog.py --check` 零变化；生成器保留 README 已有发布记录，避免更新目录误删历史说明。
- 线上匿名探测主站返回 Cloudflare HTTP 403，正确提示网页验证；没有使用用户账号实测购买章节，登录/购买限制未改变。

## 更新方式

更新现有订阅中的巴卡漫画至 2.2.1，在源设置选定网址后保存，在同一网址登录并重新进入章节。版本不再依赖先请求旧站失败才能采用新网址。GitHub 与国内 CDN 的实际下载版本和 SHA-256 在发布后核对。
