# 播放功能核对与补齐

本轮补齐历史离线续看、下一集弹幕预载、小窗下拉全屏、源编辑 AI/文件导出、HLS 标记广告过滤与播放 AI 诊断；保留已有 JS/Python 源弹幕契约。修改适用于新版 App，最低系统仍为 iOS 18。

## 功能与入口

| 需求 | 原有状态 | 本轮结果与入口 |
| --- | --- | --- |
| 缓存视频从历史观看 | 下载中心能播放，历史仍需源在线 | 视频历史与「继续看／读／听」优先查找完整下载；下载中心播放携带作品身份写历史 |
| 源内自带弹幕，如摸鱼 | JS `danmaku` 与 Python 播放结果 `danmaku`/`danmu` 已支持 | 继续使用已有 XML、JSON、内联弹幕解析；不宣称已实站验证某一摸鱼源 |
| 详情小窗下拉全屏 | 仅全屏按钮 | 页面内播放器中间区域下拉超过 72 逻辑像素进入全屏，两侧仍调亮度/音量 |
| 短剧下一集预载含弹幕 | 只预载媒体 | 视频预载解析完成后并行加载源弹幕、尝试匹配公共弹幕；切集复用内存缓存 |
| AI 修 PY 与导出源 | JS 编辑/复制，源菜单仅复制导出 | 源菜单「编辑 / AI 修复」进入；源工具可打开 JS/PY、AI 修复和文件导出 |
| 跳过 m3u8 插播广告 | 无清单广告处理 | 「预载与清理」开关默认开启；播放代理、新下载都处理明确广告区间 |
| 播放 AI 诊断 | 规则诊断与复制 | 播放信息 → AI 诊断；共享全局翻译 AI 接口、模型、钥匙串密钥 |

## 使用边界

- 离线命中按源 ID、作品 ID、章节 ID 精确匹配，文件不存在时走原有在线流程。只播放完整下载；完整 HLS 即使合并失败也可通过本机 HTTP 播放。临时磁盘缓冲不等于完整离线下载。
- 新下载记录章节索引，旧下载记录缺索引时沿用默认值；匹配离线文件使用章节 ID，不受影响。
- 弹幕预载受现有预载开关、网络策略和触发条件控制。弹幕失败不阻塞视频，也不保证每集均可匹配公共服务。
- 广告过滤只移除成对 `#EXT-X-CUE-OUT`/`#EXT-X-CUE-IN` 之间内容；直播、加密、初始化映射、字节范围、主清单及无完整标记的清单不改。正常转场与跨域分片不作为广告依据。过滤会缩短媒体时间轴，外部弹幕可能需要手动偏移；可关闭并重载。
- AI 操作需先配置兼容 Chat Completions 的 HTTPS 接口、模型和密钥。用户点击发送才提交所展示内容；播放诊断不提交播放 URL、请求头和凭据。修源会提交当前脚本全文，发送前可展开检查。
- AI 修复只是草稿，采用后仍需导入校验及实际站点验证；未使用真实付费 AI 服务做在线验收，也未在本机完成 iOS 真机/IPA 构建。
- 没有修改任何站点脚本和订阅，不涉及源仓库发布或可见性变更。SourceMaker 本地已有改动不纳入本轮提交。
