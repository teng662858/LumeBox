## 一、乐成漫画（lcmhx.cc）

Nuxt2 SSR + hanime 模板的成人站（漫画 + AI 成人短剧）。

- 导航分类：`/mctype/{5,6,7,8,10..18,21..24}/`，其中 **5 = AI成人短剧**，其余是漫画 / 图集 / Cosplay。
- 列表 `/mctype/5/`：每页 28 条，卡片 `<a href="/lcmh-{id}/">…<img title="标题">…<div class="hv-title">`。
- 详情 `/lcmh-{id}/`：`<title>` 是「标题 - 乐成漫画」；页内
  `<video data-hls-src="https://s.chigua.media/hls/{id}/index.m3u8" data-fallback-src="…mp4">`。
- **取流要绕防盗链**：`s.chigua.media` 直连一律
  `403 Forbidden — The referer has been blocked`；站点自己的代理 `/media.php?url={encodeURIComponent(m3u8)}`
  实测 **206 + application/vnd.apple.mpegurl + `#EXTM3U`（2302 B）**，
  清单里的分片也是 `http://www.lcmhx.cc/media.php?...seg000.ts`（App 会把 http 升 https），
  分片实测 **200 + video/mp2t + 901,084 B（头 `47401110`）**。源里对 `data-hls-src` 统一走这个代理。

## 二、为什么只做了短剧频道（漫画没做）

站点漫画阅读页的图全部来自 `img5.qy0.ru`（如 `/data/2589/37/107_i_107.jpg`），
本机出口对该域一律 `403 · 鏈接已失效`（同域的封面域 `t4.qy0.ru` 正常返回 webp）；
试过加 Referer / Origin / 站点 Cookie、试过站点 `media.php`（回 `403 Host not allowed`）、
`media2.php`/`img.php`（404）——都拿不到图。写源规则要求封面/图片要实测 200 + `image/*`，
拿不到就**不写进源**，所以本源只覆盖已验证的短剧频道，并在设置说明里写清漫画分类没做的原因。

## 四、次元姬（ciyuanji.com）：本次没有交付（附证据）

```
GET /                                        → 200，Next.js（_next/static）SSR 外壳
GET /bookDetails?params=pXk5sagxDKLqnbDwPVpspwn3TIpv%2FkTv
                                             → 200，但页面里只有站点 SEO + 推荐位
GET /api/book/detail | /api/book/getBookDetail → 404（Tomcat 404 页）
```

- 书的 id 是 **24 字节的不透明参数**（`pXk5sagx…` base64 解出来是 24 B 二进制），不是数字 id；
- `__NEXT_DATA__` 里只有 `recommendRegionList` + `seoPage`，**没有书籍内容**：
  `pageProps` 只有推荐区，书籍详情 / 目录 / 正文全靠客户端再请求某个接口；
- 站内 JS chunk 直接 GET 会返回 SPA 外壳 HTML（100,672 B，与首页同字节），拿不到 bundle，
  也就没法从里面找接口地址与参数加密用的密钥；
- 首页还把「下载 APP」作为主入口，网页端内容明显是二等的。

要把次元姬做成源，需要先解决：① 拿到 app/网页真正的 API 域名；② 逆出 `params` 的加密方式；
③ 拿到正文接口。这三步在网页侧都没有可验证的入口，所以本次不发布，也不猜接口。
