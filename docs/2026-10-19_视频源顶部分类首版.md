# 视频源顶部分类首版

本轮优先交付可安装的 iOS 包，T4 暂缓。视频首页仍使用原来的内容浏览、详情和播放器；单个切换按钮打开顶部分类抽屉：全部、普通、猫源、PY、模块、网页。

普通源显示原有 JS 源，猫源按订阅包分组。搜索支持源名和订阅包名，名称最多显示两行，保留完整名称提示。卡片默认两列，窄屏或大字体降为单列，支持长按排序和源设置。

视频页内部可以切到猫源内容，再切回普通源；记录、收藏、订阅和源 ID 仍使用原有存储。记住视频页上次使用普通源还是猫源。原猫源底部入口保留，避免本轮同时迁移导航配置。

PY、模块、网页分类及添加入口先展示明确的未接入状态；没有 Python 运行环境，不接受导入并伪装成可播放源。没有新增 T4 支持。

随包包含当前工作区此前完成的图标、首页布局、漫画顶栏与朗读修复；内置离线语音包继续沿用资源分片。

本地验证：静态分析无问题；新增分类、搜索、选择返回及 320/390/768 宽度和 1/2 倍字体测试通过，相关视频与原源选择器回归通过。iOS 真机安装和实际站点播放需用产物验收。
