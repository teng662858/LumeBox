# 新增源：狂人之家书屋（crazyhome2000.com，2026-11-10）

用户给的 `https://www.crazyhome2000.com/`，站点标题「狂人之家书屋」（`<title>home - 狂人之家书屋</title>`）。
WordPress + 阁楼主题的成人文学站，免登录、直连可开，本机无 CF 人机页。

## 1. 站点结构（关键）

站点把「书」和「章」拆成两层，这是写源前必须先看懂的：

| 概念 | 站方形态 |
|---|---|
| 书 | 一个 **post_tag**，地址 `/tag/<书名>/`，标签页按发布**倒序**分页（每页 ~35 条，`/tag/<名>/page/N/`） |
| 章 | 一篇 **post**，标题常写成「书名 63.22-63.29」（一篇含数章），正文在 `entry-content` |
| 分类 | 10 个小说分类 + 「AI美图共享」图集，`/category/<slug>/`（`/page/N/`） |
| 书库 | `/tag-page/` 是标签云，按篇数从多到少列全部 8890 个标签订阅；点进去就是书的目录页 |

实测规模（2026-11-10）：

- 标签（书）**8890** 个，REST `/tags?per_page=100` 共 89 页；篇数前列：系统帮我睡女人 171、赘婿的荣耀 165、超级英雄恶堕中心 156
- 分类篇数：玄幻世界 9080、都市生活 8904、红杏出墙 8339、家庭伦理 7103、暴虐世界 3456、古风小说 3154、校园师生 2698、浪漫纯爱 1311、摄心控制 1285、乡村野趣 699、AI美图共享 20

## 2. 为什么不扒页面而走 REST

站方 WordPress 的 `/wp-json/wp/v2/{posts,tags,categories,media}` **完全开放**（实测 200 JSON，
无 nonce、无鉴权），比扒主题 HTML 强很多：

- `/posts?tags=<id>&per_page=100&_fields=id,title` 一次 100 章（一页 HTML 只有 ~35 条，还要 5 页）
- 正文 `content.rendered` 里**没有广告位/推荐位**；页面版正文前后夹着书签小部件和站尾版权
- `?search=` 在标签接口上直接按**书名**搜索，比全站文章搜索更贴合「找书」
- `/media?include=` 批量把特色图 id 换成真地址，图集分类才有封面

所以源里所有请求都走 `domain + /wp-json/wp/v2/...`，一处解析（`api()`）统一处理状态码。

## 3. 源里的映射

- **categories()**：`最新更新`（全站文章）、`全部书库`（按篇数排的标签）、10 个小说分类、AI美图共享，共 13 项。
- **list()**：
  - 关键词 → `/tags?search=<词>`，直接出书
  - `all` → `/tags?orderby=count&order=desc`
  - `latest` / 数字分类 → `/posts?...&categories=<id>`，一页 30 篇里按 tag 去重后翻成书；
    文章只给 tag id，书名用 `/tags?include=...` 一次补齐（30 个 id 一个请求）
  - 翻页用响应头 `X-WP-TotalPages`；超过总页数时 WordPress 回 **400**
    `rest_post_invalid_page_number`，源里按空页处理（不是报错）
- **detail()**：`/tags/<id>` 取书名/篇数，再取**最近两篇**文章：作者在正文首行
  「书名 作者：X」里，早期文章没有这行，所以取两篇往下找；分类从 `categories` 映射成中文名。
- **chapters()**：`/posts?tags=<id>&per_page=100&orderby=date&order=asc`，最多 6 页（600 篇，
  实测最大 171 篇）；标题去掉书名前缀，剩下的就是「63.22-63.29」这种章段。
- **content()**：`/posts/<id>?_fields=...,content`，取 `content.rendered` 的 `<p>` 段落，
  丢掉书签小部件的登录文案（用户名/密码/记住我）、「显示更多搜索结果」、版权行与「只限年满18岁」警告，
  首行「书名 作者：X」与详情重复也去掉；图片 ≥3 张且正文很短时按图集返回 `kind:'images'`。
- **home()**：两个板块 —— `热门书库`（篇数前 12 的标签）、`最新更新`（24 篇文章去重后成书）。

站内 ID：`t:<tagId>`（书），章节 ID 用 post id。

## 4. 封面

- 小说章节 **featured_media = 0**，站方列表页也不给小说封面，所以小说书条目**没有封面**（不编造）。
- 只有「AI美图共享」的帖有特色图（如 `uploads/2026/11/stocking.webp`），源里用
  `/media?include=<ids>&_fields=id,source_url` 批量换真地址；实测图床 `www.cool18.cc`
  无 Referer 也返回 200 `image/webp`。

## 6. 限制

- 站点章节编号本身有跳号/错位（例如《赘婿的荣耀》最后一篇是 18.1-18.21，发布在最晚），
  源按站方**发布时间升序**排列，不按标题里的数字排序（站方自己就这么发）。
- 小说没有封面；列表/详情按标题展示。
- 没有排序/筛选（站方只有分类、标签、搜索），源不声明 `filters()`。
- 一本书最多取 600 篇（6 页 × 100）；实测最大 171 篇，正常书远低于此，超出部分不显示。
- 站方 REST 全开，若以后加 nonce/鉴权或关闭 REST，需要改回页面解析。
- 成人内容：App 侧按 18+ 归档（`crazyhome_novel` / 名称「狂人之家书屋」）；
  源仓库 `metadata/content-ratings.json` 已登记。
