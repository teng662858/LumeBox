# Python Spider 后台流服务兼容

用户提供菠菜园.py、红果修复版.py，目标为适配原有 TVBox/hipy Spider 宿主。原文件保留在用户桌面，本轮未把第三方源代码打进 App。

## 修复

- CPython 原生回调按仍加载的来源校验，支持 playerContent 返回后继续运行的后台 HTTP 处理线程；释放或载入失败后撤销该来源。
- 后台线程沿用所属源的上下文，单次网络/宿主请求最多30秒，不复用已结束的 playerContent 截止时间；前台仍保留独立 CPU/调用预算。
- 跟踪源创建的 HTTPServer/ThreadingHTTPServer，释放或重载时关闭服务，避免旧端口与后台服务残留。
- 检查器额外验证本地 MP4 流在原调用预算结束后仍可读取第二个 Range 区间。iOS 原生烟测增加 lzma 解压往返。

## 验证与限制

- 生产 Python 宿主离线回归含真实本地206服务、后台跨调用请求、来源隔离、释放关闭；Dart通道/首页/导入测试通过。
- 红果实站4分类、27首页项、24列表项、470选集读取通过；首段和1MiB后续片段均206，后者1024字节且Content-Range匹配。
- 菠菜园33分类、首页/列表/详情/选集/播放解析通过；本次抽样播放URL由上游返回403，不能把宿主兼容等同所有资源可播。
- 源对其他客户端127.0.0.1:9978/action的弹幕推送不是LumeBox弹幕接口，当前仍使用App自己的弹幕服务；未声称该私有推送接口已接入。
- 本地Windows回归不等同iPhone实机验收。iOS目标保持18.0，原生改动需安装新版App生效。
