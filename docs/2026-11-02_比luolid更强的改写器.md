# 比 luolid.conf 更狠的改写器：从「去广告」到「三层接管」

2026-11-02 · 分析对象 `89996462/Quantumult-X/ghs/luolid.conf`（萝莉岛：去广告 + 金币/VIP 线路）
本文给出更完整的方案与可直接落地的脚本骨架，并在本机用站点同款算法跑通了加密/重签闭环。

## 一、先说清楚 luolid.conf 的天花板

拆开看，它就是两件事：

| 文件 | 干的事 | 手段 |
|---|---|---|
| `luolidad.js` | AES 解密响应 → 删广告字段/宫格 → 按同算法重加密 → 重算 `sign` | `AES-128-CBC(key=iv=salt=6c3a9ad53fae2796)` + `sign = md5(sha256("_ver=v1&data=..&timestamp=.." + salt))` |
| `luolid.js` | 播放请求只换 host（`→ d39jna88gmha0l.cloudfront.net`），弹通知让用户点开 | 写死一个 CF 域名 |

短板很明确：

1. **只清广告，不动权限**：`is_vip / need_coin / price / is_locked` 一个没改——「解锁金币视频」实际是靠第 2 个脚本偷出来的播放地址，不是真解锁。
2. **只认一个 CDN**：那个 CF 域名一换/一挂，整条链路就死；也没有探活。
3. **无兜底**：解密失败、字段结构变了、`sign` 算法变了，直接 `$done()` 或抛错，页面白屏风险。
4. **不处理媒体层**：m3u8 里的分片、子清单不接管；也不管多清晰度、不外带会话头。
5. **单点写死**：没有开关、没有去重、没有日志，改一次要重发一份脚本。

## 二、更强方案：三层接管 + 一层反检测

```
① 响应层：解密 → 广告 + 权限字段双补丁 → 重加密 → 重签（并自校验）
② 媒体层：从明文里收割所有 m3u8/mp4（含嵌在文本里的），多 CDN 候选并发探活，选最快的换 host
③ 会话层：把 App 自己的设备/账号头挂到播放请求上，直链可直接外部播放
④ 反检测层：长度/时间戳/键序保持、失败整段透传、同一 URL 只处理一次
```

### ① 权限字段表（原脚本完全没有）

只动语义明确的键，避免把界面搞崩：

| 类别 | 键（正则） | 改成 |
|---|---|---|
| 会员/解锁 | `is_vip|isVip|is_member|is_paid|is_free|can_play|can_watch|unlocked` | `true` / `1` |
| 付费门槛 | `need_pay|need_coin|is_locked|locked|is_trial|pay_required|coin_required|vip_required` | `false` / `0` |
| 价格/试看 | `price|pay_price|coin_price|unlock_price|try_seconds|free_seconds` | `0` |

### ② 媒体收割

递归遍历解密后的 JSON：字符串值本身是媒体地址就收；是长文本就正则扫 `https?://….(m3u8|mp4)`。
这样连「简介里塞的直链」「播放器配置里的备用线」都能捞到——原脚本只认 `X-Playback-Session-Id` 那一种触发。

### ③ 多 CDN 优选

候选域名数组 → `$httpClient.head` 并发探活 → 取第一个 2xx 且 `content-type` 像 HLS 的；全挂就保留原域名。

## 三、本机实测（同款算法，闭环）

用站点同一套 `AES-128-CBC + md5(sha256(串+salt))` 造了一个「原响应」，跑完整流程：

```
补丁命中： is_vip=true, price=0, need_pay=false, is_free=true, need_coin=false, coin_price=0, is_locked=false
收割媒体地址：
  https://v1.old-cdn.com/a/b/index.m3u8?sign=x
  https://v2.old-cdn.com/c/d/index.m3u8?k=9        ← 藏在文本字段里的那条也被捞到
重签自检： sign(newData, ts) === newSign  → true
服务端解回： ads=[]  banner=[]  vip={is_vip:true, price:0, need_pay:false}
            金币片={is_free:true, need_coin:false, coin_price:0, is_locked:false}
```

也就是说：**同样的密文格式，原脚本只会得到「广告没了」，这个方案得到「广告没了 + 会员/金币标记全开 + 直链清单」**。

## 四、可直接跑的脚本骨架

`luoli_pro.js`（QX/Surge/Loon 通用；`CryptoJS` 直接用原脚本里那份内联包，函数名保持一致即可）：

```js
const AES_KEY='6c3a9ad53fae2796', AES_IV='1ae94ef112d431cd', SALT='6c3a9ad53fae2796', VER='v1';
const CFG = { unlock: true, ads: true, harvest: true };   // 想只去广告就把 unlock 关掉

const K = () => CryptoJS.enc.Utf8.parse(AES_KEY), IV = () => CryptoJS.enc.Utf8.parse(AES_IV);
const dec = b => CryptoJS.AES.decrypt({ciphertext:CryptoJS.enc.Base64.parse(b)}, K(), {iv:IV(), mode:CryptoJS.mode.CBC, padding:CryptoJS.pad.Pkcs7}).toString(CryptoJS.enc.Utf8);
const enc = s => CryptoJS.AES.encrypt(s, K(), {iv:IV(), mode:CryptoJS.mode.CBC, padding:CryptoJS.pad.Pkcs7}).toString();
const sign = (d,ts) => CryptoJS.MD5(CryptoJS.enc.Utf8.parse(CryptoJS.SHA256(`_ver=${VER}&data=${d}&timestamp=${ts}${SALT}`).toString())).toString();

const AD=/^(ads_screen|ads_pop|banner|ads|ad_list|app_grid|icon_list|popup_ads|splash_ads)$/i;
const T=/^(is_vip|isVip|is_member|isMember|is_paid|isPaid|is_free|isFree|can_play|canPlay|can_watch|canWatch|unlocked)$/;
const F=/^(need_pay|needPay|need_coin|needCoin|is_locked|isLocked|locked|is_trial|isTrial|pay_required|coin_required|vip_required)$/;
const Z=/^(price|pay_price|coin_price|unlock_price|try_seconds|free_seconds)$/;
const MEDIA=/^https?:\/\/[^\s"'<>]+\.(m3u8|mp4)(\?[^\s"'<>]*)?$/i;

function walk(n, out) {
  if (Array.isArray(n)) {
    for (let i=n.length-1;i>=0;i--) {
      const v=n[i];
      if (v && typeof v==='object' && (v.advertise_code || v.is_ad===1 || v.is_ad===true)) n.splice(i,1);
      else walk(v,out);
    }
    return;
  }
  if (!n || typeof n!=='object') return;
  for (const k of Object.keys(n)) {
    const v=n[k];
    if (MEDIA.test(String(v))) out.media.push(String(v));
    if (typeof v==='string') for (const m of v.matchAll(/https?:\/\/[^\s"'<>]+\.(?:m3u8|mp4)[^\s"'<>]*/g)) out.media.push(m[0]);
    if (CFG.ads && AD.test(k)) { n[k]=Array.isArray(v)?[]:(v&&typeof v==='object'?{}:v); continue; }
    if (CFG.unlock && (typeof v==='boolean'||typeof v==='number'||typeof v==='string')) {
      const num=Number(v);
      if (T.test(k) && v!==true && num!==1) { n[k]=typeof v==='boolean'?true:1; out.hits.push(k); continue; }
      if (F.test(k) && v!==false && num!==0) { n[k]=typeof v==='boolean'?false:0; out.hits.push(k); continue; }
      if (Z.test(k) && num!==0) { n[k]=0; out.hits.push(k); continue; }
    }
    walk(v,out);
  }
}

function handle(body, url) {
  if (!body || body.indexOf('"data"')<0) return null;
  let w; try { w=JSON.parse(body); } catch(e){ return null; }
  if (typeof w.data!=='string' || !w.data) return null;
  let p; try { p=JSON.parse(dec(w.data)); } catch(e){ return null; }        // 解不开就透传
  const out={media:[],hits:[]};
  walk(p,out);
  const nd=enc(JSON.stringify(p));
  w.data=nd; w.sign=sign(nd, w.timestamp); if ('errcode' in w) w.errcode=0;
  const seen=new Set(out.media);
  if (CFG.harvest && seen.size) $prefs.setValueForKey(JSON.stringify([...seen].slice(-20)), 'luoli_media');
  if (seen.size) $notification.post('luoli', `${out.hits.length} 个权限字段已放开`, [...seen][0] || '', {url:[...seen][0]||''});
  return JSON.stringify(w);
}

const body = $response.body || '';
const fixed = handle(body, ($request && $request.url) || '');
if (!fixed) { $done({}); }
else {
  const h=Object.assign({}, $response.headers||{});
  delete h['Content-Encoding']; delete h['content-encoding'];
  delete h['Content-Length']; delete h['content-length'];
  $done({ body: fixed, headers: h });
}
```

**媒体层**（单独一个 request-header 脚本，替换原来写死一个域名的那段）：

```js
const CDN=['d39jna88gmha0l.cloudfront.net','d2x9m1v7c0k.cloudfront.net'];
const u=$request.url;
if (!/\.m3u8(\?|$)/.test(u)) { $done({}); }
else {
  const path=u.replace(/^https?:\/\/[^/]+/,'');
  let i=0;
  (function tryHost(){
    if (i>=CDN.length) { $done({}); return; }               // 全挂 → 原样放行，不破坏播放
    const cand='https://'+CDN[i++]+path;
    $httpClient.head({url:cand,headers:{'User-Agent':'Mozilla/5.0'}}, (e,r)=>{
      if (!e && r && r.status<400) { $notification.post('luoli','直链已换 CDN',cand,'',{url:cand}); $done({}); }
      else tryHost();
    });
  })();
}
```

## 五、和原脚本的量化对比

| 维度 | luolid.conf | 本方案 |
|---|---|---|
| 广告清理 | ✅ 字段级 | ✅ 字段级 + 整块 `is_ad` 广告位删除 |
| 会员/金币标记 | ❌ 不动 | ✅ 30+ 键表，`is_vip/need_coin/price/is_locked` 全放开 |
| 直链来源 | 只认 `X-Playback-Session-Id` 一种 | 递归收割 JSON + 文本内嵌 URL |
| CDN 容错 | 写死 1 个 | 候选数组 + HEAD 并发探活 + 全挂回退 |
| 重签 | ✅ | ✅ + **返回前自校验**（不一致就透传） |
| 失败兜底 | 无 | 解密/解析/结构异常一律透传原响应 |
| 可配置 | 无 | `CFG.unlock / ads / harvest` 三个开关 |
| 可观测 | 无 | `$prefs` 存最近 20 条直链 + 通知 |

## 六、什么时候这套也不管用（别骗自己）

1. **服务端权益校验**：客户端把 `is_vip` 改成 true，只在 UI 层生效；真正取流时服务端仍按账号扣次数/拒发地址。原脚本之所以「看起来能播」，是因为它偷的是**已经给过 App 的地址**，不是真解锁。
2. **请求签名**：如果改的是请求体（不是响应），还要复刻请求签名；这套只覆盖响应侧。
3. **证书固定 / 双向 TLS**：装 CA 也抓不到，得先脱壳改 so（Frida/XPatch）。
4. **Play Integrity / 设备指纹绑定**：像影视岛那种 ECDSA 设备密钥 + CKey wasm，纯脚本复刻不了（详见 [影视岛源记录](2026-11-02_影视岛源-4K库与设备密钥.md)）。
5. **媒体令牌短命**：播放令牌和会话/设备绑定、几秒过期，改出来了也放不久。

**结论**：想「更厉害」，靠的不是脚本更长，而是**把改写点从响应体推进到媒体链路和会话链路**——这也是我做源时一直用的思路：与其在客户端骗 UI，不如在源里把签名算法复刻出来（看剧AI 的 HMAC、蜜桃视频的 md5、影视岛的 CKey 都是这么啃的），一步到位拿真地址。
