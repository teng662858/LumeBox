# 2026-11-04 第一版主（bz1111111.net / diyibanzhu.app）：为什么打不开 + 源怎么落地

## 一、为什么打不开（三条证据）

| 地址 | 现象 | 性质 |
| --- | --- | --- |
| `https://diyibanzhu.app/` | HTTP **403**，`Attention Required! \| Cloudflare`，正文「**Sorry, you have been blocked** / You are unable to access diyibanzhu.app」，`cf-ray: a55486b5acb0ceec-HKG` | **WAF 封禁**（站点按 IP/地区封），不是挑战，浏览器也解不了 |
| `https://www.bz1111111.net/` | HTTP **403**，`Just a moment...` → 中文「正在进行安全验证… Ray ID: a554874aecee77c5」 | **CF managed challenge** |
| 同上，真浏览器（Tabbit + 有头 Chrome） | 挑战脚本 `cdn-cgi/challenge-platform` 回 **401**，紧接着 `brunhild.challenges.cloudflare.com` 报 **ERR_CONNECTION_CLOSED** | 你这台机器/这条网络**连 Cloudflare 的挑战域都被断**，所以挑战永远过不去 |

顺带说一句：这两个域名在本机 DNS 上都解析到 `198.18.0.x`（fake-ip 段），说明本机走了代理/软路由的
fake-ip；`198.18.0.0/15` 只是本地映射，真正原因还是上面这三条（一条 WAF 封禁 + 一条挑战域被断）。

**结论**：diyibanzhu.app 不是你操作的问题，是站方在 Cloudflare 上把当前出口 IP 封了；
bz1111111.net 是「挑战域连不上」导致挑战永远转圈。换网络（手机流量）或换个出口节点再试，
或者在 App 里打开网页视图让它自己过一次校验。

顺着搜索结果把候选域名逐个试了一遍：

| `www.01bzw.us` | **200**（45 KB） | 第一版主网 · 龙腾小说藏经阁，UTF-8，**本源默认** |

真到了 CF 站会抛 `NEED_WEBVIEW_VERIFY` 提示换镜像。

## 三、站点结构与实现（qula 模板）

```
分类   /sort/{1..10}/{页码}/   玄幻小说/武侠小说/都市小说/历史小说/侦探小说/
                              网游小说/科幻小说/恐怖小说/散文小说/辣文小说
       列表两种排版都要抓：
       ① 大卡片 <div class="item"><div class="image"><a href="/bookcv/{id}/"><img …></a></div>
                 <dl><dt><span>作者</span><a href="/bookcv/{id}/">书名</a></dt><dd>简介</dd></dl>
       ② 文字行 <ul class="txt-list"><li><span class="s1">[分类]</span>
                 <span class="s2"><a href="/bookcv/{id}/">书名</a></span>…</li>
       一页 31 本，/sort/1/2/ 实测换内容
详情   /bookcv/{id}/    <h1>书名</h1> + 作者/类别/状态
       关键：og:novel:book_name / author / category / status / update_time /
             lastest_chapter_name / lastest_chapter_url 全在 meta 里，直接读
目录   同一页的 /html/{p}/{书号}/{章节号}.html 链接（实测一本书 22 章一次给全），
       源里按章节号排序并过滤「开始阅读/加入书架」这类按钮
正文   /html/{p}/{书号}/{章节号}.html → <div class="content" id="content"><p>…
       防采集：部分汉字被换成 <img class="zi" src="/zi/j3.png" data-word="交" alt="交">
       → 源里用 data-word（回退 alt）还原成汉字
       广告：正文里插「发布邮箱…地址发布页…」「笔趣Ω 『 阁ΔＢＱgXsw．ＣoM」→ 按行过滤
```

搜索 `/search/?q= / ?keyword= / ?searchkey= / ?wd=` 四种参数都回「共有 0 个结果」，
站点搜索是前端脚本调的，所以关键字暂时返回空。
