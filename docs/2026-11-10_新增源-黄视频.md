# 新增源：黄视频（huang.video，2026-11-10）

用户给的 `https://huang.video/`。站点是 Rails 服务端渲染的国产成人视频站（AI 短剧 / 糖心Vlog /
网红福利姬 / 探花大神 / PMV / ASMR），本机直连 200，无需登录、没有 Cloudflare 挑战。

| 项 | 结论 |
|---|---|
| 板块 | `video`（`contentCategory: adult`） |
| 列表 | `/videos`、`/c/{shorts,tangxin,influencers,tanhua,pmv,asmr}`，24 条/页 |
| 排序 | `?sort=latest\|popular\|popular_24h\|popular_7d`（实测首条互不相同） |
| 博主筛选 | `?creator_id=N`（`/videos` 页内联 93 个博主） |
| 搜索 | `/search?q=&sort=relevance\|latest`，结果分「短剧」与「视频」两段 |
| 详情 | `/videos/{id}`、`/series/{id}` |
| 播放 | 详情页内联 `master.m3u8`，**CDN 只认站点 Referer**，实测 206 + `#EXTM3U` |

## 1. 站点结构

列表页卡片统一是：

```html
<article id="video_5368" class="card …">
  <a class="group block" aria-label="标题" href="/videos/5368">
    <figure><img src="https://h.matecdn.com/videos/d44fca4f/cover.webp" />
      <span class="badge badge-neutral …">44:11</span></figure>
  </a>
  <div class="card-body …">
    <h3><a href="/videos/5368">标题</a></h3>
    <p class="truncate …"><a href="/creators/zyxm711">梓怡学妹</a></p>
  </div>
</article>
```

短剧卡同结构，只是 `id="series_486"`、链接 `/series/486`、没有时长角标。源里用 `article` 上的
`video` / `series` 前缀区分，站内 ID 统一成复合串 **`v:视频ID` / `s:剧集ID`**。

分类页（`/c/*`）与 `/videos` 都带四档排序 `<select name="sort">` 与博主筛选 `?creator_id=N`，
翻页是 `?page=N`，非末页带 `rel="next"`。

## 2. 搜索：两段结果、两套分页

`/search?q=<词>` 一页里有两个 section：

- **短剧**：`#search-series` 的 series 卡，分页参数是 `?series_page=N`（实测 19 页）
- **视频**：视频卡，分页参数是 `?page=N`

两段各自 24 条；源里同一页同时请求 `page=N&series_page=N`，合并后按前缀去重，
`hasMore` 看页面里有没有 `rel="next"`。`sort` 只传站方支持的 `relevance` / `latest`
（筛选里选了别的排序时搜索退回 `relevance`）。

实测「短剧」：第 1 页 48 条（24 短剧 + 24 视频），第 2 页 43 条（24 + 19，视频段先到底）。

## 3. 播放与防盗链

详情页播放器 div：

```html
<div id="player_video_5368" data-xg-player-source-value="https://h.matecdn.com/videos/d44fca4f/master.m3u8"
     data-xg-player-poster-value="https://h.matecdn.com/videos/d44fca4f/cover.webp" …>
```

`master.m3u8` 只有一条 720p 变体（`720p/index.m3u8`），所以不给 `qualities`，直接返回 master。

**CDN 防盗链实测**：

| 请求 | 结果 |
|---|---|
| 无 Referer / 无 UA | `403`（Cloudflare 拦截页） |
| 外站 Referer（`https://example.com/`） | `403` |
| `Referer: https://huang.video/` | `200 application/vnd.apple.mpegurl`，162 B master |
| 分片 `720p/00000.ts` + 站点 Referer | `200 video/mp2t`，465 KB |

所以 `content()` 返回 `{ kind:'video', url, headers:{ Referer: <当前域名>/ } }`；
App 的 mdk / mpv 内核会把逐媒体请求头带到分片请求上。封面与 `thumbnails.vtt` **不需要** Referer，
直接给列表用。

## 4. 剧集与选集

`/series/{id}` 给 `h1#series-title`、`aspect-[2/3]` 封面、「共 N 集」与完整 `#episodes-title` 列表
（实测《高三爱情故事》42 集一次给全）。单集页 `/videos/{id}` 右侧还有整部剧的播放列表
（`aria-label="…中的视频"`，每项 `href="/videos/N"` + 集名 + 时长）。

源里两边都解析：`chapters(s:…)` 走剧集页；`chapters(v:…)` 优先取单集页的播放列表，
没有播放列表（单片）才退回「正片」。这样从任一集点进去都能直接选集。

## 5. 分类 / 筛选 / 首页

- 分类 7 个：最新视频、AI短剧、糖心Vlog、网红福利姬、探花大神、PMV、ASMR。
  实测各分类首条：`v:5164` / `s:486` / `v:5368` / `v:5164` / `v:4373` / `v:4557` / `v:253`
  （「最新视频」是全站并集，和「网红福利姬」首条相同属正常，内容集合不同）。
- 筛选：排序 4 档 + 博主 93 个（站点 `/videos` 页内联）。博主是单选，多选时取第一个。
- 首页 7 个板块：精选推荐（轮播 5 部短剧）+ 站内 6 个 `creator_category_*` 板块；
  `moreUrl` 直接回传分类 id。

## 6. 地址发布页

站内「回家的路」(`/home-road`) 公布：

- 海外永久地址：`https://huang.video/`（唯一正式域名）
- 地址发布页：`https://18dh.pages.dev/`、`https://daohang.pro/`

两个发布页是 JS 渲染的通用导航（`app.js` 里的 `CONFIG.links`），只收录 `huang.video` 一个本站地址，
没有其它镜像。按约定写进源设置的 `openWebsite` 动作，不当镜像。

## 8. 限制

- 播放只有 720p（站方 master 就一条变体）。
- 搜索里的「视频」段会把短剧的单集也列出来，标题就是「第N集」；短剧本身在「短剧」段里。
- 播放地址依赖站点 Referer，换域名后源会自动用 `LumeSource.config.domain` 拼，不用改脚本。
- 站点是成人内容，App 侧按 18+ 归档（`huangvideo_video` / 名称「黄视频」）。
