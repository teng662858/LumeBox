# 原生视频播放页重建

本次按用户要求替换现有 App 的视频播放链路，保留 Flutter 多板块界面、QuickJS 源引擎和现有数据，不新建 App，不修改源脚本，不生成 IPA。最低系统仍为 iOS 18。

## 播放链路

`VideoPlayerPage` 只负责路由交接，`NativeVideoSourceSession` 负责源取址、请求头、选集和历史。完整的可见播放页由 Swift/UIKit 的 `NativeVideoScreen` 管理，系统 AVPlayer 与 libmpv 均直接嵌入这张原生页面。播放时钟、按钮、手势、跳转、生命周期和音频会话不再由 Dart 与原生各维护一份。

移除旧 Flutter 播放页及其片头/路由扩展，删除 Dart AVPlayer、MPV、MDK、Aether 的解码实现，删除 Aether 原生控制器与 AetherEngine SDK，移除 fvp。旧枚举和偏好模型保留用于兼容历史设置；正式视频入口不会创建旧播放器。离线 MP4 合并继续使用直接引用的 FFmpegBuild，它的产品名仍叫 AetherFFmpegBuild，属于合并库，不是 Aether 播放器。

| 责任 | 新实现 |
| --- | --- |
| 系统画面与解码 | AVPlayer / AVPlayerLayer，保留系统 HDR 和 AirPlay 通路 |
| 格式兼容播放 | 原生 libmpv，串行控制队列与独立渲染队列 |
| 视频操作 | UIKit 按钮、滑条、双击跳转、横滑定位、亮度/音量、长按倍速、锁定、旋转、定时暂停 |
| 源功能 | 原源 ID、线路、集数和内容接口；切画质、同集换线、重取签名地址 |
| 数据 | 原视频库的历史、逐集进度、隐私模式、Bangumi 进度和独立源偏好 |
| 请求与缓存 | 保留原 URL 和精确请求头，按目标内核准备 HLS；复用 VideoDiskCache |

AVPlayer 不同步读取未加载的 asset 时长，音轨异步加载。MPV 的初始化、命令和释放在原生队列执行，先释放渲染上下文再销毁 core；关闭页面不等待解码器销毁。切内核与取址使用代次校验，旧任务不能覆盖新会话。未输出首帧时 30 秒提示重试，返回、切线路和切内核按钮仍可操作。

换集前先以旧集的标识保存进度，再更新当前媒体；源会话按事件携带的身份写入对应集。内核切换重新准备目标内核的缓存地址，保持当前位置；MPV 请求头使用原生节点数组传递，避免 Cookie 中逗号和反斜杠被文本列表解析改变。缓存启动变为幂等，换集不会清空已有磁盘块。缓冲秒数和内存上限读取现有模块/源设置，缓冲填满不是起播条件。

## 这版的功能边界

- 系统播放器提供画中画；MPV 暂不开放画中画。MPV 在失去前台状态时停止并清空最后的图形提交，后台只保留音频，图形资源延至回到前台释放。后台是否继续音频服从现有开关。
- MPV 显示使用有上限的 BGRA 缓冲，最长边 1920，SDR 输出；不声明 4K/HDR、Dolby Vision 或 Atmos 输出已验证。需要系统 HDR / AirPlay / 画中画时选择 AVPlayer。
- 系统播放器外挂字幕支持 SRT / VTT，MPV 的外挂字幕交给内核；两者支持已有音轨和字幕轨选择。复杂字幕样式、字幕/音频延迟等旧面板选项未全部迁移。
- 支持当前源直接提供的基础弹幕。旧版自动弹幕匹配、AI 片头片尾识别、画面增强和预解码下一集没有接入新播放页。相关独立模块及历史配置保留，不将其描述为已迁移。
- 全局播放器入口仅展示新版会使用的内核、倍速、内嵌字幕开关、硬解、连播、后台和缓冲设置，避免旧面板参数显示可设置却不作用于新页面。

苹果明确要求在进入后台前停止 OpenGL ES 并完成已提交命令，后台使用可能被系统终止，因此这版不通过后台继续绘制来实现 MPV 画中画。参见 [Apple OpenGL ES 后台要求](https://developer.apple.com/library/archive/documentation/3DDrawing/Conceptual/OpenGLES_ProgrammingGuide/ImplementingaMultitasking-awareOpenGLESApplication/ImplementingaMultitasking-awareOpenGLESApplication.html)。

## 验证

本地 21 个相关测试文件合并运行，218 项通过，1 项因本机缺少 QuickJS 原生桥跳过；`flutter analyze --no-pub lib test integration_test` 通过。覆盖源请求头、逐集历史、换线续播、过期取址、关闭时取消、源独立偏好、缓冲配置、原生路由、缓存、全局设置落库与其他视频入口。删除随旧实现废弃的 Flutter 控件测试，用原生会话测试和 UIKit 模拟器实播验证新契约，不把旧用例数量当成新版功能等价证明。

Mac 验证由 `check_ios_player_presentation.sh` 编译实际 Swift/Objective-C 文件；`check_native_video.sh` 将生产页面与 libmpv 链接成临时模拟器测试宿主；`check-playback.yml` 编译完整 Runner 并通过 Flutter 通道调用同一页面及生产缓存。模拟器测试覆盖 MP4 / HLS、AVPlayer / MPV、暂停、跳转、切换和 UIKit 命中测试。测试资源是本地生成的测试画面和音调，请求头用含逗号、反斜杠的固定测试值。

首次独立模拟器验证因普通 Python 文件服务器不支持 Range 而失败，已使用支持 206 的测试服务器；随后验证发现 MPV 文本请求头解析会改变测试值，已改为节点数组。完整 Runner 首轮编译成功，但测试检查通道因 Runner Debug 未定义 Swift DEBUG 不可用，已仅为 Debug 配置补充该标志。上述失败不记为实播通过。

原生最终代码 `549f7dbd` 的 [Mac 验证 43161086626](https://github.com/teng662858/LumeBox/actions/runs/43161086626) 已全部通过：iOS 18 Swift/Objective-C 编译、原生页面四种播放组合、暂停/跳转/切换/命中测试、锁屏归属交接，以及工作流内的系统栏/Python 原生检查。打包和 IPA 上传步骤均跳过。只上传测试日志，不发布测试宿主。

[完整 Runner 集成检查 43159502327](https://github.com/teng662858/LumeBox/actions/runs/43159502327) 编译与安装成功，连上 VM 服务后测试超时，**该项未通过**。停滞截图显示生产缓存中的 MP4 已输出实际测试画面并播放到片尾；主线程采样大多处于正常 RunLoop 等待，仍有 NativeAVEngine 定时回调和通道事件发送。结合测试在原生全屏页后仍调用 `tester.pump`，判断等待隐藏的 Flutter surface 刷新导致测试不能继续。脚本已改为实时轮询原生状态，并为调试通道加 3 秒超时；本次未重新执行完整 Runner 集成检查，不宣称五项集成用例已通过。

删除本轮未使用的重复工作流，并给现有播放检查增加同分支新任务取消旧任务的并发策略。两个既有工作流 YAML 已解析核对；没有新增常驻任务或定时任务。

MPV 的 CI 用空音频输出；时钟推进不代表真机声音已验证。画中画测试仅准备内容源，未证明真机后台画中画窗口。模拟器不能证明用户设备、原源、特定网络、硬解、HDR、AirPlay、后台和画中画均无问题；本次重建不承诺消除所有播放类故障。原诊断包没有 Aether crash/ips 堆栈，不能据此断言原闪退的唯一原因。
