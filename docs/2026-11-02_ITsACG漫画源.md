# ITsACG 漫画源（`comic/itsacg.js`，`itsacg_comic`）

2026-11-02 · 用户给的 `https://www.itsacg.com/` + 发布页 `https://itsacg.top/`

## 一、站点是什么

ITsACG（漫畫中心）—— **Discuz! + 插件 `jameson_manhua`** 的绅士向漫画站：

| 项 | 值 |
|---|---|
| 主站 | `https://www.itsacg.com`（发布页注明「大陆被屏蔽，科学上网能访问」） |
| 备用 | `https://www.itsacgaa123.space`（发布页给的大陆备用站） |
| 发布页 | `https://itsacg.top/`（另有邮箱索取最新地址） |
| 内容 | 同人誌 / 單行本 / 雜誌&短篇 / 韓漫 / 3D&漫畫，全部 18+ |
| 结构 | 一个 `kuid` = 一本，一个 `zjid` = 整本阅读（没有多章节） |
| 门槛 | **无登录、无会员、无积分**，列表/详情/阅读/搜索全是匿名 GET |

## 二、接口（实测）

```text
分类列表  /plugin.php?id=jameson_manhua&a=ku&category_id=<cid>&page=<n>   # 30 本/页
          cid: 1 同人誌 / 2 單行本 / 3 雜誌&短篇 / 4 韓漫 / 19 3D&漫畫
排行榜    /plugin.php?id=jameson_manhua&a=rank&page=<n>                  # 20 本/页，分页极深（page=17321 仍在）
最近更新  /plugin.php?id=jameson_manhua&a=updatelist                     # 10 本，单页
编辑推荐  /plugin.php?id=jameson_manhua&a=new_tj                         # 10 本，单页
详情      /plugin.php?id=jameson_manhua&c=index&a=bofang&kuid=<kuid>
阅读      /plugin.php?id=jameson_manhua&c=index&a=read&zjid=<zjid>&nopage=1
搜索      /plugin.php?id=jameson_manhua&c=index&a=search&keyword=<词>     # GET，不需要 formhash
图片      https://image2.imgspace.co.uk/data/…、/hacg_cover/…              # 只认 Referer
```

两个关键点：

1. **`nopage=1` 一次给整本图片**：阅读页把地址内联成 `let urls = [...]`，一本 132 张就是 132 个 URL；
   和分页版（每页 40 张、7 页）合并后完全一致（实测 132 = 132）。
2. **搜索不需要 Discuz 的 `formhash`**：搜索页 HTML 里有 `formhash` 输入框，但 `a=search&keyword=`
   直接 GET 就能出结果（实测「巨乳」→ 30 条，可翻页）。

## 三、两套卡片布局（解析踩的坑）

| 页面 | 卡片结构 |
|---|---|
| 分类 / 搜索 | `<div class="image-fm"><img></div><div class="image-title">标题</div><div class="image-summary">更新时间</div>` |
| 排行 / 更新 / 推荐 | `<div class="item-media"><img></div><div class="item-title">标题</div><div class="item-subtitle">閱讀量: N</div>` |

只认 `image-title` 时排行页会把 `<img src=…>` 当标题（第一次跑就是这样）。
现在两种类名都认，并补了 `alt/title` 兜底；都没有就跳过，不再把 HTML 当标题。

详情页**没有 og:image**，封面是正文第一张 `<img>`（与列表页封面同一张 `hacg_cover`）。

## 四、源的做法

- `categories()` 8 个：排行榜 / 最近更新 / 编辑推荐 / 同人誌 / 單行本 / 雜誌&短篇 / 韓漫 / 3D&漫畫；
- `home()` 三个板块（最近更新 / 排行榜 / 编辑推荐），单个失败不影响其它；
- `list()` 支持 `keyword`（搜索）与 8 个分类，`hasMore` 按页面里有没有 `page=N+1` 判断；
- `detail()` 标题/封面/标签（`a=search_tags&tag_name=`）/阅读量，结果做 5 分钟缓存（`chapters()` 复用，少一次请求）；
- `chapters()` 一本一话：`全集（整本阅读）`；万一详情页给了多个 zjid，就按「第 N 话」列；
- `content()` 走 `nopage=1`，返回 `kind:'images'` + 每张图的 `Referer` 头；解析不到时回落 `page=1`。

## 六、限制

- 全站 18+；`contentCategory: adult`，`itsacg_comic` 已进 `adultIds` 与源仓库 `content-ratings.json`；
- **大陆直连打不开主站**（站点自己声明），源里 `network: direct`（本机实测直连 200），
  `mirrors` 放了主站 + 备用站，打不开时在源设置里换镜像或开代理；
- 一本一话（站方结构如此），没有章节切换；
- 排行榜分页极深（17k+ 页），App 端翻到很后面会很慢；
- 站点换域名看发布页 `itsacg.top`，或改源里 `MIRRORS` / `BASE_FALLBACK`。
