# 新增源：集书阁（集书阁.com → X小说 / x文学，2026-11-10）

用户给的 `集书阁.COM`。实测这个域名仍在，但**站点已经换了新前端**，需要先理清域名关系再写源。

## 1. 域名关系（关键）

| 域名 | 实测结果 |
|---|---|
| `集书阁.com` | 301 → 一个 punycode 长域名（`…jishuge.vip…`），这台还跑**旧模板**：`list_1.html` 短篇列表、`content_<hash>.html` 阅读页 |
| 旧模板的 `content_*.html` | 再 **301 → `x成人小说.com`**（新站）的 `/read/<hash>/<章页id>` |
| 旧站首页 canonical | `https://www.集书阁成人小说.com/` |
| `www.集书阁成人小说.com` | 直接就是**新站**（X小说 / x文学 前端，`/books`、`/category/N`、`/book/<hash>`、`/read/...`） |
| 新站「收藏回家」公布 | `x成人小说.com`、`x文学.com`、`xchengren.com` 三个永久域名 |

结论：旧 集书阁.com 的列表还是旧模板，但正文全部跳去新站；新站的分类/书籍数量也更全
（旧站 10400 短篇 + 203 长篇，新站 10603 部）。**所以源直接按新站写**，用新站域名做镜像，
不去混搭「旧列表 + 跳转正文」。

## 2. 站点结构（新站）

- **列表**：`/books`、`/books/page/N`（20 部/页，共 10603 部）
- **分类**：53 个（`全部` + 短篇/长篇两个根 + 50 个题材）
  - 短篇情色小说 `/category/1`：10400 部，520 页
  - 长篇情色小说 `/category/2`：203 部
  - `/category/3` 情色文学 5186 部、`/category/4` 短篇小说 5214 部（后者 3 + 4 = 1 的拆分）
  - 题材 `/category/5..52`：`/category/N/page/N` 分页
- **搜索**：`/search?q=<词>&page=N`（实测「母子」57 部 3 页，「白洁」2 条）
- **卡片**：`<li class="book-item">` —— `h2>a` 标题 + 分类 + 「N 章」+ 摘要；
  短篇直链 `/read/<hash>/<章页id>`，长篇链 `/book/<hash>`
- **详情**：`/book/<hash>` —— `h1.book-heading` + 「分类 · 章节目录」+ `<ul class="chapter-grid">` 全目录
- **正文**：`/read/<hash>/<章页id>` —— `#bookcontent` 的 `<p>` 段落
- **站内 ID**：源里用 `b:<书 hash>`，章节用站方章页 id（数字；不是 1..N 的序号）

## 3. 正文里的水印

新站比旧模板干净得多，但正文偶有一处：

```html
<span class="brand-mark" data-site-brand="xxiaoshuo">更多阅读内容请见x文学.com，随时回来继续读</span>
```

源里把整个 `span.brand-mark` 段删掉，再兜底清一次「更多阅读内容请见…」文本；
段落按 `</p>` 换行，实体反转义。实测长章 4120 字 / 短篇 3050 字，清洗后无
`x文学`、`x小说`、`更多阅读` 残留。

旧模板的阅读页（`来源 集书阁.com` 随机标签水印）源里**不再走**，所以没保留那套清洗逻辑。

## 4. 分类 / 首页

- 53 个分类全部来自站方 `/books` 的分类导航；逐个实测都有内容（短篇 20 条/页、长篇 12 条/页）。
- 首页两个板块：`短篇情色小说` / `长篇情色小说`，各 20 条，首页用的是紧凑链接
  （`ul.book-links`，与列表页的 `book-item` 卡片不同），源里两套都解析。
- 站点**没有封面、没有排序、没有筛选**，所以源不声明 `filters()`，列表项也不给假封面。

## 6. 限制

- 站点没有任何封面图，列表/详情按标题展示（不编造图）。
- 没有排序/筛选；深度浏览靠 53 个分类与搜索。
- 分类 3/4 是站方对「短篇」的二次拆分（3 + 4 = 1），有内容重叠，属站方分类本身。
- 旧 `集书阁.com` 不能当镜像用（它只跑旧模板路径）；源默认走新站 `x成人小说.com`。
- 成人内容：App 侧按 18+ 归档（`jishuge_novel` / 名称「集书阁」）。
