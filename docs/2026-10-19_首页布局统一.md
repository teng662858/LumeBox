# 四个板块首页布局统一

小说、漫画、视频和猫源共用同一个布局入口及底部选择面板，只保留「双列列表」「三列网格」。三列网格统一使用 20pt 九宫格图标，双列列表使用 20pt 双列图标，按钮触达区域为 42pt。选择仍按板块分别保存，源切换、搜索和源管理沿用各自入口。

旧版单列列表偏好转换为双列列表；双列、四列和五列网格偏好转换为三列网格。枚举保留旧 ID 用于读取备份和独立的历史、收藏面板，其余面板的可选布局不随首页菜单一起删除。

## 双列列表适配

四个首页及使用相同布局偏好的搜索、源首页都复用 `TwoColumnSourceItemTile`，统一浅色卡片底、10pt 圆角、10pt 两侧留白、8pt 列间距、10pt 行间距。

封面宽度根据实际单元宽度调整，范围为 44～80pt，保持 3:4 比例。行高取封面高度与文字所需高度的较大值，再加上下内边距；文字高度分别按系统缩放后的标题、辅助信息字号计算。保持两列，长标题最多两行，辅助信息单行省略，封面宽度达到上限后不再随大屏无限放大。

| 可用区域宽度 | 参考封面尺寸，常规字号 |
| --- | --- |
| 320pt | 约 47 × 62pt |
| 390pt | 约 58 × 77pt |
| 430pt | 约 64 × 86pt |
| 768pt 及更宽 | 80 × 107pt 上限 |

尺寸按实际布局区域计算，横屏安全区与父级约束会相应缩小可用宽度。既有三列网格的尺寸规则保留。
