# 2026-11-01 海角 1.2.0：帖子视频登录即可原生播放（附「破解脚本」拆包结论）

用户给了账号，并指出 sleazyfork 上有一堆「海角社区破解」脚本。两边都实测了，结论分开写。

## 一、真账号实测：两条播放路径不一样

登录接口 `POST /api/login/signin {username,password}`（无需验证码）→ 拿到 `token` + `user.id`。
这个账号 `vip=0 / gold=0 / diamond=0`（没会员、没钱），所以正好能区分「登录」和「付费」：

| 路径 | 请求 | 结果 |
|---|---|---|
| 帖子视频（topic） | `POST /api/attachment {id:<附件id>, line:'', resource_id:<topicId>, resource_type:'topic'}` | **200**，`data.remoteUrl = https://ts10.hj260302818.top/hjstore/video/<日期>/<hash>/<附件id><tok>_i.m3u8` |
| 视频中心（video_center） | 同接口 `resource_type:'video_center'` | 200 但 `message:"当前用户无权播放该视频"` |

拿到的 m3u8 实测：`200 audio/x-mpegurl` + `#EXTM3U`（AES-128，`URI="enc_<附件id>.key"`）、
key `200`（16 字节）、分片 `200` → App 原生 HLS 直接能放。

两个必须注意的细节：
- `line` 必须传空串 `''`；传 `0` 会得到「请求错误」。
- `resource_type` 决定一切：`'topic'` 走帖子附件，`'video_center'` 走视频中心（要买）。

所以「会员」这层：**视频中心的收费片没有破，服务端明确拒绝**；**帖子里的视频登录就够，不需要买券**。

## 二、sleazyfork 那些「海角破解脚本」到底做了什么（拆包实证）

下载了 `594152 海角社区破解-完全免费`、`591973 海角社区破解脚本`、`569438 海角社区脚本` 三个脚本看代码：

- 它们只挂 `post/details` 页面（`if (location.href.indexOf('post/details') === -1) return`）——
  也就是上面表格里的第一条路：把帖子附件地址取出来换个播放器，**不是破站**。
- 575/594152 这类遇到「付费帖」时，会去 GitHub Gist 拉配置：
  `https://gist.githubusercontent.com/mrm7fh4ops/55df4622a441ad7bac896c15190706a1/raw/config.json`
  → `{"svc":"https://kittymao.xyz/api","key":"<JWT>"}`，再请求
  `https://kittymao.xyz/api/hj/movieInfo?kthjau=<key>&isPhone=…&t=<帖子时间戳>`，
  由**第三方解析站**给出转码地址。这是外部盗链/转码服务：key 会轮换、服务随时挂，
  页面还可能塞广告/钓鱼，本源不接这条。

## 三、源码改动（1.2.0）

- 新增分类「帖子视频（登录可原生播）」与首页第三块，条目 id = `t<topicId>`；
  `detail` / `chapters` / `content` 按 `t` 前缀分流到帖子路由（`/post/details?pid=`）。
- `content()` 顺序：先 `POST /api/attachment` 取真地址（帖子用 `topic`，视频中心用 `video_center`），
  拿不到再试老的分线路表，最后才退回 `webplayer`（视频中心 → `/watch?id=`，帖子 → `/post/details?pid=`）。
- 登录态来源不变：账号密码（源设置 → 账号登入）或 Cookie（含 `token=`、`uid=`），
  token/uid 走 `X-User-Token` / `X-User-Id` 头。

## 验证

  探活 `206` + `#EXTM3U`（真实可播）。

## 限制

- 视频中心（`/watch`）的收费片仍然只能网页播放；站点的券/VIP 账务没碰。
- 帖子图片（`/hjstore/images/*.jpg.txt`）是站点前端现解的加密图，App 图片管线解不开，帖子封面只用视频附件封面。
