# 2026-11-04 草榴小说视频源（`video/mycall.js`，综合站）

用户给的入口 `https://mycall.biz/`，站点是**草榴小说视频**（综合站：小说 + 视频 + 图集，全站 18+）。
本源按**综合源**交付：`mediaType` 分派 `novel` / `video` / `comic`，`content` 分别返回
`kind: text` / `video` / `images`。

| 项 | 值 |
| --- | --- |
| ID / 名字 | `mycall_video` / 草榴小说视频 |
| 版本 | 1.0.0 |
| 板块 | video（综合源，小说条目在漫画板块阅读器里打开） |
| 分级 | 18+（`adultIds` + `content-ratings.json`） |
| 网络 | direct |

## 一、结构（逐页实测）

- **小说频道** `/threadlist?group=RecentThread|PopularThread|HotThread`（最新 / 最多浏览 / 最多点赞）
  + **7 个分类** `/threadlist?group=…&category={id}`：诱骗系列、改编系列、变身系列、乱伦系列、
  古典情色、武侠系列、玄幻系列。
- **视频频道** `/category/6095467d69deb6073dc6d6d7?sort=recent|popular|like`。
- **图片频道** `/images?sort=recent|popular|like`。
- **搜索** `/search?type=all|novel|video&sort=recent&q={词}`。
- **帖子** `/thread/{24 位 hex}`，`<body class>` 决定形态：
  - `novel-reader`：`data-chapter` / `data-total-chapters`（实测 957 章），正文 `?chapter=N`（1 基）
    里的 `#chapter-content .novel-chapter-content`；
  - `video-watch-page`：前端 `player24.min.js` 请求
    `GET /api/v1/video/thread/{id}/play` → `source.manifestURL` =
    `/api/v1/video/thread/{id}/manifest/master.m3u8`（实测 200 + `#EXTM3U`，2312 B，VOD，免登录、免 Referer）；
  - `image-viewer-page`：`.image-gallery` 每个按钮带 `data-gallery-preview="/imagesph/960/{hash}.jpg"`
    （实测首图 200 + `image/jpeg`，54 KB）；`data-gallery-src` 只是去掉扩展名的原图路径。
- 列表两种版式都解析：图文卡 `<article><a class="cp-catalog-cover" href="/thread/{id}">…<h2><a>【小说】标题</a></h2>`
  与图集卡 `<a href="/thread/{id}"><img…><strong class="cp-image-title">【色图】标题</strong></a>`。
  标题前缀 `【小说】` / `【视频】` / `【色图】` 直接用来定 `mediaType`。

三处都实测生效。

## 三、限制（如实记录）

- **全站列表都是单页 24 条**：`page=` / `p=` 实测被忽略，页面上也没有翻页控件 → `hasMore` 恒为 false，
  「翻页」只能靠换排序或换分类。这是站点自身的设计，不是源漏写。
- 小说帖子页**没有封面图**（页面里没有任何 `<img>`、`og:image` 为空），详情里封面留空由 App 占位图兜底；
  视频与图集帖子的 `og:image` 正常。
- 章节目录只给章数，页面不暴露每章标题 → 章节列表用「第 N 章」，正文打开后标题也是「第 N 章」。
- 站点会挂 exoclick / magsrv 广告（首页 popunder、正文 slider），源里只取 HTML 与接口，不加载广告脚本。
