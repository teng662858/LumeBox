# PY 合集适配与仓库源管理评估

日期：2026-11-02。范围：用户指定的 `D:\PY源合集包`、当前 LumeBox 代码与独立源仓库生成器。最低目标保持 iOS 18。本轮按“先检查”完成评估，未改 App 功能，未把尚未验证可播放的源加入公开订阅。

## 结论

可以接入其中符合 Spider 协议的 Python 源，并入现有 GitHub／国内 CDN 双线路订阅。App 已有 CPython 宿主、Spider 接口适配、`.py` 导入、多文件包和订阅同步；源仓库生成器也已支持 `.py`。实际仍需按源验证依赖、配置、分类、搜索、封面与播放，不能把整个目录直接标记为可用。

App 已能添加、删除已安装源，删除订阅源会保存排除项，后续自动同步不会装回；重新添加同一订阅则清除该订阅的全部排除项。目前缺少直接浏览仓库全部条目、逐项选择安装和单独恢复已删除源的界面。可以复用现有安装、卸载和排除机制补齐。

“在 App 管理自己安装的仓库源”与“在 App 提交 GitHub 仓库增删”是两种功能。前者可直接沿现有机制实现；后者需要仓库写入身份、提交和发布流程，当前 App 没有这条链路。

## 依赖与协议边界

AST 扫描发现 10 份不同内容文件含 Android／Java 导入，17 份含额外依赖；这些线索可重叠。导入可能位于可选路径或 `try/except` 回退里，不能仅据扫描判定整源不可用。例如果果短剧的 `spider` 导入是回退路径，当前宿主也提供该模块别名。

| 线索 | 代表文件／范围 | 接入处理 |
| --- | --- | --- |
| `java`、`javax`、`dalvik`、`com`、Android WebActivity | 91porna、porna91、红果最终版、带排行榜红果、多聚听书、玩物社区、自动加载工具等 | 按实际调用路径改为已有 Python 加密／WebView 能力；DEX 和客户端注入不能直接在 iOS 运行 |
| `curl_cffi` | 91短剧、网飞TV | 评估能否改走宿主 HTTP；存在 TLS 指纹依赖时需额外验证 |
| `PIL` | 网飞猫、55影院、ik4k、ZIP0、咸鱼、无极、资源管理 | 核查是否仅用于验证码／图片处理；需要原生扩展时按 iOS 构建规则接入 |
| `Cryptodome`／`pyaes` | xx9、有料、TVB云播代理版 | 核查回退路径，按实际算法适配；不能承诺完整 PyCryptodome 兼容 |
| `m3u8_cleaner`、`storage`、`music_station` | 欲语心镜、火云、音乐聚合 | 补齐辅助模块或替换相关调用，必要时使用多文件源包 |
| `urllib2` | 短剧大全 | 核查是否为兼容回退，Python 3 实际路径统一到已有网络桥 |
| 动态 `exec`／`eval` | 扫描发现 9 份文本有此类调用 | 外层 AST 不能完整反映内部依赖；结合实际加载和调用结果判断 |

## 并入现有订阅的落地方式

1. 先按内容去重，再合并同站点版本，排除管理器和纯工具脚本；动漫视频进入视频板块，图集／漫画按图片协议接入，音频按媒体类型归类。
2. 保留 Python Spider 主体，为每源补稳定 ID、名称、版本、板块、实际网络要求和必要设置。对已有仓库源先比对站点与 ID，避免重复安装。
3. 修复实际必需的宿主接口／依赖，再实测分类差异、分页、搜索、详情、选集、封面和真实媒体。需登录、会话或网页验证的源明确标注。
4. 只将通过验证的源加入独立源仓库；生成器已有 `.py` 支持，但必须有合法 `LumeSource` 元数据头。
5. 运行 `build_catalog.py` 和 `--check`，加入现有分类订阅及总订阅；涉及 18+ 的源按现有两处登记规则处理。
6. 同步发布 GitHub 与 CDN，刷新缓存，并下载清单和源脚本对照版本及 SHA256。无需另建一个与现有订阅割裂的入口。

## App 仓库源管理建议

建议在现有订阅管理中增加“仓库源目录”：支持按分类／关键词查看全部条目，显示已安装、未安装、已移除状态；提供逐项和批量添加、卸载、恢复。

安装复用当前导入验证；卸载复用 `SourceMaintenance.remove`；恢复只清除所选 ID 的排除记录，并保留同订阅其他排除项。当前 `register` 会清除整份订阅的排除集合，不能直接拿它实现单源恢复。同步与这些操作应继续串行协调，并验证跨线路同 ID、重复点击、部分失败及重新启动后的状态。

这表示用户管理本机安装集合；远端仓库内容仍按正常 Git 提交、源验证和双线路发布流程维护。
