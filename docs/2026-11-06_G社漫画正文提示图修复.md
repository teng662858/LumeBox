# G社漫画正文提示图修复

G社正文图床对 Referer 有特殊要求：使用图床自身 origin 会返回 HTTP 200 的提示图（728×728，“请到本网站阅读 manhuafree.com”），站方阅读页使用 https://g-mh.org/，返回真实漫画页。仅检查状态码无法区分。

源升级至 1.1.1，为每张正文图片返回 `imageHeaders[url]`，包含当前可用站点的 Referer 和 iOS 18 浏览器 UA。ImageContent 不读取视频载荷的 headers 字段。沿用现有图床路由和站点自己的章节解码器，不改写漫画内容。补充已验证的站点图标、网络说明及站方发布页 n.telltome.net。

## 验证

- Tabbit 浏览器对照站方图片请求与图片显示。
- 用户截图对应《元尊》第1话上“周家圣龙”（作品 mid=93，章节 id=1197418）：原有站方解码器实跑还原 10 个图片地址，与浏览器一致。10 张全部 HTTP 200、可解码、1000×1561，SHA-256 各不相同。
- 分类、列表、详情、目录实站检查通过；最新上架与默认栏目返回不同条目。
- 14 项原生回归通过，包括主站和镜像下逐图请求头经过真实 QuickJS、ImageContent 与图片管线的传递。请求头专项测试隔离解码器；真实解码另由上述实站对照验证。
- Dart 静态检查通过。未重新验收 iPhone 真机。
