# 爱丽丝书屋源（`comic/alicesw.js`）

2026-11-03。站点：爱丽丝书屋（`https://www.alicesw.com`，成人网络小说站，全站 18+，发布页 `https://alicesw.click/`）。
本源按**文字小说**交付：列表与详情声明 `mediaType:"novel"`，正文返回 `kind:"text"`，App 打开小说详情与文字阅读器；
源归属仍是 `comic` 板块（规则见 [小说阅读与综合源识别](2026-11-02_小说阅读与综合源类型识别.md)），抽屉里显示为「小说」。

## 站点结构（逐页实测）

| 用途 | 路径 |
|---|---|
| 首页 | `/`，每个 `<h2 class="layout-tit">` 一个区块（带封面大卡 + 纯文字条目） |
| 题材分类 | `/lists/{分类id}.html?page=N` |
| 总列表 | `/all/order/{update_time\|hits\|word}+desc.html?page=N` |
| 题材+排序 | `/all/id/{分类id}/order/{排序}+desc.html?page=N` |
| 原创专区 | `/original.html?page=N` |
| 排行 | `/other/rank_hits/order/hits_day\|hits_week\|hits_month\|hits.html`（固定 30 条，**不分页**） |
| 搜索 | `/search.html?q={词}&f=_all&sort=relevance&p=N`（10 条/页；`f` 可为 `_all`/`author`/`tag`） |
| 详情 | `/novel/{id}.html` |
| 目录 | `/other/chapters/id/{id}.html`（**一次给全**） |
| 正文 | `/book/{书号}/{章节hash}.html` |

- 列表条目是 `txt-list` 里的 `<li><span class="s2"><a href="/novel/{id}.html"><span class="fenleibt">[玄幻] </span> 标题</a></span><span class="s5">作者</span></li>`；
  排行页多三个 span（`.diyhot` 热度 / `.five` 字数 / `.six` 更新时间），源里把它们拼进副标题。
- 详情页给 `h1` 标题、`.imgbox img` 封面、作者/分类/热度/字数/状态几行、`.desc` 简介、`.tg` 标签。
- 正文在 `<section class="read-section">` 内的 `<div class="content_txt">`，段落是纯 `<p>`；一章一页，没有正文分页。
- **`/novel/{id}` 与 `/book/{书号}` 的编号不是同一个数字**（例：`novel/53507` → `book/54965`），
  章节地址只能从目录页取，不能拼。
- 目录页不分页：实测 6972 章的书（`novel/50074`）单页 666 KB 一次返回全部章节节点。

## 交付形态

- 35 个分类：最近更新、四个排行（本日/本周/本月/总榜）、原创专区、29 个题材（玄幻/都市/校园/穿越/同人/科幻/奇幻/系统/武侠/经典/乡村/纯爱/NTR/乱伦/凌辱/堕落/调教/熟女/萝莉/正太/伪娘/百合/耽美/媚黑/明星/反差/言情/重口/其他，顺序按站点分类面板）。
- `filters()` 只有一组「排序」：最近更新 / 人气最高 / 字数最多，落在 `/all[/id/{cid}]/order/{排序}+desc.html`。
  排行与原创专区是站点固定路径，排序对它们不生效（源里注释说明）。
- 搜索走站点自己的 `/search.html`，结果按 `.list-group-item` 解析（标题里的 `<em>` 高亮不插空格）。
- 首页 `home()` 解析站点首页的七个区块（原创专区 / 热门推荐 / 最新更新 / 乱伦 / 都市 / 同人 / 玄幻），
  取带封面的大卡与纯文字条目，`moreUrl` 直接回传到本源分类 id。

## 域名与发布页

发布页 `alicesw.click`（另有 `www.asw5.cc`）给出的地址：

| 地址 | 实测 |
|---|---|
| `www.alicesw.com` | 海外永久地址，正文完整（主站） |
| `www.alicesw1.homes` | 大陆备用，简体同源，结构与主站完全一致 |
| `alicesw.tw` | 繁体站（301 → `www.alicesw.tw`），结构一致，标题/正文是繁体 |
| `www.alicesw.quest` | **只是另一个发布页**（4832 字节跳转页，`/novel/*` 全 404） |
| `xn--vcsx64d.als1007.space` | 发布页（同上） |

`mirrors` 只放前三条（主站 + 简体备用 + 繁体），发布页写进源设置的 `openWebsite` 动作。
主站与镜像解析到 `38.46.217.x`（境外），源标注 `network:"proxy"`。
站点自带 `/prohibit/geo-block.js`：只封美国 Utah 的出口 IP，其他地区正常。

## 限制

- 列表页不给封面（只有首页大卡带封面），所以列表卡片没有图，封面在详情页才出现。
- 排行榜单页 30 条、站点没有分页参数，`hasMore` 恒为 false。
- 搜索按简体关键词归一（站点前端会做 `Simplized()`），繁体词命中偏少。
- 部分章节标题被作者写成纯数字（"1"、"2"…），源里补成「第 N 章」。
- 章节数极多的书（6000+ 章）目录页单次返回 600 KB 以上，真机首次进目录可能偏慢，但没有替代接口。
