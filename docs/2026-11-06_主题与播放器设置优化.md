# 主题与播放器设置优化

- 全局播放器设置改为默认内核概览与分组列表，各组独立详情页，返回保留修改。
- 播放中面板增加内核状态、字幕快捷开关；竖屏保留分类详情，横屏左侧分类右侧内容，分类可独立滚动。
- 支持浅色、深色自定义页面底色，限制亮度保证文字可读，纯黑背景关闭底层渐变。
- 支持保存、应用、删除配色方案，仅保存颜色，不覆盖字体、账号及模式。
- 视频源可启用独立内核、缓冲、画面与字幕偏好；关闭后恢复全局，修复弹窗状态未同步问题。
