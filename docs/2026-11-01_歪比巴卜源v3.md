# 2026-11-01 歪比巴卜 v3.0.0：原生直链（两层加密全破）

承接 `2026-11-01_歪比巴卜源v2.md`。v2 已经能按「线路 × 分集」打开站点播放器，但走的是网页播放器；
这一版把播放地址的两层加密都解开了，`content()` 直接返回 `kind:'video'`。

## 一、两层加密

### 第一层：拿播放载荷（v2 已逆出，v3 沿用）

```
Q     = <player_aaaa.url 密文> + '&next=' + ('//' + 域名 + link_next  或  '//')
key22 = md5(Q) 后 20 位 hex + ' P'
key   = base64( rc4(key22, md5(Q+'stray')) )
vkey  = base64( rc4(key22, 秒级时间戳 + md5(key22+'stray')) )
ckey  = base64( rc4(key22, md5('xn--qvr2v.850088.xyz'+'stray')) )
POST https://xn--qvr2v.850088.xyz/player/api.php  {url:Q, key, vkey, ckey}
```

实测：`key`/`ckey` 任一错 → nginx **404**；`vkey` 错仍 200 —— 服务端只校验 key/ckey。

### 第二层：解媒体地址（本次破的）

响应长这样：

```json
{"code":200,"url":"Smw1unKD…(896 B base64)","type":"mp4",
 "aes_key":"rj2/lA53y3Kd8LLD7ZL2YQ==","aes_iv":"jjKxhzBJjGWV8Lej+5O4Ag==",…}
```

**关键是 `aes_key`/`aes_iv` 不能直接当 AES 的 key/iv**，它们自己还要先过一遍 RC4：

```
K  = rc4(key22, base64decode(aes_key))   → 16 字节（实测解出 "OddfJktEbGu7gCv9" 这种纯 ASCII）
IV = rc4(key22, base64decode(aes_iv))    → 16 字节（"okjutU3RjGpWqB8Z"）
媒体地址 = AES-128-CBC / PKCS#7 解密(base64decode(resp.url), K, IV)
```

坑点记录（都试错过的）：
- 直接拿 `aes_key` 当 AES key → padding 错；
- 拿 `key22` 直接 RC4 载荷 → 乱码（那是第一层的玩法）；
- 用整条 query 或密文当 RC4 key → 乱码；
- 真正对的是「RC4 解出来的 K/IV + AES-128-CBC」。

### 怎么确认的

用 headless 的方式把站点自己的 `setting.js`（jsjiami v7，338 KB）跑在 Node 的 vm 里，
把 `CryptoJS.AES.decrypt` 和 `aesplay` 都挂上钩子，拿到真实调用参数：
`AES.decrypt(payload, Utf8.parse(rc4(key22, atob(aes_key))), {iv: Utf8.parse(rc4(key22, atob(aes_iv)))})`。
然后在源里用**纯 JS**（MD5 + RC4 + AES-128-CBC + base64）复现，和站点输出逐字节一致。

## 二、验证

```
node tools/lume-source-check.mjs sources/video/wbbb.js
=== [PASS] 歪比巴卜  v3.0.0
  chapters 4 条：高清C · 1080P / 蓝光B · 1080P / BF有广 · HD / LZ有广 · HD中字
  content  kind=video
           电影：https://wxsnsdysvp.wxs.qq.com/251/20302/stodownload?encfilekey=…&filename=BBA.mp4
                 → 206 + video/mp4，262,144 B（Range 探测，ftypisom）
  （剧集） content  https://1853039965.cdn.123clouddisk.com/1853039965/202510/醉梦/醉梦EP01.m3u8
                 → 206 + #EXTM3U，40,452 B
```

- 电影是**整片 mp4**（976 MB，`content-range: 0-1023/976595905`），不是试看片段；
- 剧集是 HLS 清单，分片同域；
- 拿不到直链时会自动退回网页播放器（`console.warn` 留痕），不会整条挂掉。

## 三、限制

- 站内搜索仍被 WAF 拦（本地索引兜底）。
- 站点对高频请求会回 **429**，连续验证要间隔几十秒；源里遇到 429 会报「站点限流，稍后再试」。
- 媒体地址带时效（`encfilekey`/`token`、`?e=` 之类），所以 `content()` 每次现解，不做缓存。
