# 小说与漫画朗读

小说阅读页顶部有「朗读」和「朗读设置」。点耳机开始朗读，再点暂停，暂停后再点继续。小说会从当前页开始，可使用停止按钮结束朗读；在朗读设置中可调整语速、音量，并选择是否跟读翻页和读完自动下一章。离开阅读器会停止。漫画阅读器的朗读入口先识别页面文字，再使用同一套朗读模式；漫画按单一旁白朗读，不自动区分角色。

## 选择声音

在朗读设置中选择模式和旁白音色。系统朗读使用设备已有的系统声音；「本地离线朗读」使用 sherpa-onnx VITS 音色包：首次选择后下载约 147 MB，安装期间建议预留至少 600 MiB；安装后可离线朗读，设置中可删除。已安装的音色包继续使用，无需重新下载。

### 小说旁白与对话音色

1. 打开小说，在阅读页面点“朗读设置”，选择系统、本地离线、Kokoro 或在线朗读模式。
2. 打开“自动识别对话并切换音色”。
3. 分别点“旁白音色”“男声音色”“女声音色”，各选一种声音；想听出区别可先选不同音色。
4. 返回阅读页面开始朗读。关闭自动识别后，整篇都使用旁白音色。

普通识别主要识别每行开头的“角色名：台词”，未知角色按规则分配到男声或女声，不保证真实身份或性别准确；普通引号对话也可能由旁白读。在线 AI 增强会尝试分析上下文，需要网络与大模型接口，失败时退回普通识别。当前最多区分旁白、男声、女声三类，不能为四个具体人物各指定声音。漫画朗读使用单一旁白，默认从当前页连续读到本章末，也可选择“仅读本页”。

### Kokoro 离线朗读

1. 选择「Kokoro 离线朗读」，首次使用确认下载约 147 MB 的模型，安装期间建议预留至少 600 MiB，安装完成后约占 205 MiB。界面会显示下载进度、校验和解压阶段，也可取消；解压期间需等待当前步骤结束。下载完成并校验后可离线朗读。
2. 在旁白音色中选择声音。编号 3–57 为中文女声，58–102 为中文男声，0–2 为英文声音。
3. 小说可开启「自动识别对话并切换音色」，分别设置旁白、男声和女声。角色判断是启发式结果，可能识别错误；关闭开关则全程使用旁白。

模型下载自 sherpa-onnx 的 GitHub 发布页，国内网络不可达或空间不足时可重试。朗读设置中可删除 Kokoro 音色包，删除前请停止朗读；原有 VITS 不会被替换。

### MiMo 在线朗读

1. 在小米 MiMo 开放平台创建 API Key。确认该模型当前的价格、额度和账户权限。
2. 在朗读设置中选择「在线朗读 · 标准」，打开「配置在线接口与密钥」，服务商选择「小米 MiMo」，填写 API Key 并保存。
3. 在旁白音色中填写 `冰糖`、`茉莉`、`苏打`、`白桦`、`Mia`、`Chloe`、`Milo` 或 `Dean`；中文建议先试冰糖或白桦。未填写或标识不支持时使用冰糖。
4. 开始朗读。小说正文会发送给小米生成语音，需要联网；平台可能计费，重复合成也可能增加用量。密钥存储在设备 Keychain，不要分享给他人。

「在线朗读 · 智能」的自动对话识别还需要另行配置大模型接口，可能产生额外费用；识别失败时会退回普通识别。MiMo 的语速由文字指令提示，实际效果由服务端决定。

## 排查

- 没有声音：检查音量、静音和当前模式；系统朗读需要设备可用的系统声音。
- Kokoro 下载失败：检查网络和剩余空间后重试。模型校验不通过不会启用。
- MiMo 失败：检查 Key、账户权限、网络和服务价格；不要把 Key 发到聊天或截图中。
- 漫画没有朗读：确认当前页图片清晰且有可识别文字，漫画文字识别需要 iOS。

模型、平台接口和音色可能变化；使用前以服务商当前文档与页面为准。
