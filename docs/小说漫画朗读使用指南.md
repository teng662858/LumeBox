# 小说与漫画朗读

小说阅读页顶部有「朗读」和「朗读设置」。点耳机开始朗读，再点暂停，暂停后再点继续。小说会从当前页开始，读完当前章后继续下一章；开启跟读时，页面跟随朗读位置。离开阅读器会停止。漫画阅读器的朗读入口先识别页面文字，再使用同一套朗读模式；漫画按单一旁白朗读，不自动区分角色。

## 选择声音

在朗读设置中选择模式和旁白音色。系统朗读使用设备已有的系统声音；原有「本地离线朗读」仍使用 VITS 音色包。

### Kokoro 离线朗读

1. 选择「Kokoro 离线朗读」，首次使用确认下载约 147 MB 的模型。需要网络及额外解压空间，下载完成并校验后可离线朗读。
2. 在旁白音色中选择声音。编号 3–57 为中文女声，58–102 为中文男声，0–2 为英文声音。
3. 小说可开启「自动识别对话并切换音色」，分别设置旁白、男声和女声。角色判断是启发式结果，可能识别错误；关闭开关则全程使用旁白。

模型下载自 sherpa-onnx 的 GitHub 发布页，国内网络不可达或空间不足时安装会失败。现有 VITS 不会被替换。

### MiMo 在线朗读

1. 在小米 MiMo 开放平台创建 API Key。确认该模型当前的价格、额度和账户权限。
2. 在朗读设置中选择「在线朗读 · 标准」，打开「配置在线接口与密钥」，服务商选择「小米 MiMo」，填写 API Key 并保存。
3. 在旁白音色中填写 `冰糖`、`茉莉`、`苏打`、`白桦`、`Mia`、`Chloe`、`Milo` 或 `Dean`；中文建议先试冰糖或白桦。未填写或标识不支持时使用冰糖。
4. 开始朗读。小说正文会发送给小米生成语音，需要联网；平台可能计费，重复合成也可能增加用量。密钥存储在设备 Keychain，不要分享给他人。

「在线朗读 · 智能」的自动对话识别还需要另行配置大模型接口，可能产生额外费用；识别失败时会退回普通识别。MiMo 的语速由文字指令提示，实际效果由服务端决定。

## 排查

- 没有声音：检查音量、静音和当前模式；系统朗读需要设备可用的系统声音。
- Kokoro 下载失败：检查网络和剩余空间后重试。模型校验不通过不会启用。
- MiMo 失败：检查 Key、账户权限、网络和服务价格；不要把 Key 发到聊天或截图中。
- 漫画没有朗读：确认当前页图片清晰且有可识别文字，漫画文字识别需要 iOS。

模型、平台接口和音色可能变化；使用前以服务商当前文档与页面为准。
