# 夜社资源综合源（`video/yeshezy.js`，`yeshezy_video`）

2026-11-02 · 用户给的 `https://yeshezy1.com/`

## 一、站点是什么

夜社资源是**苹果CMS（maccms）+ panghu 模板**的综合成人资源站，首页口径：

> 15.9w 视频 · 2.1w 有声 · 10.7w 写真 · 3.2w 漫画 · 2.5w 小说 · 2.8k 吃瓜 · 12.7w 影视

七大类：视频 / 有声 / 写真 / 漫画 / 小说 / 夜生活 / 影视。站点同时对外提供采集 API
（`/api.php/provide/vod/`），但那个要绑定授权域名（返回「域名未授权」），本源全程走页面解析，匿名 GET。

## 二、页面结构（实测）

```text
分类      /vodtype/<cid>.html          第 N 页 /vodtype/<cid>-<N>.html    30 条/页
视频详情  /voddetail/<vodId>.html      → 「第1集$https://…/play.m3u8」逐集内联
视频播放  /vodplay/<vodId>-<线路>-<集>.html
图集详情  /voddetail/<vodId>.html      → 「1P$https://…/001.jpg」逐页内联（写真/漫画同构）
小说分类  /arttype/<aid>.html          第 N 页 /arttype/<aid>-<N>.html
小说详情  /artdetail-<artId>.html      → 章节 /artrss-<artId>/nid/<n>.html
搜索      /vodsearch/<词>----------<N>---.html                        20 条/页
```

**列表卡片的标题在 `<a title="…">` 属性里**（`<div class="title">` 也有一份），
封面是 `<img src>`，分类/集数是 `<span class="type">` / `<span class="time">`。
第一版按 `class="…title…"` 抓，抓到的是「AI短剧 共4集」，改成读 `a[title]` 才对。

## 三、一个源怎么装下七大类

App 的视频板块只渲染 `video` / `audio`，图片与文本会报错（`comic_reader_page` 那边反过来只认 `images`）。
所以 `content()` 按详情页的实际形态分派：

| 类型 | 详情页特征 | 返回 |
|---|---|---|
| 视频（AI短剧/国产/日本AV/欧美/韩国BJ/H动漫/影视短剧） | 内联 `…m3u8` | `{kind:'video', url, headers}` |
| 有声（有声小说/淫词艳曲/激情骚麦） | 内联 `…m3u8`（音频 HLS） | `{kind:'audio', url, headers}` |
| 写真 / 漫画（秀人/网红COS/各国套图/AI绘图/内购私拍/机构套图/韩国H漫/日本H漫/3D漫画） | 内联 `1P$…jpg` | `{kind:'webplayer', pageUrl:'/vodplay/<id>-1-<n>.html'}` |
| 小说（7 个分类） | `/artrss-…/nid/…` 章节 | `{kind:'webplayer', pageUrl:'/artrss-…'}` |

图集与小说走 App 内嵌网页（站点自己的播放页 / 正文页），等于**一个源覆盖整站**；
视频与有声是原生播放，HLS 直连实测 206 + `#EXTM3U`。

## 六、限制

- 全站 18+；`contentCategory: adult`，`yeshezy_video` 已进 `adultIds` 与源仓库 `content-ratings.json`；
- 图集与小说是**内嵌网页阅读**（App 视频板块不渲染图片/文本）；视频与有声是原生播放；
- 采集 API 不可用（域名未授权），只能靠页面解析；站点换域名时改 `MIRRORS` / `BASE_FALLBACK`；
- 「吃瓜」(2.8k) 没有独立分类入口，站点导航里未对外开放；
- 详情页把地址内联在 HTML 里，一旦改成播放页二次加载，要去 `/vodplay/<id>-1-<集>.html` 里取。
