## 二、页面结构（实测）

```text
分类  /index.php/vod/type/id/<cid>.html
      第 N 页 /index.php/vod/type/id/<cid>/page/<N>.html        50 条/页
详情  /index.php/vod/detail/id/<id>.html
搜索  /index.php/vod/search.html?wd=<词>&page=<N>               50 条/页
```

站点公告写「本站不提供在线正版播放，复制地址到浏览器观看」，但详情页其实把地址全内联了，按来源分组：

```html
<h3>来源：黄色仓库云</h3>          → 正片$https://hsckyun.yeffpe.com/share/a3/…   （网页）
<h3>来源：黄色仓库资源m3u8</h3>    → 正片$https://hsm3.hwzcfz.com/a3/…/index.m3u8（直链）
```

两种来源分别对应 `webplayer` 与原生播放，所以 `chapters()` 把每条线路都列出来：

```text
0|0 黄色仓库云            → kind webplayer（share 页，实测 200）
1|0 黄色仓库资源m3u8      → kind video（master 200 → 2000kb/hls/index.m3u8 子列表 22,550 B
                              → 分片 200 video/mp2t 431,280 B）
```

列表页是**纯文字表格**（`<span class="xing_vb4">` 里放标题 + `[高清]`），没有封面；
封面统一在详情页取（`img.uyjthen.com/upload/vod/…jpg`），核验时封面字段在列表里是空的、详情里有值。

## 三、源的实现

- 41 个分类入口（5 个大区 + 36 个叶子），`list()` 走 `/vodtype/id/<cid>`；
- `detail()` 标题去掉「剧情介绍--黄色仓库资源站」后缀，取第一张图做封面、面包屑取分类、`vodplayinfo` 取简介；
- `chapters()` 按「来源分组 × 地址」展开，`content()` 按线路形态分派 video / webplayer；
- 搜索 `/index.php/vod/search.html?wd=`（GET，50 条/页，可翻页）。

## 五、限制与失效预案

- 全站 18+；`contentCategory: adult`，`hsckzy_video` 已进 `adultIds` 与源仓库 `content-ratings.json`；
- 列表页无封面（站点模板如此），详情页才有；
- 线路「黄色仓库云」是 share 网页，走 App 内嵌网页播放；要原生播放请选「黄色仓库资源m3u8」那条；
- 换域名：`hsckzy.vip` 打不开时用发布页给的其它域，改 `MIRRORS` / `BASE_FALLBACK`；
- m3u8 主机 `hsm3.hwzcfz.com` 换域时，从一个新详情页里读新的 m3u8 主机名。
