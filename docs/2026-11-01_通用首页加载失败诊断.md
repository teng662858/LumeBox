# 通用首页加载失败诊断

共享状态分类新增地址无法解析、网页验证及页面内容未识别三类状态。首页错误卡使用分类后的标题、恢复建议和原始报错；列表与详情使用的公共状态卡也支持这些状态。超时、HTTP 和连接错误不再全部显示为脚本错误。

DNS 失败只提示检查网络与站点地址，不判定域名已过期。普通解析失败只说明可能返回非预期页面或结构变化，不推断为验证码。HTTP 403 不单独认定为网页验证；已有验证入口规则继续适用。TypeError、ReferenceError 和 SyntaxError 保持脚本错误。

首页错误区域可滚动，操作按钮可换行。重试继续刷新首页及分类元数据，保留已有验证和 TLS 提示行为。

验证：状态分类、六种首页失败、重试恢复、短屏长错误、公共状态卡、首页及验证相关共 71 项测试通过；修改文件静态检查无问题。测试使用通用模拟源，不访问或修改任何具体站点源。

本改动属于 App，需要安装包含此提交的新版本；订阅更新不更新 App 错误展示机制。
