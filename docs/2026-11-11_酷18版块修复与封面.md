# 酷18 版块修复与封面（2026-11-11）

用户反馈：`酷18` 有些版块打不开、列表没有封面。2026-11-11 复测站点后分成两类改。

## 1. 版块打不开：色色动漫 / 成人影视 变登录可见

实测（`Cookie: isok=true`，年龄门已过）：

| 板块 | 帖子的正文区 | 结论 |
|---|---|---|
| `bbs4` 禁忌书屋 / `bbs5` 情色趣闻 / `bj` 性趣论坛 | `<pre>` 正文 | 正常 |
| `bbs` 性趣贴图 / `bbs2` 情色靓影 / `bbs6` 私房自拍 / `enter6` 卡通漫画 | `<pre>` 内 `<img>` | 正常（一帖 50–100 张图） |
| `bbs7` 色色动漫 | 只剩 `div.login-container`「请登录社区账户」 | **改成必须登录**（以前可匿名看） |
| `bbs3` 成人影视 | 只剩 `div.login-container` | 必须登录（已知） |

抽测 4 个 `bbs7` 帖子、4 个 `bbs3` 帖子，全部只有登录框，页面里没有 `m3u8`/`mp4`，
说明不是「回复可见」而是站点整体改成账号可见。源里不再抛「没解析到图片」/「要求登录」的死错，
改为：

```js
var gated = /login-container/i.test(html) || /请登录社区账户/.test(html);
if (gated) return { kind: 'webplayer', url: pageUrl, pageUrl: pageUrl, headers: {...} };
```

App 会用内嵌网页打开帖子页（会话按源保留），用户登录一次之后视频播放器/图集都能看；
漫画板块的详情页检测到 `CatWebParseRequired` 会转到视频式网页播放页，这条链路已有。

## 2. 图片板里的广告帖不再算「整块坏掉」

`bbs7`/`bbs`/`bj` 列表顶部常有「❤❤搜网页 71k.top」这类广告帖，正文没有图。
以前 `content()` 在图片板没图时直接抛错，等于把一个广告帖当成整个板块坏了。
现在图片板没图时退回正文（广告帖是纯文字），正文也没有才报错。

## 3. 列表类型按板块声明

`mediaType` 以前一律 `novel`，图片板条目会被当成小说打开；现在按板块声明：

- 文字板（`bbs4`/`bbs5`/`bj`）→ `novel`
- 图片板（`bbs`/`bbs2`/`bbs6`/`enter6`/`bbs7`）→ `comic`
- 影视板（`bbs3`）→ `video`

详情页同样按板块给 `mediaType`（以前影视板也写 `novel`）。

## 4. 封面

- **文字板没有封面**：站方帖子正文是纯文字，抽测 6 个 `bbs4` 帖子正文图数全是 0，
  列表页也不给缩略图。App 的占位图就是这类源的最终形态，不编造图。
- **图片板用懒封面**：列表项 `cover` 放帖子地址 + `x-lume-image-page-selector:
  '#content-section img'`，App 只给屏幕上的卡片按需解析首图（`img.xwbo.com`，实测 200
  `image/jpeg`，带不带 Referer 都行）。`bbs7` 已登录可见，解析到的是登录框，所以不再挂懒封面。
- **首页**原来三个板块全是文字板（首页一片占位图），改成「禁忌书屋 / 情色趣闻 / 情色靓影」，
  第三块带图，首页能看到封面。

## 5. 狂人之家书屋：补上列表与详情封面

同一轮顺手修的新源（`comic/crazyhome.js` v1.0.2）：

- 站点小说的章没有 `featured_media`，但书的**标签页**每条都带站方预览图
  （`uploads/2026/10/crazyhome2000.com_preview001-15.webp` 这类）。
- 列表项改成「懒封面」：`cover` = tag 页地址 + `x-lume-image-page-selector:
  'img.wp-post-image'`，App 按需解析；实测《夺人母爱（重修版）》拿到
  `preview001-8-480x300.webp`（200 `image/webp`），《赘婿的荣耀》拿到 `preview001-15`。
- 详情页多取一次 tag 页直接给真图地址（980–1040 ms，仍在预算内）。
- 「AI美图共享」的图集帖本来就有特色图，走 `/media?include=` 优先，不被预览图覆盖。

```

  categories 9 / filters 3 档 / list 202 hasMore:false / detail / chapters / content
  正文 12418 字（禁忌书屋）

逐板块（9 个全 PASS）：
  bbs4/bbs5/bj/bbs/bbs2/bbs6/enter6 → content kind=text / images(100 张)
  bbs7 → content kind=webplayer，url=bbs7 帖子页
  bbs3 → content kind=webplayer，url=bbs3 帖子页
```

- 列表 `mediaType` 抽验：`bbs4` → novel（无封面）、`bbs2` → comic（tag 页懒封面）、
  `bbs7` → comic（无懒封面）、`bbs3` → video（无懒封面）
- 热门榜 `bbs2 + sort=hot` 100 条，首条 `mediaType=comic`
- `comic/crazyhome.js` 四个列表入口（latest / 分类 / 搜索 / 书库）都带 tag 页懒封面；
  详情区分「特色图」与「tag 页预览图」两条路径
- `flutter test test/source_content_rating_test.dart` 不受影响（评级未变）

## 7. 仍有的限制

- `bbs7` / `bbs3` 必须登录：不登录时 App 打开的是帖子页登录框，登录后才有内容；
  源无法替用户填账号密码。
- 文字板列表/详情没有封面（站方没有任何缩略图）。
- 图片板首图按需解析，一屏 12 张卡片 ≈ 12 次帖子页请求；列表本身仍然只请求 1 次。
