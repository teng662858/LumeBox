# 源自动分类与本机安装反馈

## 两张截图对应的问题

- 仓库上传要求手选目录与脚本声明一致，且把阅读源也按视频规则强制校验 contentCategory；失败只显示技术字段，没有安装到本机。
- GitHub 仓库列表与本机已安装列表是两回事，之前只有上传/删除，没有安装按钮，上传发布后也不自动安装。
- 总订阅把有声清单放进漫画板块，但七份旧脚本仍有 video/audiobook 归属声明，旧版 App 拒绝；页面又直接展示全部 URL 和堆叠错误。

## 修改后的行为

- 普通导入按脚本声明和媒体类型自动选板块：漫画、美图、文字小说、有声进入漫画；影视、视频进入视频；猫源仍用专属入口。没有可靠声明时保留用户已选板块，不根据文件名猜测成人分级。
- Python 的 `# LumeSource`、JS 的 `// LumeSource` 使用相同媒体识别规则。有声类型优先于泛化的影视标签。
- 成功导入通知目标板块的变更监听，刷新源选择；被隐藏或停用时提示原因，不偷偷改用户的显示/启停设置。
- 仓库页增加“添加到本机（不上传 GitHub）”及每条源的安装按钮、已安装板块标记。发布时自动确定目录，缺少可靠影视/成人分类时仅询问一次，补齐发布元信息；普通 REX 等无仓库头的模块引导走本机导入。
- 仓库发布成功后读取最新目录及其固定 blob，安装到对应本机板块。待安装路径随发布任务保存，重开页面可继续；目录尚未出现时明确报错，保留待安装状态。上传后切换到对应分类并清空旧搜索，避免新源被旧筛选遮住。
- 总订阅先显示各板块新增、更新、已存在、移除及待处理数量。“已存在”解释为相同版本已在手机中，不是重复添加。详细错误默认折叠，点开可看简明原因、再查看或复制完整诊断。
