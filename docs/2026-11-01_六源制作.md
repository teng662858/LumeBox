### 1. 子子影视（`ziziys_video`）

- 发布页 `www.ziziys.info` 列出：主用 `www.ziziys.org`、`www.ziziys.net`、`www.ziziys.com`（官方标注「国内无法访问」）。

- 与仓库已有的 `4kvm`/`bttwo` 是**同一套 CMS**：`/filter?page=N`（24 条/页真分页）、`/movie /tv /anime`、
  `/search?q=`、`/play/<slug>`，播放签名 `s = HMAC-SHA256(key=slug, msg="<dataid>:<t>:<slug>")[:32]`、
  `k = base64(xor("nbmovie2024secretkey", userlink))`（bttwo 已逆出，本源复用它并核对过本站）。
- 实测播放（`/video/play?p=41836&v=ch4ruaazi&q=1080&s=…&t=…&k=…`）：
  `{"code":200,"quality_urls":[{"title":"4K","isvip":true,"locked":true,"url":"1"},{"title":"1080p","isvip":false,"locked":false,"url":"https://oss.douyinbit.com/m3u8/…m3u8"}]}`

  `q=4k` → `{"code":403,"message":"4K清晰度仅支持客户端播放，Web端不支持"}`。1080p 免费档对匿名全开，

### 6. 爱壹帆（`iyf_video`）

- 站点配置里自带同内容域名：`iyf.tv` / `aiyifan.tv` / `wyav.tv` / `flyv.tv` / `jssp.tv`（已进 `mirrors`）。
- 数据在 `m10.iyf.tv`，两套前缀：`/api/*` 与 `/v3/*`。**每个请求都要签名**：
  首页 HTML 里服务端渲染 `"pConfig":{"publicKey":"…","privateKey":["…"]}`（每次请求都变），
  请求 query 后追加 `&vv=<md5(publicKey + "&" + query.toLowerCase() + "&" + privateKey[0])>&pub=<publicKey>`。
  少它回 `{"code":1,"msg":"用户签名错误"}`；带上即 `code 0`。**哈希用的是 URL 解码后的 query**
  （前端 `get_query()` 会 decodeURIComponent 每个值），所以 `cid=0,1,3` 必须按原样参与哈希、发送时才编码。
- 接口：`/api/list/index?cinema=1&page&cid&size&isn&isfree[-&region]`（`cid` 路径：电影 `0,1,3`、电视剧 `0,1,4`、
  综艺 `0,1,5`、动漫 `0,1,6`、纪录片 `0,1,7`）、`/v3/video/detail`、`/v3/video/languagesplaylist?vid&lsk=0&taxis&cid`、
  `/v3/video/play?id&cinema=1&a=1&lang&usersign=1&region=GL.&device=1&isMasterSupport=0&sharpness&line`。
- 播放实测：`video/play` 返回 `flvPathList[]`，`isHls:true` 的 `result` 是 `https://sss111-e1.pipecdn.vip/…/chunklist.m3u8?vendtime=…`；
  非 HLS 的一条是 20 秒的 mp4 预告片。选集从 `languagesplaylist` 取（电影只有 1 条 `name:"1080P"`）。
- 筛选：站点 `GetSearchCondition` 给了 isSerial/language/region/year/plat，实测只有 **region**（地区）
  与 **isSerial**（连载状态，`isn`）在 `list/index` 生效；`year`/`lang` 传了会被忽略，故不列。
- **限流**：短时间连续请求会回 `{"code":5,"msg":"访问过量"}`（本机 2 秒内发 6 个请求即触发），
  源码里已把 detail 结果缓存 10 分钟、每次调用只发一个请求，并把 code 5 转成可读错误。
- VIP：条目带 `charge/vipResource`、`play` 返回 `isPreView/isLimitedStream`；免费篇整片、收费篇服务端截断，
  本源如实提示「不伪造」。

## 四、限制（交付时同步写在源文件头）

1. **爱壹帆限流**：`video/play` 对同一出口很敏感。实测时间线：
   - 01:00 连续调用时正常，返回 `flvPathList`（HLS 一条 `https://sss111-e1.pipecdn.vip/…/chunklist.m3u8?vendtime=…`、
     另一条是 20 秒 mp4 预告）；
   - 01:07 起（约 12 次 play 之后）该出口开始回 `{"code":5,"msg":"访问过量"}`，到 **02:10 仍未恢复**（63 分钟）；
     期间换未播过的视频、换 warm session、走本机代理（7890/7891/7892 三个端口出口 IP 都是同一个）、
     换后端主机（`api10.iyf.tv` DNS 不通、`api.iyf.tv/api/video/play` 404、`m10.iyf.tv/api/video/play`
     同样 code 5）全部无效，确认是按出口 IP 计的限流；
     期间 `/api/list/index`、`/v3/video/detail`、`/v3/video/languagesplaylist` 全部正常，说明只挡 play 这一个端点。
   - 复验方式：换出口（家用宽带/手机热点）或等限流窗口过去，再跑
     `node tools/lume-source-check.mjs sources/video/iyf.js`；源码已做 detail 缓存（10 分钟）与一次 3.5 秒重试，
     并把 code 5 转成可读错误。
   - 归集到的一次真实 m3u8（01:00 那次 play 的返回）现在仍可播：**200 + application/vnd.apple.mpegurl，21,741 B**。
2. **嘀嗒影视的蓝光线路**：地址是 hex 密文，由站点 artplayer 页里的混淆脚本现解；本源不复刻混淆代码，
   这类线路走 App 网页播放器；网盘线路标注为不可在线播放。
3. **多多追剧的播放**：令牌解码要站点 `decode/url` 的 protobuf + wasm 签名（`get_signature_headers`），
   纯 JS 沙箱算不出 → 网页播放；其余（分类/筛选/排序/搜索/详情/线路集数）都是真数据。
