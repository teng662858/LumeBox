# 内容与播放增强（2026-11-07）

本批范围按用户最后指示收敛：不发布 iOS 小组件／快捷指令／Spotlight／系统更新通知，不接个人媒体库或媒体服务器，不扩展 iCloud。相关试做仅留在本地 work/deferred_experience，不进入提交；已有 iCloud 保持原样。

## 使用入口

设置 → 阅读与播放 → 内容中心／内容与播放增强。历史抽屉增加内容中心入口，首页布局保持原样。

- 继续：跨板块汇总有进度的阅读、视频与媒体库听书记录，按最近时间排序；手工关联的作品只保留最近版本。隐藏条目不删除原进度。
- 追更：首次检查建立目录基线，后续新增进入更新收件箱；重排不算更新，空目录不覆盖基线。暂停／已完结条目跳过，停用或连续失败源可跳过。逐源串行、15 分钟内不重复检查；自动检查默认关闭，开启后回到前台每六小时最多一次，不能保证 iOS 后台持续执行。
- 阅读离线：默认关闭。开启后漫画加入已有离线下载中心，小说缓存后续正文；复用已缓存小说，不重复请求。可配置后续 1–5 集／章。
- 离线策略：Wi-Fi、保留空间、播放时暂停、已看清理分别开关，默认关闭。清理只针对 App 内已播放完成且文件保存超过七天的视频，不影响已导出副本。未知网络时不会当成 Wi-Fi。
- 播放恢复：默认关闭。可开启同作品备用线路尝试，跳过登录／授权失败；不与原有 AVPlayer 分段兼容降级抢同一次操作。
- 字幕：播放设置 → 外挂字幕 → 在线搜索／双语字幕。OpenSubtitles API Key／用户令牌本机加密保存，不进备份；字幕下载站不接收账户头。支持两个本地 SRT/VTT 合成双语、语言偏好与按剧集记忆外挂字幕。
- 源能力档案：汇总运行、搜索、封面、目录、解析与最近实际起播记录；需要登录／网页验证如实显示。封面仅解析未探活时标为待实际加载验证。
- 作品关联：从历史和收藏中手动选择原著、改编或不同版本，保存关联，不按同名自动合并、不覆盖各源进度。
- 统一摘录：视频保存时间点、漫画保存页码、小说保存可编辑正文段落、听书保存书签。可选择收藏夹、备注、定位打开，按收藏夹复制或导出 JSON。
