## 一、先解决「打不开」的问题

`18comic.vip` 和 `jmcomic.me` 在本机一律 `403 Just a moment...`（Cloudflare managed challenge），
公共 CORS 代理（allorigins / codetabs / corsproxy）也全是 522 / 403。
逐个试发布页给出的域名时发现 **`18comic.ink` 直连 200**（首页 704 KB，全部频道可读），
所以两个源默认用 `18comic.ink`，`.vip` / `jmcomic.me` 留在 `mirrors` 里；
在这两个域名上请求会抛 `NEED_WEBVIEW_VERIFY`（文案里直接提示换镜像）。

## 二、H動漫（视频）

- 列表：`/videos?o={mr|mv|mp|tr|md|tf}&t={a|t|w|m}&page=N`，一页 40–50 条，**翻页/排序/时间都实测生效**
  （`?o=mv`、`?t=w`、`page=2` 首条互不相同）。
- 卡片：`<a href="/video/{id}/{slug}">` 里是 `.thumb-overlay` + `img[data-original]`（`/media/videos/pic_s/{id}.jpg`），
  旁边 `.video-factory`（片商）/`.video-view`（👁️ 播放数）/`.video-added`（日期）。
  ⚠ 站点有两种链接写法（`<a href="/video/…">` 与带 class 的 `<a class=… href="/video/…">`），
  按 `href="/video/` 切块才能把 40+ 条都抓到（按 `<a href=` 切只有 12 条）。
- 详情：`/video/{id}/`，`h1` 是标题，`og:image` 是封面（`/media/videos/tmb/{id}/default.jpg`）。
- 播放：页面内联 `<source src="https://ms18comic-2.iiooxx.rocks/…/hls/{iphone|hd}/{id}.mp4/index.m3u8?e=&st=" type='application/x-mpegURL'>`。
  签名带时效、且某些清晰度不一定存在（实测 6930 的 `hd` 是 404、`iphone` 是 200），
  所以 `content()` 依次试前 4 条源，第一个 200 + `#EXTM3U` 的作为默认并全部放进 `qualities`。
  实测 206 + `application/vnd.apple.mpegurl` + 6.5 KB master。

## 三、JM文庫（小说）

- 入口：`/novels?o={mr|mv|mp|tf}`（禁漫小說），单页 **78 部**，站点**没有翻页控件**；
  `?t=`（时间）实测回 0 条，所以**只声明排序**，不放假的时间筛选。
- 卡片：`.thumb-overlay-albums` → `<a href="/novel/{id}/{slug}">` + `img[data-original]`（`/media/novels/{id}_tmb.jpg`）。
- 详情：`/novel/{id}/`，`h1` = 「[作者] 标题 | 原名」，封面取 `img[data-original*="/media/novels/"]`
  （`og:image` 是站点 logo，已排除）。
- 章节：详情页里是 `<a href="/novelchapters/{n}" data-album data-index> <li>2. 第1.2話 …` 这种块级链接，
  按 `href="/novelchapters/` 切块取 id、从 `<li>` 里取标题，再按章节号排序（实测一本 14 章）。
- 正文：`<div id="ncc1" class="novel-content">` 与 `<div id="ncc2" class="novel-content">` 两栏，
  `<br />` 分行、纯 `<p>` 段落，**未登录可读**（页面里虽有「金幣購買」弹窗的 JS，但正文照常下发）。
  实测第 1 章 4317 字、第 13 章 2865 字。

## 六、限制

- `.vip` / `.me` 两个官方域名在本机被 CF 挡住，源里只能提示换 `.ink`；`.ink` 挂了要在 mirrors 里再加可直连的镜像。
- H動漫的 m3u8 是「页面现签 + 时效」，`content()` 必须先开播放页；签名过期时会把全部源试完再报错。
- JM文庫列表单页 78 部、没有翻页；排序是唯一能翻动内容的维度。
- 小说详情页的章节列表可能只列站点给的那部分（这本 14 章全在），超长连载若分页需要再补解析。
- 漫画源（`comic/禁漫天堂.js`）是仓库里已有的，本次没有改。
