# 有爱爱 UAA 综合源（`video/uaa.js`）：Cloudflare 旁路与 VIP/U币 绕行记录

2026-11-02 · 站点：`www.uaa002.com`（官方永久域名 `uaa.com`，发布页 `uaadizhi.com`）

## 一、站点形态

- Spring Boot 服务端渲染（Thymeleaf）+ 独立 JSON 接口，一个站四个内容库：
  视频 `/video/*`、有声 `/audio/*`、漫画 `/comic/*`、小说 `/novel/*`；另有直播 / 美图 / AI / 坊市，未做。
- 站群：`uaa001`–`uaa010`、`uaa2601`–`uaa2610` 全部 21 个域名实测 `200` + 同一份首页（34,694 B，
  标题「想爱爱上有爱爱 www.uaa.com」）。`uaa.com` / `www.uaa.com` 对脚本请求直接 403（CF「Attention Required」），
  只做 mirrors 手选，不进脚本自动路径。
- 全部匿名可读：列表 / 详情 / 章节 / 取流都不需要登录。

## 二、关键通路：`/api/` 前缀不过 Cloudflare 校验

网页侧实测：

| 请求 | 结果 |
|---|---|
| `https://www.uaa002.com/` | 403 `cf-mitigated: challenge`（「Just a moment…」，`cType: managed`） |
| `/js/video.js`、`/css/main.css`、`/image/logo.webp`、`/manifest.json` | 同上 403 |
| `/api/web/home` | **200**，34,694 B 完整首页 HTML |
| `/api/web/js/video.js`、`/api/web/image/logo.webp` | **200**（静态资源也走 `web` 服务的路由） |
| `/api/video/app/video/intro?id=…` | **200** JSON |

即站点的 CF 规则只挡页面/静态直连，`/api/` 全放行。本源把**所有页面请求都加 `/api/web` 前缀**，
JSON 接口走 `/api/<服务>/app/...`，因此不需要网页视图过校验；App 自带 UA（iOS 17 Safari 串）实测同样 200。

浏览器里实测：Tabbit 打开站点会卡在「正在进行安全验证」，`challenges.cloudflare.com` 的
`/pat/`、`/i/` 请求 `ERR_CONNECTION_CLOSED` —— 本机网络到校验域的链路就断的，硬过校验不可行，
所以这条 `/api/` 通路是本源能成立的唯一前提。

## 三、VIP / U币 挡在前端，接口照样给全量

站点 VIP 权益写的是「无限量内容，不再需要 U币（AI 除外）」，具体门槛分四层，全部只在前端：

| 层 | 站点做法 | 实测证据 |
|---|---|---|
| 视频 60 秒试看 | `video.js#gateTick`：`#mui-player` 的 `code != 0` 时 `currentTime = 58` 并弹「试看结束」 | 匿名 `intro` JSON 返回 **`code:1` 但 `model.url` 就是整片 m3u8**。`xc2026103109` 清单 22,349 B / 794 段，`#EXTINF` 合计 **2381.3 秒**，与详情 `duration:2381` 完全一致；分片 `206 image/jpeg`，`content-range …/1006364`。`su2026102313` 同理（886 段 / 3668.2 秒） |
| 每日免费额度 | `reportWatched()` 播满 60 秒才 `POST /video/free/consume`，服务端按 cookie 里的 `viewId` 记账；额度满 `code` 变 2/3/4 | 源里**不调** `consume`，且每次请求现生成 `viewId`（`Date.now()+4位随机`）。实测连续 16 条 `intro` 全是 `code:1` + 完整 `url`，`limitCount:0` |
| 漫画 U币 解锁 | 章节页有「支付 0.1U币解锁此话」按钮 | 章节页 SSR 内联 `var chapter = {…}`：`price:0.3` 的章节照样把整话 `images` 全给出（实测 26 张 / 48 张），首图 `200 image/jpeg` |
| 小说付费章节 | 章节页有「支付 0.3U币解锁此话」「此章节为付费章节」 | 正文就是 SSR 的 `div.line`。页面自称「字数：N」，实际交付字符数**与 N 完全相等**（4886 / 111），即正文没有截断 |

结论按仓库《VIP处理约定》的判定顺序属于**第 1 条「页面层可绕」+ 第 4 条「接口不鉴权」**：
地址本来就在响应里，前端只是加了个遮罩与计数。

## 四、接口清单（本源用到的那几条）

| 用途 | 请求 |
|---|---|
| 视频列表 | `GET /api/web/video/list?keyword=&searchType=1&category=&origin=&tag=&sort=<1\|3\|4>&page=N`（48 条/页，真分页 1333 页） |
| 视频搜索 | `GET /api/video/app/video/search?keyword=<词>&page=N&viewId=<串>`（20 条/页，`totalCount`/`totalPage` 真实） |
| 视频详情/取流 | `GET /api/web/video/intro?id=<id>`（SSR：标题/封面/番号/片商/标签）+ `GET /api/video/app/video/intro?id=<id>&viewId=<串>`（JSON：`url`/`duration`/`price`/`code`） |
| 有声音轨 | `GET /api/audio/app/audio/chapter?id=<chapterId>&viewId=<串>&offset=0` → `model.url`（mp3） |
| 漫画阅读 | `GET /api/web/comic/chapter?id=<chapterId>` → `var chapter={…}` 的 `images[]` |
| 小说正文 | `GET /api/web/novel/chapter?id=<chapterId>` → `div.line` 段落 |
| 排行 | `/api/web/comic/rank`、`/novel/rank`、`/audio/rank`（固定 100 条，**不吃 `page` 参数**） |

坑位：

- `intro`/`chapter` 这类 JSON 接口**必须带 `viewId`**，否则一律 `{"result":"fail","msg":"非法操作"}`（实测无 `viewId` 时 0 数据）。
- 有声的 `chapter` 对游客回 `code:1 + msg「请先登录」`，但 `model.url` 照发（`13191.mp3` 实测 200）。
- 网页 SSR 的 `?keyword=` **不生效**（服务端把关键词回填进输入框，列表仍回默认），所以搜索只走 JSON。
- `/api/comic|novel|audio/app/<svc>/search` 一律 500，未启用；搜索目前只覆盖视频库。

## 五、分类去重（每个分类都真换内容）

实测比对首页第一条 id 后砍掉的：

| 砍掉 | 原因 |
|---|---|
| `origin=4`（正规） | 与默认列表逐条相同 |
| `category=AI生成` | 0 条 |
| `category=日韩片 / 国产片 / 欧美片 / H动漫` | 分别与 `origin=2 / 1 / 5 / 3` 结果逐条相同 |
| 有声 `category=有声小说` | 与「最新」相同 |
| 漫画 `sort=4` | 与 `/comic/rank` 相同 |
| 小说 `category=乱伦` | 前两条与 `都市` 相同 |

保留下来的 29 个分类（视频 7 / 有声 7 / 漫画 6 / 小说 9）逐条跑过 `list`，26 个首条 id 互不相同，
其余 3 个是「同一批内容的第二三条才开始分叉」（`v:o5` vs `v:new`、`n:c:都市` vs `n:new`、`a:rank` vs `a:hot`），
已在源文件里注明。

## 七、限制

- **小说分类的跑测会报 `playable` 失败**：`kind:"text"` 没有 URL 可探活，属 `lume-source-check` 的限制（同「天撸啦小说」）。
- **搜索只覆盖视频库**：有声/漫画/小说的搜索接口 500，只能按分类浏览。
- **排行页不吃 `page`**：固定 100 条，`hasMore` 恒 `false`。
- **`/api/` 是唯一通路**：哪天站方把 `/api/` 也纳进 CF 校验，源会抛 `NEED_WEBVIEW_VERIFY`，届时只能靠 App 网页视图。
- 站点按 `viewId` 记账免费额度；本源每次现生成，等价于「不领额度」。不做注册、不触发任何扣费接口。
