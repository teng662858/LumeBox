# 源换网址后的通用请求头兼容

此前巴卡漫画 2.2.1 修复的是脚本未及时采用 `config.domain` 的问题。App 原本已有域名映射、配置保存后释放源运行时和读取结果缓存的机制；本次继续修复公共 HTTP 层的请求头一致性。

- 跨域或切换端口时同步原站 `Origin` 与匹配的 `Referer`，移除旧 `Host`、Cookie 和 Authorization，让 HTTP 客户端与目标域会话池重新提供目标站的请求身份。
- 同一 origin 内只调整目录时保留 Cookie 和 Authorization，避免路径映射导致已登录状态丢失。
- 旧域显式 Cookie 不再强制覆盖目标域会话。第三方 Origin、Referer 与第三方会话保持各自归属；表单内容和签名参数不做字符串替换。
- 公共行为适用于走 `LumeHttp` 标准 HTTP 桥及配置中已声明的域名映射，不承诺自动适配未知域名、源内专用签名、登录回跳参数或站点购买权限。浏览器渲染桥未在本次改动范围内。

验证：新增跨域、端口、目录、第三方会话四项回归，修复前其中三项失败，修复后通过。连同已有请求头、地址覆盖、网络生命周期、会话池、网络队列、源线路、登录同步测试共 57 项通过；`dart analyze` 无问题。

巴卡漫画 2.2.1 的源修复继续保留。公共层修改需要安装包含此提交的新 App 才能生效，仅更新订阅不会更新 App 网络实现。
