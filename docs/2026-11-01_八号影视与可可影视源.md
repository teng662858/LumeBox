## 一、八号影视（bahaotv_video）v1.0.0

### 域名
用户给的是 `bahaotv.com`，但它和真实站点的证书名不匹配：

```
Host: www.bahaotv.com is not in the cert's altnames: DNS:bhtv001.com, DNS:www.bhtv001.com
```

两个域名是同一台站（首页字节一致）。本源**默认走 `https://www.bhtv001.com`**（证书匹配），
`bahaotv.com` 作为镜像保留（App 的 HTTP 桥若不做严格校验仍可用）。

### 结构（苹果CMS v10 + shoutu38 主题）
| 用途 | 路径 |
|---|---|
| 栏目 | `/vodshow/movie-----------.html`、`tvseries`、`anime` |
| 列表 | `/vodshow/<cat>-<地区>-<排序>-<类型>-<语言>------<年份>--<页码>--.html` |
| 详情 | `/details/<id>.html` |
| 播放 | `/vodplay/<id>-<线路>-<集>.html` |
| 搜索 | `/so.html?wd=<词>` |

筛选槽位是从站点的筛选条原样取出来的（11 个短横线段位）：
`slot1=地区`、`slot2=排序(time/hits/score)`、`slot3=类型`、`slot4=语言`、`slot8=页码`、`slot11=年份`。
实测：地区 / 类型 / 语言 / 年份 / 排序 各自都换内容，且可组合（如 美国+动作+2025）。

### 播放（本源自己解）
播放页里有 `var player_aaaa={...}`，`url` 指向第三方 iframe（`xx.kanrenao.cn/v/ty/<sid>`）；
iframe 页给出 `var rand="<16位>"` 与 `var player="<base64>"`，
用 **AES-128-CBC（key=`VFBTzdujpR9FWBhe`，iv=`rand`，Pkcs7）** 解出 JSON，里面才是真正的地址。

实测解出 mp4：`206 video/mp4`，首字节 `ftypisom`，无 VIP / 试看限制（`trysee=0`、`points=0`）。

### 线路
详情页「切换线路」给多条线路（实测 `2182` 有 3 条 × 8 集 = 24 项），
DOM 里 `.source-item` 与 `.episode-list` 按索引一一对应。本源按线路分组，把每集都列出来，
线路名写在选集标题里（如 `高清线路Ⅳ · 第01集`）。

## 二、可可影视（kkys_video）v1.0.0

### 入口反爬
首访返回 HTTP **850** + 内联脚本：把常量 `c` 与递增 `i` 拼接做 SHA-1，
直到摘要第 `n1` 字节 == `0xB0` 且下一字节 == `0x0B`，然后写 cookie
`cdndefend_js_cookie=<c><i>` 再刷新。

本源用**纯 JS SHA-1** 现算（实测约 1.5 秒解出，`i=95389`），拿到 cookie 后重试即通过；
同一实例内复用，不会每次请求都算。

### 结构
| 用途 | 路径 |
|---|---|
| 栏目 | `/show/1------.html`（电影）`2`（连续剧）`3`（动漫）`4`（综艺） |
| 列表 | `/show/<cat>-<类型>-<地区>-<语言>-<年份>-<排序>-<页码>.html` |
| 详情 | `/detail/<id>.html` |
| 播放 | `/play/<id>-<线路>-<集>.html` |
| 搜索 | `/search?t=<页面令牌>&k=<词>`（缺 `t` 会 503；令牌从列表页表单取） |

排序：`1=最新`、`2=最热`、`3=全部`、`4=评分`。四个栏目各有自己的类型/地区集合。

### 播放
播放页里直接写着 m3u8（带 `sign` / `timestamp`）：
`https://142.248.97.95:21302/.../index.m3u8?appId=kkdy&sign=...&timestamp=...`
实测 `200 application/vnd.apple.mpegurl`，`#EXTM3U`，31 万字节。

### 线路
详情页「切换线路」最多 **37 条**，每条线路一套独立分集（实测 `376140` 共 156 项）。
本源把每条线路的分集全列出来，标题带线路名。

## 四、限制

- **八号影视**：`bahaotv.com` 证书名不匹配，默认用 `bhtv001.com`；4K 档在站点侧要客户端，本源只用站点给出的可播地址。
- **可可影视**：首访要过反爬挑战（首次 1-2 秒）；**封面图被源站 403 拦**（`/vod1/vod/cover/...`
  无论带 cookie / Referer / 浏览器头都 403），所以列表里可能没有封面，但标题、分集、播放都正常。
- **LIBVIO**：见 `docs/2026-11-01_LIBVIO地域限制.md`。
