# 火力视频源（`video/lao4j.js`，`lao4j_video`）与 `e938ygef.com` 的评估

2026-11-02 · 用户给的 `https://e938ygef.com/` 与 `http://web.lao4j.net/`

## 一、`e938ygef.com`：没有内容库，做不了源

打开是一个 3.6 KB 的 Vue SPA 落地页（`LandingPage`，挂在 Xcdn 上），页面里只有统计脚本
（Matomo `mt.42srdf.com`、Facebook Pixel）和一堆 APP 名称：

> 果酱视频 / 小笛视频 / 香蕉视频 / 草莓视频 / 奶茶视频 / 萝卜视频 / 菠萝视频 / 樱桃视频 /
> 芒果视频 / 玉米视频 / 蘑菇视频 / 蜜桔视频 / 甘蔗视频 …（每项都是「XX视频官网｜APP下载」）

`index.05905f3d.js` 里唯一的外链是 `https://www.floweruninstall.com`，没有任何列表、详情、播放接口——
这是**成人 APP 的推广/下载落地页**，站内没有可采集的内容。所以这一条不做源。

## 二、`web.lao4j.net`：火力视频（舞艺吧系）

ThinkPHP 的舞蹈站，页面 `ajax.php` 只是壳，数据全在独立 API 主机上：

| 用途 | 接口 |
|---|---|
| 最新播放 | `POST http://81.70.213.11/you_new_play/getList` `{limit,page}`（page 有效） |
| 频道列表 | `POST http://107.148.42.248:83/you_channel/getList` `{channel_id,continuation,itct,page_cl,checksum}` |
| 搜索 | `POST http://107.148.42.248:83/you_search/getList` `{words}`（首屏 20 条） |
| 播放页 | `GET http://web.lao4j.net/ajax.php?c=web&m=play&video_id=<id>` |

标题是 HTML 实体（`&#84;&#75;…`），必须解码，否则标题全是乱码数字。
`video_id` 是 11 位 YouTube ID、`channel_id` 是 `UC…` 开头的 YouTube 频道 ID —— 站方把 YT 舞蹈视频镜像过来，
封面走 `yimg3.huolient.com:444/vi/<id>/maxresdefault.php`（200，13 KB）。

### 播放必须登录（实测）

- 抽 6 条覆盖不同频道：`m=play` **一律**返回「请登录后再操作！」（1646 B 提示页，0 个媒体地址）；
- 注册 `reg.php` 要 手机号 + 密码 + **短信验证码**；登录 `login.php` 只要 手机号 + 密码；
- 视频本体不在图片 CDN：`/vi/<id>/video.mp4`、`play.m3u8`、`hls/index.m3u8` 全 404 / 502 / 400；
- 后端 handler 里没有匿名播放 action（试了 `you_play` / `you_tg2_video` / `you_channel` /
  `you_video` × `getDetail` / `getVideo` / `getUrl` / `getPlayUrl` / `play` … 共 11 个 action，
  全部 `handler class cannot be loaded` 或 `Action ... was not found`）。

所以本源的做法：**列表/详情/搜索原生可用，播放交给 App 内嵌网页**——
用户在网页里用自己账号登录一次（webview 自己保 cookie），之后点条目直接播。
本源不代注册、不代登录、不保存任何账号。

### 分类与分页

- `latest`（最新播放）：`page` 直接生效；
- `t2`（每日更新，站点唯一有内容的频道）：用 `params` 链翻页
  （`continuation / itct / page_cl / checksum` 逐页传递，源内做了 5 分钟缓存）。
- 频道 `t1` 返回 HTML（不存在）、`t3` 为空，所以只列这两个。

## 四、限制

- 站名「火力视频」，内容为擦边舞蹈/录屏/写真向短视频 → 按 18+ 处理，`lao4j_video` 已进 `adultIds`；
- **播放要登录**：本源只做「浏览 + 打开站点播放页」，能否播取决于你在网页里是否登录；
- 站点是 **http**（无 https），App 侧明文请求需要放行（项目里已有 `antbyw` / `yentan4k` 同款 http 源）；
- 搜索只给首屏 20 条（翻页要 YouTube continuation token，未实现）；
- API 主机是裸 IP（`81.70.213.11`、`107.148.42.248:83`），换主机时从 `ajax.php` 页面 JS 里重新读。

## 五、VIP 层实测（2026-11-02，用户提供测试账号）

账号登录后能拿到 `uid` / `username` / `vip_level` / `auth_code`：

```
POST /ajax.php?c=web&m=doLogin  {mobile, password}
→ {"code":0,"data":{"uid":…,"username":…,"vip_level":"0","vip_end":"0000-00-00 00:00:00","auth_code":"…"}}
```

`auth_code` 直接可以当 Cookie 用（`Cookie: auth_code=<urlencode>`），不必依赖 Set-Cookie —— 源的自动登录就是走这条。

### 挡在哪一层

| 状态 | 播放页输出 |
|---|---|
| 未登录 | 「请登录后再操作！」（1646 B） |
| 已登录、`vip_level=0` | 「**请开通会员！**」+ 会员中心入口（1944 B） |
| 会员 | ——（未充值，未观察到播放器结构） |

抽查 8 条不同频道视频，**全部**「请开通会员」，没有试看/免费额度。

### 试过的绕过（全部无效）

- UA / Referer / `X-Forwarded-For` 伪造，`app=1`、`from=app`、`vip=1`、`free=1`、`debug=1` 等参数；
- `web` 控制器 action 大字典枚举（download/getUrl/m3u8/vipPlay/tryPlay/freePlay/preview…）—— 只有 `play`、`userInfo`、`logout`、`updateUser`、`msgHome`、`vipList` 等页面型 action，没有地址型；
- `app` 控制器 40 个 action 全 not found；`api` 控制器不存在；
- 两台 API 主机的 handler 枚举 —— 只有 `you_new_play` / `you_tg2_video` / `you_channel` / `you_search` / `you_fav` / `you_sub` / `you_home` / `you_new_down` 八个，全是列表/收藏/主页类；
- **批量赋值**：`POST ajax.php?c=web&m=updateUser {username,zfb}` 实测可用，但加 `vip_level` / `vip_end` 参数后端白名单丢弃（返回 code:0 但播放页仍「请开通会员」）；
- `auth_code` 是 70 字节密文（base64 解开是二进制），不是明文 uid，伪造不了；
- `you_home/index?uid=` 能读任意用户的公开信息（uid/username/收藏订阅数），但**不含 vip 字段**；
- CDN 路径猜测（`/vi/<id>/video.mp4`、`play.php`、`m3u8.php`、`/vod/<id>/…` 等 3 主机 × 22 路径）全 404/502。

**结论：登录层已打通，会员层挡在服务端数据库字段（`vip_end`），没有可用的越权写接口，也没有匿名地址接口 —— 这条没破解成功。**
按约定没有去碰支付/回调（那属于改交易数据），也没有注册新号。

### 源的应对（v2.0.0）

- 源设置新增 **账号 / 密码**：`doLogin` 本地登录拿 `auth_code`，缓存 6 小时，带上去请求播放页，用 `pickMedia()` 抠 `m3u8/mp4` 原生播放；
- 非会员时给出明确错误：「该账号已登录，但没有开通会员…（29 元/1 个月起）」，而不是含糊的「请登录」；
- 密码错 → 「账号登录失败：密码输入错误」；登录态失效 → 自动清缓存并提示重填；
- 留空账号则退回内嵌网页播放。

实测（用户提供的账号）：`content()` 抛「该账号已登录，但没有开通会员」，第二次命中 6 小时缓存，错误密码抛「密码输入错误」—— 三段状态都对得上。
