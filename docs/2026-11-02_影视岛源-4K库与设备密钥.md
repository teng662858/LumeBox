## 一、这是哪个站

就是之前说的那个：`tv.yingshidao.com`（官网 `yingshidao.com`，主打「身在海外」的华语影视）。
条目接口里带 **`has4k` 字段**——不是海报贴纸，是真实档位。电视剧第一页 20 条里 12 条 `has4k: true`。

分类：电影(1) / 电视剧(2) / 综艺(3) / 动漫(4) / 纪录片(5) / 少儿(6) / 短剧(7) / 微剧(10)。

## 二、能直连的接口（全部免登录）

```
GET /api/v1/video/category?categoryId=2&page=1
    → {list:[{id,title,subtitle,coverUrl,has4k,isVip,totalEpisodes,first_episode_id,year,region,…}],has_more,filter_tags}
GET /api/v1/video/category?categoryId=2&type=tv-romance&regions=KR&years=2025&page=1
    → 筛选实测生效：type / years / regions 三组都在 filter_tags 里，id 直接透传
GET /api/v1/video/search?q=凡人&page=1
GET /api/v1/video/detail?id=mov_…
```

## 三、登录与播放：实测结论

用给的账号（`630891567@qq.com`）走 `POST /api/v1/auth/login {account, channel:"email", password}` **登录成功**，
返回 `__Host-watchtv_session` Cookie；`/api/v1/auth/session` 里 `isVip: true`、`giftSupporterExpireAt` ≈ 7 天后。
（`channel` 只认 `email`；传 `phone` 返回「不支持的 channel」。）

但**直链取流走不通**，卡点很明确：

| 步骤 | 结果 |
|---|---|
| `POST /api/v1/video/playback/access {episode_id}` | 403 `PLAYBACK_CKEY_INVALID`（播放设备验证已失效） |
| 同上 + `ckey_prepare:{direct_guest:true}` | 403 `DEVICE_KEY_SESSION_MISMATCH`（设备与登录会话不匹配，账号绑着原设备公钥） |
| `GET /ckey/assets/9bdf4d856bc20c9d667699cdcd4b44e4` | 404（该资源随构建版本变） |

客户端那套 CKey（`_next` chunk 6887 里）：

```
登录 → enrollDeviceAfterLogin：WebCrypto 生成 ECDSA P-256 设备密钥对
     → registrationPublicKey / registrationKeyID → 提交设备注册
播放 → 签名 canonical 串：
     "ysd-ckey-direct-v1" \n purpose \n <playback?scope> \n <episode_id> \n <play_attempt_id> \n <issued_at> \n <nonce>
     签名放 ckey_direct:{key_id, nonce, issued_at, signature, public_key}
     + 挑战时间窗校验（>120s 视为过期）→ 换 playback_token（X-Playback-Token）→ 才能取 HLS
```

要用纯 JS 沙箱复刻，等于把 ECDSA P-256（无 `crypto.subtle`）+ 设备注册 + 挑战流程全写一遍，
而且新设备注册可能顶掉你手机上的登录态。所以本源**不做伪装**：列表/搜索/详情走接口，
`content()` 返回 `webplayer` → App 网页播放器打开 `/video/<id>?play=1`，站内播放器自己算 CKey、按账号给 4K。
和「4k影视」那条网页播放器线路是同一套思路。

## 五、下一步（想要直链的话）

1. 复刻 ECDSA P-256 + 设备注册（可先用 `crypto` 在 Node 里跑通，再移植成纯 JS），
   代价是账号可能被绑到新设备，需要在网页端重新登录一次；
2. 或者抓一次真机的 `X-Device-Token` / `X-Playback-Token`，在源设置里做成「登录态」输入项，
   用 `settings` 的 `text` 存 token（和 `haijiao` 那套 cookie 登录一致），过期再换。
路径 2 更省事，等抓到真机请求就能接。
