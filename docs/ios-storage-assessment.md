## 运行时额外空间

- 首次准备内置离线音色时，程序在应用支持目录组装约 110.4 MiB 压缩包，解压临时 tar 并生成模型；清单中保留的模型文件合计约 117.9 MiB。成功后临时目录清除，模型留在应用数据中；安装期间峰值高于最终新增量，且重装时可能同时存在旧模型。用户导入的完整包大小可不同。
- 首次启用识别时，YAMNet 约 15.3 MiB 会复制到应用数据；iOS 图像模型压缩包约 20.2 MiB，解压后约 21.8 MiB，还可能产生 Core ML 编译缓存。实际占用取决于设备和使用情况。
- 漫画图片处理会生成 Core ML 编译模型；图片缓存、视频下载、播放历史和用户数据也会增加空间。这些无法从 IPA 推算。

## 建议

1. 最值得评估的是把内置离线音色改为首次使用时可选下载或导入：理论上能从安装包移出约 110 MiB，但会改变开箱即用的离线体验，还需要可靠的下载、校验、失败恢复与清理机制；下载后设备仍需保存模型。
2. 片头片尾模型和漫画图片模型可以考虑类似的按需资源，但收益较小，需分别权衡离线体验、网络和维护成本。不要未经验证就移除模型或框架。
3. 猫源运行时、多个视频内核及其原生依赖涉及实际功能；先用功能使用情况与真机测试确认取舍，再做裁剪。压缩大小和安装后大小差异较大，不应把框架的解压大小当成 IPA 可减少的大小。
4. 真机测量：记录 iOS 18 设备的空闲空间，在全新安装、首次启用音色、识别模型和图片处理、清理缓存后分别查看系统「iPhone 储存空间」和 App 内缓存统计；报告系统版本及样本 IPA，并区分应用大小与文稿和数据。当前没有真机测量，因此不推断最终设备占用。
