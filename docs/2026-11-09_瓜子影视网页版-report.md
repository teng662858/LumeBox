# 瓜子影视网页版

`gz360_web_video` 是面向 `gz360.tv` 的独立 JS 源。可从视频板块同步私有影视订阅，显示名称为「瓜子影视（网页版）」。原 Python 源使用自己的标识和客户端接口。

## 接入范围

仅请求公开网页及游客可访问的目录、选集和媒体。筛选支持地区和年份，每组按网页的单选行为取第一个值。客户端专属选集不进入网页播放列表。站点和接口在本机代理网络下实测。

## 证据与实现

| 证据 | 观察 | 源脚本行为 |
| --- | --- | --- |
| E1 · 首页与 `/_nuxt/256178e.js` | Nuxt 网页使用 `/Pc` 接口。Axios 拦截器把 JSON 参数编码成 AES-CBC 十六进制，响应中的加密 `data` 用同一封装解码 | `gz360Request()` 调用宿主 AES 工具并处理接口状态 |
| E2 · 搜索页及 `/Search/GetConditionList` 实测 | `tid`、`keywords`、`page`、`area` 和 `year` 对应网页的分类、搜索、分页和筛选 | `categories()`、`filters()` 和 `list()` 使用站点选项及总数 |
| E3 · 详情和选集接口实测 | `GetVodInfo` 给出简介，`GetOnePlayList` 给出分集 ID 和公开网页播放地址。剧集样本返回有效 HLS，详情封面为图片 | `content()` 按分集 ID 重新获取播放地址，携带网页 Referer |

P1 · 分类和筛选 → 目录查询 → 影片详情 → 网页选集 → HLS。验证依次检查接口结构、参数生效、封面和媒体。

Windows QuickJS 宿主验证了六个分类、不同分类与分页的结果差异、年份筛选、搜索、详情、下架条目及多集播放地址。实站抽测了《谷雨》的封面和 HLS 首个媒体分片，以及电影、电视剧样本的播放清单。站点目录也会展示尚无网页选集的作品。

## 复现

```powershell
$env:NODE_USE_ENV_PROXY = '1'
node tools/lume-source-check.mjs sources/video/gz360.js --category 2 --keyword 谷雨 --filter year=2026
node tools/lume-source-check.mjs sources/video/gz360.js --category 1 --page 2
```
