源文件：`sources/video/mitaovideo.js`（源仓库 `video/蜜桃视频.js`）

## 二、接口与解析

```html
<!-- 列表 -->
<script>window.APP_DATA = [ {module:'text_link',…},
  {module:'video_list', currentPage:1, totalPages:1089, data:[{short_id,title,thumbnail,duration,…}]} ]</script>

<!-- 详情 / 播放页 -->
<script>window.APP_DATA = {"data":{"short_id":"9geFtd1i","title":"…",
  "m3u8":"eab2eac3b26466a3/video.m3u8","duration":2859,"server":"s3","tags":[…]},"recommend":[…]}</script>
```

- 分页在**路径**上：`/type/2/5` = 第 5 页（`?page=5` 无效，仍第 1 页）
- 详情：`/play/<short_id>`
- 封面：`https://a89hu01.top/<thumbnail>`，实测 200、字节头 `FF D8 FF`（真 JPEG，但 CDN 用 `text/javascript` 的 content-type 反盗链，App 按字节解码，不影响）

## 三、播放签名（本次的核心突破）

播放地址必须签名，否则 403：

```
https://p.xionganzhengwu.com/<m3u8路径>?sign=<ts>-<rand>-<uid>-<md5>
```

### 1. 怎么挖出来的

前端是字符串数组混淆（`play2.js` / `common.js` / `icons.js`），静态搜 `sign` 全是噪声。改走动态：

1. **定位调用点**：CDP 订阅 `Network.requestWillBeSent`，取 m3u8 请求的 `initiator.stack` → 只到 videojs 内部；
2. 于是**钩 `window.videojs` 的赋值**，拿 `new Error().stack` → 命中 `play2.js:1:48206`，这里调 `videojs(el, opts)`；
3. 读 `play2.js` 该处附近代码，确认签名结构：
   `md5(path + "-" + ts + "-" + rand + "-0-" + 密钥)`，密钥由两段混淆串拼成、结尾是明文 `"R8"`；
4. **截 md5 入参**：钩 `String.prototype.charCodeAt`（md5 计算必走），把 `Date.now`/`Math.random` 固定后过滤含 `9位数字-4位字母` 的串，直接拿到：
   ```
   /eab2eac3b26466a3/video.m3u8-1793552000-4fzzz-0-PsTU3c3rSDkzbe42CMozR8
   ```
   → 密钥 `PsTU3c3rSDkzbe42CMozR8`；
5. **实测验证**：`md5(上述完整串)` 拼成 `?sign=1793552000-4fzzz-0-c57d836a97b395000804cc50b25c1b57` → **200 + `#EXTM3U`**；去掉密钥那段 → **403**。

### 2. 源里的实现

```js
sign = ts + '-' + rand + '-' + uid + '-' + md5(path + '-' + ts + '-' + rand + '-' + uid + '-' + 'PsTU3c3rSDkzbe42CMozR8')
// ts = 秒级时间戳，rand = 5 位 36 进制随机，uid = '0'
```

沙箱没有 `crypto`，源里自带 `utf8Bytes` + 紧凑 `md5Hex`（已用 `node:crypto` 对 6 组输入含中文比对一致）。

## 五、限制

- **没有搜索**：站点搜索也是前端逻辑，未提供接口，源里对 keyword 抛可读错误。
- `tag/*`、`actress` 页没有 `APP_DATA`（纯客户端渲染），暂不支持。
- 首页/推荐不分页（`/2` 404），只有 `type` 频道能翻。
- 密钥写死在源里；站点若轮换密钥，需要重跑本文第三节第 3~4 步重新截获。
