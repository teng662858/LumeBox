# 液态导航调节说明

进入“设置 → 底部导航栏管理 → 液态玻璃细调”。上方始终显示实际底栏，可以按住、拖动、松手查看变化。滑动参数立即生效，松手后自动保存，重开 App 后仍保留。

原页面的白度、磨砂、边缘高光、阴影、左右留白、高度、离底距离及动效时长继续有效。“液态动效总开关”与原“点击弹跳动效”是同一个开关。六类效果均可单独关闭：水滴鼓起、拖动拉伸、胶囊联动、按压变清透、透镜折射、高光与阴影联动。

| 新参数 | 默认 | 范围 | 调整后的感觉 |
| --- | --- | --- | --- |
| 按压响应时间 | 100 毫秒 | 50～400 毫秒 | 越小按下鼓起越快 |
| 回弹阻尼 | 58% | 30～100% | 越低回弹越明显，原动效时长继续控制速度 |
| 水滴鼓起高度 | 48% | 0～100% | 水滴超出下方胶囊的幅度 |
| 按压横向膨胀 | 22% | 0～80% | 按住向左右撑开 |
| 上下跟手幅度 | 9% | 0～25% | 随手指上下轻微偏移 |
| 拖动拉伸幅度 | 65% | 0～120% | 快速拖动、离落点较远时拉长 |
| 拖尾收窄程度 | 55% | 0～90% | 尾部变细，随拖动方向转向 |
| 胶囊横向伸缩 | 1.4% | 0～6% | 下方长胶囊左右跟着变形 |
| 胶囊纵向伸缩 | 6.5% | 0～18% | 下方长胶囊上下跟着变形 |
| 按压磨砂减弱 | 62% | 0～100% | 按住变清晰，松手恢复磨砂 |
| 按压白度减弱 | 24% | 0～100% | 按住更透；全透、全白端点保持原值 |
| 折射放大强度 | 100% | 0～250% | 图标、文字和背景一起放大、弯曲 |
| 边缘彩色折光 | 100% | 0～250% | 边缘轻微红蓝折光，零为关闭 |
| 按压高光增强 | 60% | 0～150% | 在原高光之上增强，原高光为零则不额外开启 |
| 按压阴影增强 | 220% | 0～400% | 相对原阴影增强，原阴影为零时仍无阴影 |

建议先保留默认值，只改一类观察。恢复本页默认值只恢复液态细调，保留原导航尺寸、白度、磨砂、排序和动效时长。

按压预览不立即切页，松手才确认页签；触摸被系统取消时回到原页。减少动态效果开启后不运行按压、拉伸与回弹。透镜不重复创建图标或触摸区域。

Android 模拟器已检查五项、三项布局、按住变形、设置页实际预览。回归覆盖触摸取消、减少动态效果、白度端点、参数持久化及所有参数最大值。截图在 `build/dock-reference-20261019/`；iOS Metal 折射和真机手感尚待 IPA 验收，不能据安卓截图声称完全一致。
