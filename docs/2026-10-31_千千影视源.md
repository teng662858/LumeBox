# 千千影视源

`sources/video/qqys01.js` 将千千影视的公开 HTML 页面接入视频板块。它读取首页正在热映、MacCMS 列表与详情页、分集线路和站内搜索；电影/连续剧/综艺/动漫分类使用实测导航 id。

站点使用 UTF-8。分类列表通过 `/vodshow/{type}--------{page}---.html` 分页；类型/地区/剧情/语言/年份选项从当前分类的公开筛选页读取，多选取首项，旧版无分类参数时默认电影库。搜索首屏使用 `/vodsearch.html?wd=`，后续使用站点分页路由 `/vodsearch/page/{page}/wd/{keyword}.html`。详情及封面来自页面字段，播放地址按站点公开播放器配置解码；腾讯、爱奇艺等分享页交给网页播放器处理。完整保留多线路分集，不按总条数截断。

源对分集页显式标注的 VIP、积分和付费内容返回可读错误，不调用解析服务、不尝试会员权限接口、不绕过访问控制。站点有多条公开线路，失效线路会保留并允许手动切换；线路可用性随站点变化。当前抽查的 JS、BF、DB 线路返回 `200 + #EXTM3U`，LZ/FF 样本则有 404/403，因此排序将 JS/BF/DB 放前。直连主站为 `www.qqys01.com`；根域 `qqys01.com` 跳转至主站，不是独立镜像；尚无实测同内容的其他镜像。
