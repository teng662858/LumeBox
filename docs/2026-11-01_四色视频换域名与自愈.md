# 2026-11-01 四色视频 1.0.3：整站换域名后首页加载失败

## 现象

App 里「四色视频」首页报 `脚本错误：首页没有解析到板块（站点改版了？）`。用户提供两个可用域名：
`x5p2n.top`、`z2g9w.top`。

## 原因

站点在 `/help/help.html` 里自己写明「本站 3 天会换一次域名」。旧的 `www.z8f0q.top`（1.0.2 的主站）
和更早的 `www.d9y1w.top` 现在还在响应，但**整站 302 到新域的 `/enter/index.html`**：

```
GET https://www.z8f0q.top/index/home.html
→ 302 Location: https://www.x5p2n.top/enter/index.html   （或 www.z2g9w.top，随机轮换）
```

App 的 HTTP 桥会跟随 302，但**既不回报 `reply.url`，也不回 302 的 `Location`**，脚本拿到的是那张
「进入页」（4513 字节，只有 `enter-content` / `qrcodeSmall` 标记）。`home()` 找不到
`home-list-item` → 抛「首页没有解析到板块」。站点本身没改版，解析规则（AES 标题、`/cYc` 卡片、
`/search/...` JSON、播放页 `decodeString`）全部照旧，1.0.2 的 key/iv 也仍然有效。

## 修改（1.0.3）

- **域名**：`mirrors` 改为 `www.z2g9w.top`（主）、`www.x5p2n.top`（镜像）、`www.zie2.com`
  （官方长期地址；本机 TLS 被劫持，只供手选）。`SITE`、`icon` 一并换到 z2g9w。
- **发布页**：新增源设置 `publishPage`（action / openWebsite）指向 `/help/help.html`——
  这页就是站点的「自救页」，写着 3 天换域名、正确访问方式 `https://www.zie2.com`
  与找回邮箱 `liumangtu@mail.com`；另加 `note` 说明域名轮换与镜像。
- **换域名自愈**：`getText()` 现在按 `host.json` 缓存 → `config.domain` → `SITE` → `MIRRORS`
  依次试；用**页面形态**（含 `enter-content` / `qrcodeSmall` 且没有 `video-item`）认出「只剩进入页」，
  换下一台重试，成功的主机缓存 12 小时（`host.json` 里同时记 `selected`，用户换镜像即失效）。
  全部失败时抛出带「去打开发布页看最新地址」提示的错误。
- **媒体 CDN**：play 页现在给 `4sv.0827.la`（主）与 `s4.dt188.site`（备），两台 m3u8 / 封面 JPEG
  都 200；老的 `www.0734.la`（连不上）、`s5.sanheyiliao.xyz`（NXDOMAIN）从兜底里去掉，
  少一次必败的探活。`IMAGE_HOST` 跟着换成 `4sv.0827.la`。

## 验证

- `node tools/lume-source-check.mjs sources/video/d9y1w.js`：五入口全绿，播放探活
  `200 application/vnd.apple.mpegurl` `#EXTM3U` 23.8 KB。
- **自愈实测**：把副本的 `SITE`/`mirrors[0]` 改成 `www.z8f0q.top` 再跑检查，
  首请求落到 `z8f0q`（4513 B 进入页）→ 自动切到 `www.x5p2n.top`，五入口仍全绿，
  播放 Referer 变成 `https://www.x5p2n.top/`。
- `flutter test test/d9y1w_source_test.dart`：原快照用例（AES 标题 / 分类 / 列表 / 搜索 / 详情 /
  双线路）通过；新增「主域只剩进入页时自动换镜像取首页」用例通过。
- `dart analyze test/d9y1w_source_test.dart`：无问题。
- 18+ 登记不变（`adultIds` / `content-ratings.json` 均已含 `d9y1w_video`）。

## 已知限制

- 站点每 3 天换域名：`MIRRORS` 里三台都不在时仍会失败，此时靠源设置里的「打开发布页」找新地址，
  或发邮件 `liumangtu@mail.com`。脚本只能从**已知域名**里换台，读不到 302 的目标域（桥接层限制）。
- `www.zie2.com` 在本机 TLS 握手失败，只作手选镜像；海外/其他网络可用。
