## 🚀 使用方法

### 1. 部署到 LumeBox

```bash
# 复制源文件到 LumeBox 扩展目录
cp sources/*.js /path/to/LumeBox/assets/extensions/
```

### 2. 配置代理（如需要）

在 LumeBox 配置文件中设置：
```
proxy: http://127.0.0.1:7890
```

### 3. 加载和使用

LumeBox 会自动加载扩展源，用户可以在界面中：
- 浏览不同源的内容
- 搜索感兴趣的资源
- 在线阅读/观看
