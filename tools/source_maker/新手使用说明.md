# LumeBox 制源工坊 0.8.1 · 一页上手

Windows 版，不需要自己安装 Python。

0.8.1 已内置补充根证书，修复部分机器的 HTTPS 本地签发者证书错误。网站仍可能要求人工验证；详情页遇到验证时，在已打开的浏览器中完成，再回工具点“已完成，继续制作”。这不代表任意站点都已适配。当前逐站结果见 [本版验证记录](0.8.1验证记录.md)。

## 平时只做三件事

1. **填网址、选类型。** 填写能看到一排作品封面的页面，类型选视频、漫画、有声小说或图片。
2. **点“开始制作”。** 工具自动识别作品并检查详情、选集和内容地址。静态页面只有导航链接时，会打开推荐浏览器继续；看到作品列表后回到工具点“已完成，继续制作”。不需要手动生成代码或再点验证。源名称会自动填写，也可以自己改名。
3. **点“保存源文件”。** 检查通过后才能保存。把文件传到手机，到 LumeBox 对应的源管理中导入，打开作品试播或阅读。

默认保存到“文档 / LumeBox Sources”，也可以在保存窗口里另选目录。

做完一个源后，直接点底部 **制作下一个源**。旧规则、浏览器会话和分类会清空，保存的文件保留，不必关闭重开。失败或卡住时也可以用这个按钮重新开始。直接更换网址再点“开始制作”也会清除上一个入口的设置。

## 网站打不开、要登录或作品显示不全

点击网址下方的“用浏览器重试”。在网页中完成登录或验证，等作品列表出现，再回到工具点“已完成，继续制作”。想取消就点“取消浏览器操作”。手机和电脑的登录独立，手机有需要时仍要再验证一次。

制作或连接卡住时，直接点网址旁的“取消”。按钮立即恢复，可以修改网址重新开始，不必退出软件。浏览器连接等待最多 3 分钟。

如果工具读到了首页导航，而你在打开的浏览器里找到了真正的作品列表，先完成浏览器连接，再进入列表页，回到工具点 **读取浏览器当前页**。工具会更新列表网址、重新识别并检查。适用于推荐浏览器、Playwright、Selenium、内置浏览器；不读取其他浏览器窗口或跨站页面。

## 检查没有通过

可以点主界面的“AI 辅助识别”，填写自己的兼容模型接口、模型名和密钥后分析列表结构。先看规则预览，确认应用后仍需检查通过才能保存。没有模型接口也能继续使用普通制作功能。AI 密钥只留在本次运行内，不会保存到工程或源文件。AI 与 MCP 的安装和功能边界见 [README](README.md)。

失败原因会直接显示在状态行，并自动展开日志；也可以点“查看详情”查看。优先换成真正的作品列表网址或用浏览器重试。失败后不能保存成可用源。

**默认保持 JS，不会擅自改成 PY。** 静态视频或漫画 JS 失败时，可以点“尝试 PY 方案（需你确认）”。选择“否”会继续保留 JS；选择“是”才尝试 PY，PY 也必须重新检查通过。

修改网址、类型、名称或规则后，再点一次“开始制作”。旧检查结果不会用于保存新内容。

漫画也可以制作 PY：在高级设置选择“漫画 PY”，由你确认后再制作。导出的 `.py` 在 LumeBox 漫画板块的源管理中导入，需要安装含漫画 PY 支持的新版本 App。

## 什么时候需要高级设置

日常制作可以一直收起。需要换浏览器引擎、编辑规则、保存或打开工程、批量制作、查看代码时，再打开右上角“高级设置”。批量制作不会自动把 JS 改成 PY。

更多格式、引擎和规则说明见 [README](README.md)。工具只能检查抽样链路与内容地址，不能保证任意网站、所有作品都可播放。
