0.8.1 修复部分 Windows 机器的 `CERTIFICATE_VERIFY_FAILED / unable to get local issuer certificate`：同时加载系统和内置 Mozilla 根证书，并将证书包明确打入 EXE，保持主机名和证书校验。Gaze 实测从证书失败恢复 HTTP 200，并识别语义 article 卡片；详情页仍需人工验证，尚未验证制源成功。还修复空 h1 覆盖有效标题，并统一识别人工验证页。前面八站目前三站抽样通过、五站未通过，见 [0.8.1 验证记录](0.8.1验证记录.md)。

0.8.0 实际接入可选的 **Playwright MCP** 引擎，并提供 **AI 辅助识别**。AI 接口、模型和密钥由你填写；返回的 CSS 先经过本地兼容性检查，你确认应用后再检查真实链路。修复根目录 HTML 作品和尾斜杠作品路径过拟合、人物/分类导航误识别、缩略图目录遗漏；动态列表、403 与部分静态播放器会引导到浏览器验证。截图各站的实测结果见 [0.8.0 验证记录](0.8.0验证记录.md)，不是所有网站都已完成适配。

制源工坊是本仓库的 Windows 辅助工具，不随源订阅发布。它导出的源仍需单独完成 App 兼容与站点验证后再发布。

0.7.9 增加“制作下一个源”，无需重启即可清空上一个站点的规则、分类、浏览器操作和会话；取消后迟到的结果也不会覆盖新任务。直接换网址再开始也会清除旧站点设置。新增“读取浏览器当前页”，支持在推荐 Edge、Playwright、Selenium 或内置浏览器中手动进入正确列表，再读取真实 DOM 并重新检查。各类 Browser MCP、iv8 与本工具的区别见 [浏览器工具对照](浏览器工具对照.md)。

0.7.8 修复大量分类导航覆盖真实视频列表的问题，增加缩略图卡片识别。PorCore 实测识别19条作品及19张列表封面，3条作品的详情、选集和媒体地址抽样通过。0.7.7 的浏览器跳转恢复修复也包含在内。媒体地址已提取不等于已完成手机实际播放验证。

## 开始制作

1. 双击 `LumeBox-SourceMaker-0.8.2.exe`。
2. 填写能看到作品封面的列表网址，选择视频、漫画、有声小说或图片。
3. 点 **开始制作**，等待自动识别和检查。需要时可修改源名称，再点一次开始制作。
4. 显示检查通过后，点 **保存源文件**，把文件传到手机，在 LumeBox 对应的源管理中导入。
5. 继续做别的网站时，点 **制作下一个源**，再填写网址。已有导出文件和保存目录保留；正在制作时也可用这个按钮取消并重置。

不需要先选择引擎、填写解析规则或查看代码。动态列表会自动使用推荐的 Edge 浏览器继续，读取时等待作品或播放器出现，不把页脚、Logo 和空播放器元数据当作内容。作品详情、选集和内容地址会自动抽样检查，通过后才允许保存；实际播放或阅读仍需导入 App 确认。

## 遇到问题

制作和浏览器连接过程中可随时点击网址旁的 **取消**，不需要关闭软件。浏览器等待最多 3 分钟；取消后的旧结果不会覆盖新任务。

- 网页需要登录或内容不全：点 **用浏览器重试**，在打开的网页中完成登录或验证，看到作品列表后回到工具点 **已完成，继续制作**。
- 浏览器中后来找到了正确列表：在该浏览器窗口进入列表页，点击主界面的 **读取浏览器当前页**。工具读取当前 DOM 和网址，不会先退回旧首页；后续会重新抽查详情和内容。仅限同站点，换域名需重新连接。Scrapling 不保留可手动导航的标签页，请换推荐浏览器。
- 检查失败：状态行直接显示原因，并自动展开可见的日志；也可以点 **查看详情**。可以修改网址、用浏览器重试，或在高级设置中调整规则。不会自动改成 PY。
- 证书报错：0.8.1 已内置根证书；如果仍无法验证站点身份，会保留校验并提示浏览器检查。不会关闭证书校验强行抓取。
- 作品详情出现安全验证：在保留的浏览器窗口完成验证，再点 **已完成，继续制作**。已连接的会话会直接重新检查，无需重开程序；人工验证未完成前不能保存源。
- 确实需要 PY：点击 **尝试 PY 方案（需你确认）**，确认后才尝试，且仍须检查通过后才能保存。
- 没看到熟悉的引擎、工程或批量功能：打开右上角 **高级设置**。不展开也能完成日常制作。

完整的首次操作见 [新手使用说明](新手使用说明.md)。

## 动态网页与手动验证

### AI 辅助规则

主界面点“AI 辅助识别”，填写服务商提供的完整 Chat Completions 兼容接口地址（通常以 `/v1/chat/completions` 结尾）、模型名和密钥。也可使用本机兼容服务。远程接口必须 HTTPS；本机允许 HTTP。密钥仅留在本次运行内，不写入工程或导出源。

页面用途选“列表页”“详情 / 选集页”或“漫画 / 图片页”。浏览器已连接时读取当前页；详情/阅读页需先识别源，再在浏览器中进入相应页面。发送的是节点结构、精简类名、去查询参数的链接与图片属性名称，不发送原始正文、脚本、输入框值或 Cookie。服务商仍能收到这些结构与网址，可能计费。

模型只提议 CSS，不能执行任意代码或改写接口。先检查选择器能否在导出 JS 的解析器中运行，再显示规则和候选数量，由你确认是否应用。应用后仍要检查详情/选集/内容，通过前不能导出。尚未填写真实模型接口时，普通制源照常可用。

### Playwright MCP 可选引擎

普通推荐浏览器不需要 Node.js。使用 MCP 时，先安装 Node.js 18 或更新版本，在 PowerShell 运行本工具附带的 `install_mcp.ps1`，将固定版本 `@playwright/mcp@0.0.83` 安装到 `%LOCALAPPDATA%/LumeBox/SourceMaker/mcp`。无需更改 Codex 或其他 AI 客户端配置。

然后在“高级设置 → 浏览器与采集引擎”选择“Playwright MCP（需 Node.js）”，点击连接，手动完成验证后继续。该引擎使用真实 MCP 初始化、工具发现和调用；支持隔离 Edge、当前 DOM、加载操作和源验证。MCP 仍需模型才能进行 AI 推理；单纯采集不需要模型。该通道当前没有 JSON 响应体记录，需要接口响应体时使用推荐浏览器或 Selenium。

### 原有浏览器引擎

选择「内置浏览器」「Playwright」「Selenium」或 Scrapling 引擎，在高级设置中点击「连接当前引擎」。HTTP 引擎直接连接；浏览器中可手动登录或完成验证，等作品列表出现后，返回制源工具点击「已完成，继续制作」。内置浏览器顶部菜单也可以继续采集。Playwright / Selenium 保留窗口；Scrapling 的抓取页会在返回页面数据后关闭，会话模式保留浏览器状态。切换站点请结束旧会话，再连接新网址。

会话只访问当前站点；跨域接口、跨站登录与特殊播放器仍可能需要单独适配。工具不代做验证码。Cookie 值不写入工程或导出源，退出会话后失效。Windows 上的登录不会自动传到手机，App 中需再次验证。动态 JS 使用 App 已有的网页渲染桥，手机上的超时、站点环境和实际播放仍需检查。

## 批量与解析

高级设置中的「批量制作」每次最多接受 10 个公开列表网址，按当前模块处理。可调并发 1～4、请求间隔 .3～5 秒和失败重试 0～2 次，启用自动限速并遵守 robots；通过抽样检查的才导出。日志显示进度，高级设置中的「暂停批量任务」暂停后续处理，正在执行的请求需要等待返回。使用同样的网址、模块和目录重新开始可以续作；已导出的文件只有内容校验一致才会复用。完整结果在「采集诊断.json」，检查点在「制源任务.json」。需要登录或验证的站点返回主界面单独处理。

Scrapling 0.5 的抓取与会话接口已接入：Fetcher、AsyncFetcher、FetcherSession（同步/异步）、StealthyFetcher（同步/异步）、StealthySession、AsyncStealthySession。引擎选择框提供对应的 8 个入口。0.5 不再单列旧教程中的 DynamicFetcher。库负责获取页面，导出仍由 LumeBox 协议模板完成；自动验证码处理未启用。

「Scrapling 改版自动适应」默认开启。验证通过后学习列表、章节和漫画图片区域；以后重新识别同一个入口时，尝试恢复变化后的结构并生成普通 CSS。仍需再次验证，不保证任意改版都能恢复。样本保存在本机 `%LOCALAPPDATA%/LumeBox/SourceMaker/adaptive`，可以点「忘记本站样本」删除。自适应功能用于 Windows 制源阶段，手机上的已导入源不会自动安装 Scrapling 或随之更新。

「浏览器操作 / 接口记录」可设置加载更多按钮、点击次数、滚动次数、等待元素。每页最多点击 3 次、滚动 3 次；默认不执行额外操作。这些操作会保存到工程并写入动态 JS，App 通过已有网页渲染桥执行；手机超时预算较短，复杂长流程仍需专门适配。

Playwright、Selenium 和 Scrapling 浏览器可读取最近最多 20 条同站 JSON 接口响应，每条最多 256KB；不记录请求头，并隐藏常见密码、Cookie、Token、签名字段。记录用于人工辅助适配，不会未经验证自动当作源接口。内置浏览器没有此响应记录能力。

界面的「查看各引擎功能范围」列出已接入能力。当前集成面向制源流程；没有提供全部 SDK API 的图形化编辑器，也没有接入分布式集群或远程爬虫部署。MCP 当前仅支持上述 Playwright MCP 子集。

优先识别视频与漫画卡片、章节区和漫画阅读区；支持常见懒加载图片、srcset、真实下一页链接、HTML5 媒体与 JSON-LD 公开媒体。高级 CSS 可调整卡片、标题、封面、章节、图片、下一页。JS 支持标签、类、ID、属性、后代、直接子元素与逗号，不支持完整浏览器 CSS。JS 检查失败后保持 JS；只有用户明确确认后才尝试静态 HTML PY，PY 也失败则阻止保存。批量制作不会自动切换 PY；浏览器模式也不会降为静态 PY。

## 按目标选择输出

| 目标 | 输出 | App 中的实际协议 / 位置 |
| --- | --- | --- |
| 有声小说 | `.js` | `category=video`、`mediaType=audio`、`kind=audio`；有声小说标签 |
| 漫画 | `.js` | `category=comic`、图片章节、每张图的 `imageHeaders` |
| 图片 | `.js` | 同属 `comic` 存储，详情页直接作为图集；导入后可手动分组为「美图」 |
| 视频 | `.js` | 视频列表、选集、`kind=video` 公开媒体地址 |
| PY | `.py` | 视频 Python `Spider` 协议；公开 HTML 或苹果 CMS |
| 漫画 PY | `.py` | 漫画 Python `Spider` 协议；返回章节图片列表与图片请求头，导入漫画源管理 |
| 模块 | `.cjs` | `LumeRuntime: module` 和 `module.exports` 源对象 |
| 猫源 | `.zip` | Node `start()` 服务、`index.config.js`、MD5；猫源订阅页导入本地 ZIP |
| Kazumi | `.json` | `searchList` / `chapterResult` / `baseURL` 规则；Kazumi 入口导入 |
| 网页 | `.html` | HTML 导航快照；视频源选择 → 网页 → 导入 HTML |

以上是内容类型与运行协议的组合，并非九个独立的 `category`。当前 App 没有文字小说正文载荷；本工具不再生成 `category=novel` 或 `kind=text`。

## 调整规则

| 设置 | 用途 | 示例 |
| --- | --- | --- |
| 列表网址 | `{page}` 替换为页数；未配置分页只抓输入页 | `https://example.com/list?page={page}` |
| 搜索网址 | `{keyword}` 替换为编码后的关键词 | `https://example.com/search?q={keyword}&page={page}` |
| 列表链接规则 | 按绝对地址筛选内容链接的 JavaScript 正则 | `/voddetail/` |
| 分类链接规则 | 从入口页实时抓分类链接，选择分类后实际请求对应列表 | `/(category|catalog)/` |
| 章节 / 选集链接规则 | 从详情页筛选章节；没有章节时仅接受已识别到媒体的页面 | `/chapter/\d+` |
| 内容元素 ID | 限定漫画、图片区域，填写 ID 不带 `#` | `content` |
| 编辑 Kazumi XPath | 配置搜索结果与章节链接 XPath | `//a[contains(@href,'/vodplay/')]` |

修改后重新预览并测试。HTML Kazumi 必须配置真实搜索网址；JSON 接口 Kazumi 自动生成 JSONPath 与多线路分隔规则。纯 JavaScript 网站不能仅靠普通 HTTP 自动恢复接口。猫源包内使用 UTF-8 解码；旧编码网页优先使用普通 JS。无法识别或尚未适配的协议会拒绝导出。

JS、CommonJS 和猫源支持识别同站 GET 表单的 `select[name]` 筛选项，并把选项值回传到列表请求。没有识别到的筛选结构会标为「未适配」，不会硬编码年份、地区或忽略传入条件。苹果 CMS 标准接口提供分类，但未必提供额外筛选，工具不会凭空生成。Kazumi JSON 的分类与筛选能力受 App 的 Kazumi 适配器限制，不等同于普通 JS。

校验检查解析和返回数据；封面只检查地址，媒体不实际起播。不能承诺任意网站仅输入网址即可生成完整可用源。人物、作者、栏目等网页不能因为能取到标题就被当作作品；没有选集或公开媒体时会报错并阻止导出。

普通 HTTP 抓取使用系统代理及 TLS 校验，单页上限 6 MB，单请求超时 18 秒。浏览器会话有独立的加载与元素等待超时。专用签名、加密接口或不公开的媒体仍可能需要开发适配。

## 启动和构建

Windows x64 Python 3.14（含 Tk）：

```powershell
python -m pip install -r tools/source_maker/requirements.txt
python tools/source_maker/app.py
powershell -ExecutionPolicy Bypass -File tools/source_maker/build.ps1
```

输出：`build/source-maker/LumeBox-SourceMaker.exe`、使用说明。构建运行工具集成测试；含 Node 的开发环境还会运行 App 自带 `assets/cat/bootstrap.js` 启动猫源并验证接口。

App 协议验收：

```powershell
powershell -ExecutionPolicy Bypass -File tools/source_maker/verify_app.ps1
```

此检查要求本仓库的 Flutter 依赖、已构建 QuickJS DLL，以及已准备的 `.cache/python-source-runtime/packages`。它执行真实 Dart 导入器 / QuickJS / 数据源内容模型测试和 App 自带 CPython 宿主；无原生桥时直接失败。测试 HTTP 为本地快照，不访问真实源站，不能替代 iOS 设备上的网站实播验证。

实现对应源码及验收范围见 [协议核对记录](../../docs/source-maker-contracts.md)。
