# SourceMaker 0.8.1 能力与验证

本版按网站机制识别，无法识别的能力会提示或阻止导出。默认 JS，只有用户明确确认才能改为 PY。Windows EXE 在本地交付。

0.8.1 最新证书修复和九个站点（新增 Gaze）的状态以 [本版验证记录](0.8.1验证记录.md) 为准。原八站目前三站抽样通过，另外五站未通过；Gaze 证书错误已修复，但仍有详情人工验证，未列为可用源。

0.8.0 的 MCP / AI 接入、回归结果与用户截图逐站状态见 [本版验证记录](0.8.0验证记录.md)。本版仅本地交付，不提交或推送到 GitHub。AI 辅助是可配置的 CSS 建议、预览和验证流程，不是全自动网站破解或任意接口生成器。

0.7.9 提供“制作下一个源”，取消旧任务并清空规则和浏览器会话；改填新网址再开始时也清理旧站设置。推荐 Edge、Playwright、Selenium、内置浏览器新增当前页 DOM 读取并接入制源验证；Scrapling 明确提示不支持手动导航当前页。Selenium 的同站 JSON 响应会在采集后及时缓存，避免后续详情跳转导致响应体丢失。浏览器 MCP 和 iv8 的选型与实际集成范围见 [浏览器工具对照](浏览器工具对照.md)。

## 已实现范围

| 网站形式或问题 | 处理方式 | 边界 |
| --- | --- | --- |
| 普通 HTML 目录 | 影视/漫画/图文/Bootstrap 卡片；父层链接、标题与封面；按链接族归类 | 导航和作品使用相同 CSS 时仍需抽样检查 |
| 图片懒加载 | data-original / data-lazy-src / data-src / srcset / CSS 背景 / poster | 不把 data URI 占位图当封面；不能凭空补不存在的图片 |
| 分类、筛选、分页 | 真实分类地址、同站 GET select 表单、真实下一页链接 | 不生成站点未提供的地区/年份；不默默忽略未知筛选 |
| 苹果 CMS | 标准公开接口、分类、详情、多线路 | 非标准加密播放解析另行适配 |
| MediaCMS | 首页公开声明的 API、列表封面、分类、搜索、分页、排序、时长、发布时间、媒体编码 | 分类/搜索的时长条件在客户端过滤，每次最多扫描 5 页；尚未证明支持所有部署版本 |
| WordPress REST | rel=api.w.org 发现、常规路径与 rest_route 查询路径、保留公开语言参数、wp/v2 posts/categories、特色图、公开正文媒体、分页响应头与末页处理 | 普通文章不能当视频；未支持所有自定义文章类型；不会扫描猜测未声明的接口 |
| Next / 初始状态 / JSON-LD | 读取公开 application/json、JSON-LD 和已知初始状态的 JSON 字面量；用 URL、标题、封面识别列表 | 不臆造 ID 对应网址；Next App Router 流式载荷仍走浏览器 |
| Nuxt 引用数据 | 识别单应用 __NUXT_DATA__ 与多应用 data-nuxt-data；还原常见 devalue 对象/数组/引用、Reactive/Ref 包装，读取作品和公开媒体 | 仅解析内联的有界数据子集；不执行站点自定义 reducer，不自动请求外部 data-src，也不承诺完整 Vue/devalue 运行环境 |
| HTML5 / HLS.js / JW Player / Video.js | video/audio/source、VideoObject/AudioObject contentUrl、公开播放器字面量 | 不执行网页脚本；不把 embedUrl、广告字符串当媒体；复杂拼接签名不截取半个地址 |
| 嵌套播放器 | 明确播放器区域和 embed/player/play iframe，最多 2 层、每层 2 个；保留播放器 Referer | 动态跨站会话、登录播放器或专有协议可能需要人工处理 |
| RSS / Atom | 有效 enclosure、音视频 MIME、标题、订阅图、分页链接 | 普通新闻文章不是媒体；订阅未提供的搜索分类直接提示；当前 JS/模块输出 |
| SPA / 动态加载 | 推荐 Edge、内置 WebView2、Playwright、Selenium、Scrapling；等真实作品/媒体出现 | 可人工设置最多 3 次滚动/点击；手机渲染预算较短，复杂流程仍可能需适配 |
| 中文和旧编码网页 | UTF-8 URL 转义、IDNA、保留已有百分号编码；HTTP/meta charset、UTF-8 BOM | 未知私有编码不能自动保证正确 |
| 公开常见编码 | HTML 实体、JSON 转义、URL 编码、Base64/atob、decodeURIComponent、MacCMS encrypt=1/2、gzip/deflate | 这些不等同于破解私有加密；不提供未知密钥或 DRM 通用解密 |
| 临时网络故障 | HTTP 429/502/503/504、连接故障最多重试一次；尊重 Retry-After；过长等待明确提示；等待可取消 | 当前标准 HTTP 制源通道；导出的手机源网络策略由 App 环境决定 |
| 跳转入口 | 小型、唯一的 location/refresh 字面量；两个入口样本跳到同一地址时重新识别实际站点 | 不放开任意广告跨站；多步推广/选择页不能冒充目录 |
| 人工配合 | 网页登录/验证后继续，接口记录脱敏，失败日志可见，随时取消、保存工程 | 手机会话需重新验证；Cookie 不写入导出的源 |

以上新 API 与 feed 适配目前提供 JS 或模块导出。未验证的 PY、猫源、Kazumi 组合明确拒绝，不生成假兼容文件。漫画 PY 已提供独立图片协议，仍由用户决定是否使用。

## 验证的含义

自动链路抽查最多 3 条真实作品；分别记录列表封面和详情封面、分类抽查、每组筛选回传及结果变化。没有变化可能是筛选条件合法重合，不能直接认定成功或失败。合法空列表也不能当接口故障。封面地址存在、图片响应正常、媒体地址存在和实际播放是不同层次。

本轮 Python 行为测试覆盖 API 参数与结果、类别标题和 uid 区别、分页、合法空筛选、模块导出、结构化载荷、播放器编码、iframe 深度、导航排除、中文 URL、解压上限、重试与取消。另有实际 App QuickJS/数据模型测试；构建后执行 EXE 自检以确认打包资源完整。

0.7.1 续做验证：53 个 Python 用例通过；4 个新增 MediaCMS JS/模块、Nuxt、WordPress 查询路由的实际 App 模型用例通过。Nuxt 官网公开内联数据实测还原出 6 个 data 项和 9 个 state 项。0.7.0 的 35 个现有 App 协议/导入用例、13 项引擎/批量检查与 EXE 自检已通过；0.7.1 打包后重新自检并记录交付哈希。引擎名称中部分为同一 SDK 的不同会话方式，不代表 13 种独立底层引擎。

## 仍需专门适配或人工操作

- 验证码、短信、账号登录、设备绑定、会话失效：在浏览器人工完成，不自动作答。
- GraphQL、未公开接口、POST 复杂表单、滚动私有游标、跨站认证：需要公开请求证据或用户在软件中记录操作；不会猜任意查询/密钥。
- 复杂混淆 VM、WASM 私有签名、DRM、未知 AES 密钥或动态授权：不承诺通用解密；能读取公开媒体与明文配置时先使用它们。
- 网站改版：可学习已验证的 DOM 样本，恢复后仍需检查；手机已有源不随 Windows 样本自动更新。

## 0.7.6 补查（2026-10-27）

这是常见机制识别器，不是任意网站都能自动逆向的 AI。未知动态接口、授权链路和私有响应格式可能需要专项适配。换 PY 只换执行环境，不能补出缺失的媒体规则。

- 通用 HTML5 媒体卡片：直接识别 video/audio 的 src、data-src、子 source，以及 poster。至少三张明确媒体卡片才作为列表；不会把单个作品播放器判成作品列表。ViralPorn 原先误选频道链接，现在按这一通用机制识别；现场约 60 条，15 个分类入口，3 条取址通过。搜索和未公开下一页不伪造。
- 野果短剧：5 个主题分类、4 组筛选，抽查 1 个分类和每组 1 个值，结果均变化；真实加密封面 3 张已在 Flutter 解码。关键词搜索仍未适配，完整播放仍需手机验证。
- 360资源站、奶香香资源网：本机导出的 JS 各抽查 3 条，分类和取址通过。站点没有提供的筛选不显示。
- MediaCMS、WordPress、MacCMS、RSS、常见 HTML 卡片和公开内联数据沿用机制识别；这些能力不等于任意域名都已验证可用。
