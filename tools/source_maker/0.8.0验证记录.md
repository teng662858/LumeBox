# SourceMaker 0.8.0 本地交付记录

本轮只在本机修改、验证和打包，不提交或推送 GitHub，不发布任何截图站点的源。

## 实际接入

- Microsoft Playwright MCP 0.0.83：真实 stdio 协议初始化、能力协商、工具列表及调用，使用固定导航和页面求值工具完成 DOM 采集、加载操作和制源验证。Node.js 18+ 为可选运行依赖，附带 `install_mcp.ps1`；普通推荐浏览器不依赖 Node.js。MCP 的 JSON 响应体记录和跨站 frame DOM 当前不支持。
- 可配置 AI 辅助：填写完整 Chat Completions 兼容接口、模型和密钥；发送精简节点结构，返回有限 CSS 字段，本地解析器检查通过后由用户应用，再检查源链路。没有可用模型时不影响普通制源。
- 页面用途分列表、详情/选集和漫画/图片。模型不能添加任意脚本、接口或更改输出协议。密钥留在内存，不保存到工程、源或诊断。
- 已通过本地模拟模型服务的真实 HTTP 合约及 GUI 应用/拒绝流程；尚未使用用户的真实模型服务，因此不能宣称任何特定外部模型的识别成功率。

其他 Browser MCP、PilotBrowseMCP、MCPBrowser、Crawl4AI 与 iv8 尚未接入；不把已有功能或理念参考算作这些项目的接入。

## 本轮修复

- 根目录 `.html` 作品地址、带尾斜杠的多层作品地址不再只匹配首条。
- 人物、字母索引和独立列表入口不再作为作品。入口跟随只使用页面已声明的同站目录，最多尝试两个，不扫描猜测接口。
- 增加常见缩略图目录；候选重建后继续过滤导航，避免过滤结果在后续阶段失效。
- 静态动态外壳、403/人工验证、部分已识别播放器失败可进入推荐浏览器流程，保持 JS。
- 读取 KVS `flashvars` 中明确的公开媒体字面量，支持 `.mp4/` 路径；不处理 license/function 包装。
- 识别明确的 `iframe#video`。推荐浏览器 / Playwright 可读取主站已声明且已加载的跨站播放器 frame，不把主窗口导航到任意域，也不接受未声明的其他网址。重定向、嵌套与验证失败仍需适配。
- 保留上一版“制作下一个源”、旧任务丢弃、换网址清理设置和当前页读取功能。
