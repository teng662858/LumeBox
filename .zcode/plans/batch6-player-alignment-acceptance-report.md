## 二、本轮功能边界（如实声明，供真机对照）

- **AVPlayer 内核**：音轨选择 ✅ 可用；字幕轨道 / 字幕样式 / 字幕延迟 / 音频延迟 /
  硬解 ✗ 不支持（点击弹统一提示）；后台音频、锁屏控制、缓冲参数 ✅ 可用。
- **MPV 内核**：上述全部 ✅ 可用。其中 `hwdec`（硬解）是**解码链初始化期**属性，
  改动对**随后打开的媒体**生效（正在播的这一集要等切集后才换解码链）；
  字幕延迟 / 音频延迟是运行时属性，立即生效。
- **MDK 内核**：音轨 / 字幕轨 / 外挂字幕 / 字幕延迟 / 请求头 ✅；字幕样式 ✗
  （libmdk 内嵌渲染）；**音频延迟与硬解 ✗ 不猜**（libmdk 没有可查证的属性名）。
- **清晰度**：只认「图源给多条线路」（`qualities` / `levels`）；**图源不给就只有提示**，
  播放器不生成清晰度、也不做分辨率推断。
- **VLC 仍未引入**：本轮按现有三内核对齐能力矩阵（引入 VLC 会改 iOS 构建图与包体，
  待用户明确）。
- **全屏**：播放页内的沉浸布局（收起顶栏与控制栏，点画面唤回浮层controls），
  不是系统级横屏锁定。

## 三、需要真机手动核对的（本机不可执行）

按顺序点一遍，每项写明「看什么」：

1. **视频栏目结构**：进视频板块 → 顶部只有【浏览】；右上角依次 📅 / ⏱️ / 源管理 / ＋。
2. **点条目**：列表点一条 → **弹出独立播放器页**（顶栏是作品名，返回即回浏览）。
3. **时钟抽屉**：点 ⏱️ → 底部升起抽屉，里面是播放记录；点条目直接续播；抽屉里可删 / 清空。
4. **追剧日历**：点 📅 → 独立页按月显示「更新 / 看过」；小说与漫画板块的 📅 是「追更日历」，
   内容来自各自板块（**不应看到别的板块的记录**）。
5. **小说 / 漫画抽屉**：点 ⏱️ → 只读（**没有删除与清空按钮**），点条目进详情页。
6. **缓冲参数（B 项）**：同一条防盗链视频源，从点条目到出画面计时，与电脑端对照；
   重点看是否还出现「等 1–2 分钟」。
7. **播放器控制栏**：±10 秒、播放暂停、停止、进度拖动（拖动中显示「拖动到 …」、松手才跳）、
   清晰度、弹幕开关、发弹幕、弹幕设置、自动连播、画中画、全屏、锁屏、设置——**都在**。
8. **设置弹窗**：齿轮 → 内核 / 倍速（滑杆 0.25~4x + 预设）/ 画面（缩放含「填充」「适应」、
   旋转 90/180/270、镜像）/ 字幕（含底色）/ 音频（音轨、音频延迟）/ **弹幕** / 解码。
9. **按内核分别记住**：在 MPV 调倍速与字幕样式 → 切到 AVPlayer（值应变回 AVPlayer 自己的）
   → 再切回 MPV（**应还是刚调的值**）；退到后台重进 App 再核对一次。
10. **不支持项的提示**：切到 AVPlayer，进设置弹窗点「字幕样式 / 字幕延迟 / 音频延迟 / 硬解」
    → 应弹「当前播放器内核不支持该功能，请切换其它播放器」，**控件本身不消失**。
11. **清晰度**：找一条多线路的源 → 点清晰度弹菜单、切换后**从当前位置继续**（不是从头播）；
    单线路源 → 点它应提示「当前图源不提供多清晰度选项」。
12. **锁屏与后台**：播放中按锁屏键 → 控制中心 / 锁屏出现播放条，播放 / 暂停可用，
    「下一集 / 上一集」能切集；按 Home 退到后台 → 声音继续。
13. **手势与画面**：左半屏上下滑调亮度、右半屏调音量、横滑调进度、长按临时倍速；
    设置里改缩放 / 旋转 / 镜像 → 画面**当场**跟着变（三套内核都应一致）。
14. **设置页「显示」分组**：设置 → 最上方「显示」卡，两行（外观 / 主题色）；
    外观切「深色」→ 整 App 当场变深色；主题色挑一种（如森林）→ 主色当场变；
    **杀掉 App 重进 → 应仍是刚才选的**。
15. **回归**：换主题色后各页面颜色仍读得清（卡片 / 文字 / 按钮不糊）；阅读器（小说 / 漫画）
    **不受全局主题影响**（它们有自己的阅读主题）。

> 若某项不符：记录「机型 / iOS 版本 / 内核 / 图源 / 步骤 / 实际现象」，附截图。
