# Lume Box · 第三步变更预览：数据源抽象接口层

## 一、本轮立起来的分层

```
lib/features/**      UI：只认 DataSource 接口，不再 import core/js/** 与 core/db/**
        ↓
lib/core/source/     ★ 新增：数据源抽象接口层（本轮唯一新层）
        ↓
lib/core/js/**       QuickJS-NG 沙箱与图源运行时（已完成；本轮仅加一个方法）
```

组合根只有一处：`LumeSources`（谁选择实现、谁打开数据源）。沙箱→接口的桥是 `JsDataSource`；全平台可跑的 `MockDataSource` 是简单模拟实现。

### 接口定义（核心，先贴签名）

```dart
/// 统一数据源接口：四个板块的图源（JS 图源与模拟实现）都实现这一套能力。
/// UI 只依赖本接口，不认识沙箱、脚本与数据库。
abstract interface class DataSource {
  String get id;        // 图源标识（板块内唯一）
  String get name;      // 图源显示名
  Section get section;  // 所属板块：小说 / 漫画 / 自定义视频 / 猫源

  Future<List<SourceCategory>> categories();                                    // 获取分类
  Future<SourceList> list({String? categoryId, String? keyword, int page = 1}); // 列表
  Future<SourceDetail?> detail(String itemId);                                  // 详情
  Future<List<SourceChapter>> chapters(String itemId);                          // 章节列表
  Future<ChapterContent?> content({required String itemId, required String chapterId}); // 播放/阅读章节
}
```

约定（写入文档注释并被测试覆盖）：
- **分类可缺省**：无分类的图源返回空列表，UI 自动隐藏分类行。
- **列表一个入口三用**：`categoryId` 空＝默认列表；`keyword` 非空＝搜索；`page` 从 1 开始。`SourceList{items, hasMore}` 保留分页语义，Phase1 的 UI 只翻第一页。
- **空结果不算失败**：无结果→空集合；条目找不到→`detail` 返回 null；章节暂无内容→`content` 返回 null。
- **真失败抛 `SourceException(kind, message)`**：`unsupported`（平台无运行时）/ `notFound`（图源不存在或已禁用）/ `callFailed`（脚本错误、超时、返回格式不符契约）。UI 只认这三个 kind 与 message。

`ChapterContent` 用密封类（与既有 `sealed SandboxResult` 同风格，Phase2 阅读器可穷尽 switch）：

```dart
sealed class ChapterContent {}
final class TextContent  extends ChapterContent { final String text; }                 // 小说
final class ImageContent extends ChapterContent { final List<String> images; }          // 漫画
final class VideoContent extends ChapterContent { final Uri url; final Map<String,String> headers; } // 视频
```

### 门面

```dart
class LumeSources {
  static bool get runtimeAvailable;                          // Phase1 = iOS（唯一平台开关）
  static Future<List<SourceDescriptor>> list(Section);        // 板块内图源列表（管理 UI 用）
  static Future<SourceDescriptor?> importScript(Section, String script);
  static Future<void> setEnabled(Section, String id, bool);
  static Future<void> remove(Section, String id);
  static Future<DataSource?> open(Section, String id);        // 取统一接口；不可用返回 null
  static void close(Section);                                 // 板块级释放（页面退出时）
}
```

生命周期：`open()` 返回的是薄适配器，底层引擎由 `SourceRegistry` 按「一图源一沙箱」持有；页面不持有也不释放引擎，板块页退出时经 `LumeSources.close(section)` 统一释放。接口因此**不含 `dispose()`**。

## 三、JS 契约 v2（示例脚本同步重写）

| DataSource | JS 方法 | 入参 | 返回 |
|---|---|---|---|
| categories | `categories()` | — | `[{id,title}]` |
| list | `list(arg)` | `{categoryId?, keyword?, page}` | `{items:[{id,title,cover?,subtitle?}], hasMore?}`（兼容裸数组） |
| detail | `detail(arg)` | `{id}` | `{id,title,cover?,subtitle?,description?}` 或 null |
| chapters | `chapters(arg)` | `{id}` | `[{id,title}]` |
| content | `content(arg)` | `{id, chapterId}` | `{kind:'text',text}` / `{kind:'images',images:[…]}` / `{kind:'video',url,headers?}` |

旧的 `latest` / `search` 不再使用，**不做兼容回退**（Phase1 无存量图源，契约保持单一清晰）。`SourceMetadata`（脚本 id/name/version）仍留在 JS 层 `source_script.dart`：它属于导入期脚本声明，与消费期接口无关。

## 五、明确不做

- 阅读器 UI（小说/漫画/视频播放页都不进）；章节点击仍只提示。
- 真实爬虫业务逻辑；任何新的 Polyfill 垫片实现体。
- 自定义视频板块不接 DataSource：`VideoPage` 保持现状走 `AbstractPlayer`；接口用 video 类型内容覆盖该板块语义，模拟实现给出 video 样例。
- 模拟实现不接进应用：非 iOS 行为不变（仍 Phase1 骨架），`MockDataSource` 只在测试中驱动 UI。
