# Phase2 真机验收清单（照做版）

> 这份清单是给**在 iPhone 上执行验收的人**用的。开发机是 Windows、没有 iOS 工具链
> （`ios_preflight` 的 macOS / xcode-select / xcodebuild / simctl / 模拟器五项全不可用，
> 实测输出见文末附录），因此「装到手机上点一遍」这件事由人工执行。
>
> 本轮把**能在代码层提前查出来的问题**先查了一遍并修掉（见第一节）——这样真机
> 阶段只剩「iOS 系统交互」这一层要看，不至于把时间花在必然出现的布局问题上。

## 二、验收项（逐条照做）

### A. 主题：跟随系统深色 / 浅色

1. **切换系统外观**：手机「设置 → 显示与亮度」切深色 / 浅色，回到 App。
   - 预期：页面底色、卡片、文字、顶部栏、底部导航**整体跟着变**，不需要重启 App。
   - 预期：**不会跳回首页**——先进入任一二级页（如设置 → 沙箱设置），
     再切外观，页面应当还在原地。
2. **层次感**：深色下看卡片是否与页面底色**分得开**（卡比底略亮），
   顶部栏与底部导航是否仍是**半透明磨砂**（滚动内容从栏下透出）。
3. **状态栏图标**：深色下状态栏图标应为浅色（反之亦然），不应出现「深底深图标」看不清。
4. **文字可读性**：深色下正文、辅助说明、按钮文字都要能读清（不应出现白底黑字变黑底黑字）。
5. **阅读器不受影响**（文档硬性要求）：
   - 小说阅读页：应仍按**阅读设置里的主题**（羊皮纸 / 夜间深灰 / 护眼绿 / 纯白）显示，
     不跟随全局深色；
   - 漫画阅读页：底色应仍是阅读设置里的「纯黑 / 深灰 / 护眼绿 / 纯白」；
   - 但两页的**工具栏/面板**是全局主题色——在纯白阅读底色 + 深色系统下，
     请确认工具栏文字仍可读（本轮已验对比度 6.5–17.4，理论上没问题）。
6. **视频浮层**：播放页的手势提示、HUD、弹幕应保持深色（它们压在画面上）。

### B. 调试面板

1. 设置 → 调试面板。
   - 预期：能看到「开发者模式」「请求抓包」两个开关，**默认都是关的**。
   - 预期：运行环境区显示在册 JS 上下文数、放弃回收的 runtime、日志缓冲、全局网络参数。
2. 打开「开发者模式」→ 再打开「请求抓包」。
   - 预期：抓包开关在开发者模式关闭时是**禁用**的。
3. 回到任一板块浏览图源内容（触发网络请求），再回调试面板。
   - 预期：出现请求明细（方法 / 状态 / 耗时 / 来源 / URL）。
   - 预期：展开任一条，请求头里 **`Cookie` / `Authorization` 显示为「已隐藏，N 字符」**，
     **看不到明文凭据**。
4. 关掉「请求抓包」。
   - 预期：记录**立刻清空**（不留「关了但旧数据还在」）。
5. **确认不落盘**：关掉抓包后杀 App 重进，调试面板应无历史记录。

### C. 字幕与解码（重点：分清「真生效」与「只记录」）

1. 设置 → 播放器设置 → 字幕区。
   - 预期：字号（小/标准/大/**特大**）、颜色（白/黄/绿/青）、描边（无/细/粗）、
     延迟滑杆（±10 秒）都在。
2. **切到 MPV 内核**，播放一个**带内嵌字幕**的视频，逐项验证：
   - **字号**：切「特大」→ 字幕应明显变大（**真生效**）；
   - **颜色**：切「黄色」→ 字幕应变黄（**真生效**）；
   - **描边**：切「粗」→ 字幕应有黑色描边，压在亮画面上仍能读（**真生效**）；
   - **延迟**：拖动滑杆 → **当前不生效**（见下方说明），这是已知边界，不是 bug。
3. **硬件解码开关**：设置 → 播放器设置 → 解码区，关闭开关。
   - 预期：**当前不影响解码**（media_kit 未开放写 hwdec 的通道），
     但**设置值会保存**，重进设置页仍是关闭状态。
   - 运行日志里应有一条说明：「硬件解码开关已记录…当前内核未开放写 hwdec 的通道」。
4. 若某台设备**硬解 HEVC 花屏 / 黑屏**：本轮无法通过开关绕过，请记录机型与表现
   （这是已登记在 `deferred-todo.md` 的待办：需 media_kit 开放通道或 fork）。

### D. 原有核心功能复测

1. **MPV 播放器切换**：视频板块 → 反复来回切换原生 / MPV → 杀 App 重进视频板块。
   - 预期：右上角播放器设置入口**稳定不消失**；播放**无卡死转圈**；
     起不来时有「重试 / 切回 AVPlayer」两个出口。
2. **JS 沙箱**：导入死循环脚本（`assets/test_sources/deadloop_source.js`）→ 触发加载。
   - 预期：约 1–5 秒内出超时提示；App **不卡死**；返回后仍可正常操作。
3. **沙箱超时可配**（本轮新增）：设置 → 沙箱设置 → 选 5 秒 → 保存。
   - 预期：提示「已保存：新建的源引擎按新超时运行」；页面注明其余上限不可调。
4. **Venera 图源**：导入 `venera_demo_json.js`（改 `BASE_URL` 指向可访问站点）→
   走完 分类 → 列表 → 搜索 → 详情 → 章节 → 图片。
5. **三套 demo 图源**：小说 / 漫画 / 视频各导入一份，确认：
   - 各自板块正常出内容；
   - **跨板块导入被拒**（报「跨板块」）。
6. **图源生成器入口**：设置页底部应有「图源生成器（开发中）」，点进去是占位页，
   按钮点击弹「功能开发中」。
7. **批量刷新订阅源**（本轮新增）：源总管理页工具栏 → 刷新按钮。
   - 预期：只刷新带订阅地址的源；有确认；结束给汇总（更新 / 已是最新 / 失败）。
8. **图源分组与失效标记**（本轮新增）：板块源管理 → 某源「更多」→ 设置分组。
   - 预期：列表上显示分组名；连错 3 次的源标「已失效（连错 N 次）」，
     菜单多一项「恢复（解除失效标记）」。
9. **底部导航栏开关**（本轮新增）：设置页顶部 → 关掉「显示底部导航栏」。
   - 预期：底部 5 个 Tab 消失，**左下角出现一个小圆按钮**；
   - 预期：点它导航栏回来；
   - 预期：恢复按钮**不与页面右下角的「+」按钮重叠**；
   - 预期：杀 App 重进，开关状态保持。

## 附录：本机环境实测（为什么真机部分必须人工做）

```
ios_preflight:
  macOS               → ✗ (win32)
  xcode-select        → ✗ spawn xcode-select ENOENT
  xcodebuild          → ✗ spawn xcodebuild ENOENT
  simctl              → ✗ spawn xcrun ENOENT
  simulator devices   → ✗ spawn xcrun ENOENT
```

因此本机**无法安装、无法运行、无法截图** iOS 包。本轮能做的是：
在代码层把真机必然暴露的问题（布局溢出、颜色可读性、机制正确性）提前查出来并修掉，
把剩下的部分交给人工按本清单执行。
