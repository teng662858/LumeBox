## 二、三批提交明细

### 提交 1 · 书架网格 / 列表双视图（`e7578de`）

| 项 | 内容 |
|---|---|
| 落点 | `lib/features/novel/novel_shelf_page.dart` |
| 新增 | `ShelfViewMode`（grid / list，落库标识稳定不随文案变） |
| 交互 | 书架右上角两个图标按钮切换；网格沿用与漫画书架同一套 3 列海报规格（跨板块手感一致），列表保留原横向卡片（进度 + 一键续读） |
| 持久化 | 偏好落**本板块阅读库**的 `reading_setting`（键 `novel.shelf.viewMode`，与排版参数同表同隔离）；重进书架沿用上次选择；脏值回退默认不抛错 |
| **默认视图** | **列表**——小说是文字内容，封面信息量不如「读到第几章、百分之多少」+ 续读；且保持升级后形态与原先一致 |
| 用例 | 3 个：双视图切换、偏好落库并沿用、脏值回退 |

### 提交 2 · 目录页章节搜索（`efb247f`）

| 项 | 内容 |
|---|---|
| 落点 | `lib/features/novel/novel_catalog_page.dart` |
| 交互 | AppBar 增加「搜索章节」开关，**默认收起**（目录页主用途是翻到某一章，常驻输入框会挤掉目录可视区）；输入即筛（纯内存过滤，不打网络）；带「清空」 |
| **正交性** | 搜索只决定「显示哪些行」，行上仍是**正序下标**：搜索与倒序可叠加，且点章进阅读器落库的 `chapterIndex` 始终正序 |
| 空态 | 搜不到给「没有匹配的章节」，不是白屏 |
| 用例 | 5 个：只留命中项、空态、搜索×倒序叠加、清空/收起恢复完整目录、搜索结果点章落正序下标 |

### 提交 3 · 阅读字号上限 30pt → 36pt（`159bfbb`）

| 项 | 内容 |
|---|---|
| 落点 | `lib/features/novel/novel_typesetting.dart`（`maxFontSize`） |
| 依据 | 宪法第 3 部分第 2 节「字号（12-36pt）」；实现里的 30 是早期自定值 |
| **升级影响** | 旧库中 >30pt 的字号会被**钳回 30**（钳位在 `copyWith` 与反序列化两处）。属有意的口径修正：放宽上限后若保留超上限历史值，「参数永远落在 min–max 区间内」这条不变式会失效（分页引擎与滑杆都依赖它） |
| 受影响面 | 很小——旧上限本就是 30，只有曾把字号顶到 30 的用户需手动再调到 36 |
| 数据安全 | 只钳位字号一个字段；书签 / 阅读进度 / 主题 / 其余排版参数原样保留 |
| 文档 | 新增 `CHANGELOG.md`（本仓库原先没有），首篇记录本次口径修正与同批两项 UI 变更 |
| 用例 | 3 个：范围与钳位不变式、旧库超限值读取时钳回、上限值本身不被误钳 |
